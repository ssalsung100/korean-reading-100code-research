# 독립 연구 03 — 증거 평가·설명 경쟁·입장 귀속

연구일: 2026-09-07~08. 현재 A~L **12문항·독립 지문 12개**에 대한 회차 집계. 평가원 6(본시험·모평 5, 예시문항 1), LEET 3, MEET 3이다. 9월 8일 재개 회차에서 새로 풀이한 문항은 G~L 6개이며 A~F는 이전 최초 기록을 보존했다. 새 지문·문항은 생성하지 않았다.

## 성과와 한계

정답·개별 태그를 가린 최초 풀이를 파일로 고정한 후, 정답 대조 → 독립 코드 저장 → SDSS 공개 순서로 조사했다. A는 이전에 같은 지문의 다른 문항을 읽은 이력이 있으므로 신규 지문 블라인드 성과에서 제외한다. 나머지 B~L 11문항은 이번 연구에서 확인된 선행 지문 노출이 없다. 연구 코드군은 사전에 알려져 있었고 모델 사전학습의 노출까지 배제하지는 못한다.

공식 정답 일치: A~L 12/12(신규 지문 집계 B~L 11/11). 정본의 공식 정답 필드를 대조한 범위이며 모든 원본 시험지의 정답 PDF를 이번에 새로 전수 대조한 것은 아니다. 이는 세부 해석의 유일성이나 코드 판정의 정답률을 뜻하지 않는다. **풀이 구조의 확인과 SDSS 명칭·주 코드 순위의 확정은 별개**다. 실제로 B·G 및 E·H·I에서 판정 단위와 누락된 경쟁 코드 문제가 드러났다.

사이트 연결 사례는 A~I 9개, 외부 태그 미연결 보충 사례는 J~L 3개다. 최종 대조 집계는 일치 4, 부분 일치 3, 코드 복합 사례 1, 판단 보류 4(그중 외부 태그 미연결 3)다. 보류를 억지로 승패에 포함하지 않는다.

근거 수준은 다음과 같이 나눈다.

- **원문 확인:** 특정 기출에서 직접 확인한 논리·정보 위치·선지 오류.
- **표본 공통:** 복수 기출에 반복되지만 모든 기출의 불변 법칙으로 확정하지 않은 관계.
- **가설:** 코드의 일반 경계, 시험군 전체의 문체, 생성 시 난도 효과 등에 관한 미검증 제안.

자료 정리·해시·연결 검수는 Terra, 최초 풀이·오답·경쟁 코드·귀납은 주 에이전트가 담당했다. 세부 공개 순서는 [절차와 진행 기록](독립연구_03_절차와_진행기록.md)에 따른다.

## 1. 코드 이름보다 먼저 보존할 실제 구조

### 1.1 근거를 약하게 하는 것과 결론을 거짓으로 만드는 것

원문 확인 A: `제도 R을 목적 G로 정당화 → R이 G에 기여할 후보를 배제하는 사례 E → 정당화 연결 약화`. 제도 전체의 위헌 또는 무효를 증명하는 구조가 아니다.

원문 확인 H: `현재 액체 핵 → 자기장` 외에 `과거 고체화 후 잔류자기 → 자기장`이 가능하다. 후자는 자기장 관측을 액체 핵의 독점적 근거로 사용하는 것을 막지만, 현재 액체 핵이 없음을 직접 증명하지 않는다. 다른 예측을 내는 경도칭동 자료는 별도로 제시된다.

표본 공통: 결론의 부정, 전제의 부정, 근거에서 결론으로 가는 연결의 약화, 대체 설명의 추가를 분리해야 한다. 단지 ‘불리한 정보’라는 한 칸으로 합치면 생성할 오답의 오류 위치도 사라진다.

### 1.2 양립과 지지의 구별

원문 확인 C: 어떤 자료가 해석과 ‘상충하지 않는다’는 정답은 그 자료가 해석을 확증한다는 말보다 약하다. 또한 양립 가능하다고 증거력이 반드시 중립이라는 결론도 나오지 않는다.

원문 확인 E: 동일 자료가 (나)와 (라)를 함께 보강할 수 있다. 설명을 여러 개 비교한다고 모든 쌍이 양립 불가능한 것은 아니다. 하나의 발굴 자료에서도 연대·식생활·주거·출입구 정보가 각각 다른 주장 부분에 연결된다.

원문 확인 H: 전도성이라는 기제의 조건, 액체 층이라는 구조 가정, 실제 칭동 관측을 모두 동일 강도의 독립 증거처럼 처리하지 않는다. 공식 답이 ④라는 것만으로 나머지의 증거 강도 순위가 정해지는 것은 아니다.

### 1.3 같은 관측도 평가 대상을 나누어야 한다

원문 확인 I: `이론 T가 현상 O의 존재를 예측 → O 관측은 지지`와 `O의 속성 S의 원인을 T가 설명하지 못함`은 함께 성립한다. 배경 복사 존재에 대한 성공을 등방성의 설명 성공으로 확대하거나, 설명 공백을 기존 관측의 전면적 반증으로 바꾸면 오답이 된다.

원문 확인 E: 어떤 연대 자료가 특정 전파 경로의 부정에 유리하더라도, 같은 학설의 사회 평등성 주장까지 보강하지는 않는다.

표본 공통: 증거 평가 전에 `대상 / 명제의 부분 / 적용 조건 / 평가 강도`를 고정한다. 학설 이름 하나에 모든 내용을 묶고 자료의 ‘찬반’만 표시해서는 부족하다.

### 1.4 입장 귀속은 증거 평가보다 앞선 작업일 수 있다

원문 확인 D: 군주제 유지, 입헌 여부, 국민주권은 서로 다른 비교 축이다. 같은 군주제를 선택해도 정당화는 다르다. 다른 단체의 반군주제 지향을 신한혁명당에 옮기면 오류다.

원문 확인 F: 원래 텍스트의 뜻, 다른 주석가의 해석, 박세당의 해석을 구별해야 한다. 새 진술이 박세당의 견해에 부합하는지 묻는 것이지 원래 도가 사상에 대한 배경지식을 묻지 않는다.

원문 확인 C의 ④: 자료의 지지 방향을 따지기 전에 선지가 학자에게 귀속한 인과 방향부터 틀렸는지 확인한다. 자료와 맞는 내용이라도 그 사람이 주장한 내용이 아니면 ‘그 주장을 지지한다’는 설명이 성립하지 않는다.

### 1.5 새 보기의 존재와 증거 평가를 분리한다

원문 확인 G: 신용 증가에서 수요 증가로 이어지는 경로가 소비·투자 상태 때문에 막혀 있다. 침체기에 신용 공급을 돕는 제도를 곧바로 금융 안정의 필수 수단으로 삼을 수는 없다. 여기에는 기제 적용과 필요성의 강도 판단이 함께 들어 있다.

원문 확인 B: 비판에 필요한 근거가 본문에 이미 제시되어 있어도 비판을 제대로 이해하는 일이 필요하다. 따라서 ‘새 보기가 있어야 #63’이라는 규칙은 성립하지 않는다. G는 새 보기의 충분조건성을, B는 새 보기의 필요조건성을 각각 의심하게 한다.

풀이 행동에 따른 경계 문장:

- 학자 둘이 나온다고 #74인 것은 아니다. 동일 관측에 대한 대체 설명의 기대를 구별할 때 설명 경쟁 구조가 핵심이다. 지정된 학자가 실제로 한 말을 회수하면 입장 귀속 구조가 핵심이다.
- 새 자료가 있다고 #63인 것은 아니다. 자료가 주장의 지지 관계에 미치는 영향을 판단할 때 증거 평가가 핵심이다. 이미 주어진 기제를 새 조건에 적용하면 인과·조건 적용이 핵심일 수 있다.
- 설명 실패가 있다고 #36인 것은 아니다. 이론이 반드시 예측한 내용의 명시적 위반이 있는지 보아야 한다. 설명하지 못한 속성이 있다는 것과 반대 속성을 예측했다는 것은 다르다.
- ‘필요’가 있다고 #2를 자동 주로 삼지 않는다. 다만 원문이 허용하는 강도보다 결론이 강해지는지를 경쟁 목록에서 반드시 확인한다. G에서는 #50만으로는 필요성 표현의 역할을 다 담지 못했다.

## 4. 시험군별 구현 — 관찰과 미검증 일반화를 구분

이 절은 1차 A~I의 각 시험 3지문씩을 비교한 기록이다. 이후 추가한 평가원 J~L의 비교는 7절에 분리했다. 시험 전체의 난도·문체 차이를 확정할 수 없고, 특히 소재와 연도가 함께 달라 시험 효과만 분리할 수 없다.

### 평가원 A·B·G

원문 확인: A는 제도의 적용 범위를 앞에서 정의하고 뒤에서 찬반의 정당화 기준을 분산한다. 선지는 후보의 속성을 바꿔 어느 논거를 약화하는지 압축한다. B는 앞부분에서 정의한 도덕 문장의 성격을 뒤의 조건문 맥락에서 다시 회수하며 동일한 P의 내용 유지 여부가 비판으로 이어진다. G는 P1의 전달 경로, P5의 경기별 제도 작용, 보기의 수요 위축을 연결해야 한다.

생성용 후보: 앞에 정의, 뒤에 적용 조건, 문항에 관계의 회수를 배치하되 연결 문장을 전부 노골적으로 되풀이하지 않는 방식. 이는 실제 세 사례에서 추출한 배치이며 모든 평가원 글의 의무 형식은 아니다.

### LEET C·D·H

원문 확인: C는 다수의 해석과 별도 사료에서 귀속·인과 방향·평가 강도를 함께 확인한다. D는 정치 체제의 여러 비교 축이 교차한다. H는 동일 관측의 대안 설명과 별도 판별 관측을 나누고, 수식 정보 중 실제 문항에 필요한 역할만 회수한다.

가설: 평가원용 구조를 확장할 때 다중 주체·교차 기준·증거 수준 차이를 증가시키는 재료가 된다. 그러나 ‘LEET는 언제나 더 복잡하다’는 단정은 현재 표본으로 검증하지 않았다. 문자 추출본 C·H의 P1 표시는 원문 문단 길이 자료로 사용하지 않는다.

### MEET E·F·I

원문 확인: E는 하나의 보기에서 다수 발굴 항목을 여러 설명의 서로 다른 주장 부분에 연결한다. F는 원래 사상과 후대 주석의 해석을 분리한다. I는 관측·설명 한계·후속 보완이 시간 순서 속에 얹혀 있다.

가설: 복수 증거의 선택적 대응, 해석 층위, 이론의 성과와 공백의 공존을 연구하는 확장 사례가 된다. 그 긴 문장이나 역사·과학 서술 방식 자체를 평가원 생성의 문체 기준으로 옮기지는 않는다.

## 7. 추가 반례 J~L — 두 번째 귀납

이 절은 A~I 중간 귀납을 먼저 저장한 뒤 추가 기출을 답·태그 가림 절차로 풀어 얻은 수정이다. 태그 공개 전 파일을 보존하므로 사이트 정보에 따른 추후 변경과 구분할 수 있다.

### J: 강한 단어의 유무가 아니라 결론의 확정 강도

[최초 풀이](../../data/기본기_연구/독립풀이_03/J_01_최초풀이.md), [독립 코드](../../data/기본기_연구/독립풀이_03/J_02_정답대조와_독립코드.md). 2010학년도 6월 모평 37번. 최초 ①/공식 ①.

상대 우열 `C > S > R > C`는 어느 집단이 최초로 우세해지는지 결정하지 않는다. 동일 비율은 최초를 정하는 충분한 정보가 아니다. 반면 ‘저항성 집단의 출현이 필연적이라면’이라는 가정 안의 필연성은 그대로 전제로 사용할 수 있다. ‘균등한지의 여부를 판단한다’도 ‘균등하다’라는 결론이 아니다.

G에서 발견한 양상 검토 누락을 보완하되, ‘필요·필연 같은 단어를 우선 찾으면 된다’로 대체하지 않는다. **가정의 강도 / 실제로 도출하는 결론의 강도 / 정보가 제공하는 결정 가능성**을 분리한다. 단어 탐지보다 문장 전체의 논리적 기능이 먼저다.

### K: 대안 설명과 전제 묶음의 책임 미결정은 다르다

[최초 풀이](../../data/기본기_연구/독립풀이_03/K_01_최초풀이.md), [독립 코드](../../data/기본기_연구/독립풀이_03/K_02_정답대조와_독립코드.md). 2017학년도 수능 18번. 최초 ⑤/공식 ⑤.

`H ∧ B ∧ C → P`의 예측 실패는 H만의 실패를 확정하지 못한다. 다른 부분을 수정하여 H를 유지할 가능성이 총체주의 안에서 허용된다. ⑤는 그 가능성을 불가능으로 바꾼다. H의 자기장 사례는 한 관측을 만드는 여러 경로이고, K는 하나의 예측을 만드는 결합 전제의 수정 대상 문제다. 표면상 ‘가설이 반박되지 않을 수 있다’는 결론이 같아도 중간 구조는 다르다.

이 사례를 엄격한 ‘경쟁 가설의 상반된 예측을 관측으로 가르는 평가원 사례’로 세지 않는다. 가설이라는 단어와 과학철학 소재만으로 부족한 표본을 채우면 처음부터 피하려던 표면 분류로 되돌아간다.

### L: 비판 방향 판단 전에 비판 대상을 고정한다

[최초 풀이](../../data/기본기_연구/독립풀이_03/L_01_최초풀이.md), [독립 코드](../../data/기본기_연구/독립풀이_03/L_02_정답대조와_독립코드.md). 2022학년도 평가원 예시문항 9번. 최초 ③/공식 ③. 본수능 시행 사례와 구분한다.

‘독립적인 비물리적 정신을 추가할 필요 없음’과 ‘정신이 없음’은 다르다. ③은 후자를 상대의 주장으로 잘못 귀속한 뒤 공격한다. 나머지 선지는 실제 구현과 모방, 행동과 이해 등의 구별로 물리적 설명의 충분성을 문제 삼는다. 따라서 단순히 모두 ‘약화’로 적지 않고 **귀속 오류(#65 후보)와 연결 충분성 공격(#62 후보)**을 나눠야 한다.

B와 L은 새 보기가 없어도 비판의 적절성을 판단할 수 있음을 확인한다. 그러나 둘 다 과제 유형 #63과 세부 병목 #60/#65를 구분해야 한다. 새 보기의 유무를 버렸다고 곧 단일 주 코드 판정까지 해결된 것은 아니다.

### 추가로 보존할 평가원형 생성 원재료

- J: 쌍별 관계를 먼저 주고 순환 순서와 출발점을 문항에서 분리한다. 정답은 정보가 보장하지 않는 특정 결과를 지목하고, 매력적 오답은 조사 가능성을 결과 확정으로 오독하게 한다.
- K: 앞의 전제 묶음 구조를 뒤의 수정 원칙으로 설명하고, 문항에서 지시 기호 ⓐ~ⓒ로 회수한다. 정답 선지는 허용된 수정 경로를 불가능으로 바꾼다.
- L: 처음 정의한 존재 방식의 구별을 뒤의 컴퓨터 논증에서 재사용한다. 정답 선지는 중요한 한정어 ‘독립적인’을 잃은 상대 주장을 공격한다. 단순 어휘 삭제가 아니라 부정 대상의 범위가 달라지는 구조를 보존해야 한다.

### 두 번째 탐색의 결론

추가 세 사례로 양상 단어 탐지, 예측 실패의 단일 책임 귀속, 비판 과제의 단일 코드화라는 간단한 기준에 반례를 얻었다. 반면 평가원에서 엄격한 상반 예측–관측 판별 구조의 짝 사례는 아직 확보하지 못했다. **후보가 없다는 결론이 아니라 이번 선정이 해당 조건을 충족하지 못했다는 기록**이다. 다음 탐색은 이 미충족 조건에 집중한다. 독립 연구의 목적상 새 사례가 쉽게 기준을 수정시키는 현재 단계는 포화가 아니다.

J~L은 로컬 사이트 라벨의 정확한 연결을 찾지 못한 `site_unlinked_supplement`다. 사이트의 전역 미표지로 단정하지 않으며, 독립 #2/#65 판정을 SDSS가 해당 문항에 붙인 태그처럼 적지 않는다. [추가 공개 자료와 탐색 범위](../../data/기본기_연구/독립풀이_03/source_disclosure_JL.json)에 미충족 조건을 남겼다.

## 8. 다음 회차의 바로 할 일
