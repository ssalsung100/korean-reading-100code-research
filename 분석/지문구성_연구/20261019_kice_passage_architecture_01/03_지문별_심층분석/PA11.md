# PA11 — CT의 영상 구성

자료: 2014학년도 9월 A 19~21. [전사](../근거/지문만/PA11.md). 본문은 텍스트만으로 핵심 과정이 이어진다. 문항의 그림은 2단계에서 별도 취급한다.

## 지문 자체 분석

질문은 **몸을 통과한 X선의 세기에서 어떻게 조직의 단면·입체 분포를 재구성하는가**이다. 독자는 X선으로 안을 본다는 인상에서 관측값 보정→여러 방향→역투사→합성이라는 변환을 이해한다.

|문단|정보·설명 역할|앞 정보 재사용|
|---|---|---|
|P1|비침습 진단의 발전|기술의 목적과 결과 소개|
|P2|투과율·두께와 X선 세기, 필름, 구별 한계|측정량과 조직 사이 관계 제공; 뒤의 환산·분포 복원에 필요|
|P3|발생기·검출기·회전 중심의 배치|어디서 어떤 자료가 생기는지 측정 장치 지정|
|P4|공기 통과 영향 제외, 환산값, 여러 방향의 관측|검출된 세기를 조직에 귀속되는 양으로 바꿈; 다방향 자료의 입력 생산|
|P5|경로에 고르게 분배하는 역투사, 방향별 합산|P4의 한 경로 총량을 공간의 후보 위치들에 배정하고 결합|
|P6|조직 분포, 연속 단면, 입체 조합|각 단계를 새 발명처럼 나열하지 않고 출력의 공간 차원을 확장|

의존: P2→P4[감쇄의 의미], P3→P4[관측], P4→P5[입력/변환], P5→P6[단면 출력/조합]. 시간적 서술 순서와 실제 데이터 의존이 일치하는 부분이 많은 표본이다.

삭제·이동: P4를 지우면 P5의 환산값이 무엇을 뜻하는지 알 수 없다. P5를 지우면 여러 방향에서 찍었다는 사실만으로 분포가 만들어지는 중간 기전이 사라진다. P1은 압축해도 과정의 논리는 유지된다. P6의 입체 조합을 먼저 제시하는 것은 가능하지만 그때는 결과 예고가 되고 기술적 근거는 뒤에서 채워야 한다.

P4의 공기 보정은 단순 계산 함정이 아니라 측정 대상을 조직으로 한정하는 기능이 있다. P5의 균등 분배는 실제 CT 알고리즘 전체를 완전 재현하는 설명이 아니라 기출이 제시한 단순화된 기전이다. 역투사를 현대 임상 알고리즘의 유일 방식으로 일반화하지 않는다.

문항을 제거해도 모든 중간 변환이 필요하다. 다만 결과의 이름보다 입력·출력의 단위와 의미를 식별해야 하는 구조를 일반화할 수 있을 뿐, 모든 지문이 기술 공정처럼 선형이어야 한다는 근거는 아니다.

## 문항 연결 — 19·20번

19번 최초 선택 ④, 확신 높음. P2의 흡수·산란량과 투과량을 언제나 같다고 둘 근거가 없고, 두께·투과율에 따라 나뉘는 양이 달라진다.

20번 최초 선택 ②, 확신 높음. 공기의 투과율이 높음(P2)→조직 감쇄에 해당하는 환산값이 작음(P4)→역투사 결괏값이 크게 모일 대상이 아님(P5). ④는 낮은 투과율→큰 감쇄→큰 결괏값을 연결한다. 입력 물성에서 처리 출력의 방향까지 서로 다른 단계의 양을 잇는다.

P4/P5를 삭제하면 20번이 어렵기 때문만 아니라 검출값에서 영상이 만들어지는 설명 자체가 끊긴다. 과정의 중간 정보가 본문과 문항에 공용되는 사례다. 21번의 물체 그림·그래프는 누락되어 전수 적용 분석에서 제외한다. 텍스트만으로 그래프 정답을 추정하지 않는다.
