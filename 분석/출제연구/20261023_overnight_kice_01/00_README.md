# 최근 평가원 기준 연속 연구·출제

시작: 2026-10-23 02:02:25 KST. 목표 종료: 2026-10-23 09:32:25 KST.

이번 작업은 2026-10-23 09:09:26 KST에 완료했다(실제 7시간 7분 1초). [종합 결과 보고](연구결과_보고.md)에 실제 범위와 남은 한계를 정리했다. **지역 빈곤 개정 후보와 신규 품질 보증·공유자원·사회적 확산 후보, 총 4세트·12문항·60선지 및 전 선지 해설**을 저장했다. 기존 6세트는 기노출 재검토이며 독립 blind 성과로 세지 않는다. 실제 진행 상태는 [checkpoint](checkpoint.json)을 따른다.

이번 사용자 지시에 따라 다른 모델을 호출하지 않고 직접 연구·기록한다. 기존 Astra/Luna 원장과 CURRENT는 갱신하지 않는다.

향후 독자 검토용 [학생용 빈 응답기록지](후속검토/학생용_응답기록지.md)와 [교사용 관찰 기준](후속검토/교사용_관찰기준.md)도 분리했다. 추가 서술형 확인2개는 수치·후보 집합만 검산했으며 학생에게 실시하지 않았다. 정규12문항이나 새 기출 실적으로 합산하지 않는다.

기준 기간은 2022학년도 수능(2021년 시행)부터 실제 공개된 2027학년도 9월 모의평가까지다. 최신 회차의 공식 문제·정답 PDF는 저장소 보유를 확인했다. 기존 6세트 연구를 새 전수 성과로 중복 집계하지 않았다. 새 소재에 필요한 권리의 대상 구별을 위해 2024학년도9월4~7번을, 관찰 결과의 입력 복원을 위해2024학년도6월4~7번을 추가했다. R7은 원문 검색 중 정답 노출로 비독립 검토다. R8은 이번 세션의 단계 장벽을 지켰지만 과거 노출 불명으로 엄격한 blind 실적을 확정하지 않았다.

후속 R9는2024학년도 수능8~11번의 기술·측정 지문이다. 지역 빈곤의 집계와 더 가까운 연산이 있는지 대조했으나, 실제 정답의 대표값 민감도·후보 단계 판단은 달랐다. 빈곤2는 유지하고 직접 대응을 추가하지 않았다. 같은 시험의 답이 앞서 노출되었으므로 비독립 검토로 표시한다. 기존6세트에 추가한 참조는 총3세트12문항이며 신규 고유 기초연구 실적으로 소급 집계하지 않는다.

후속 대조에서는 R9의8번을 공유1의 직접 근거로 재사용했다. 명시된 예외로 일반 진술을 배제하는 실제 최소 풀이가 더 가까워, 이전 R7의 권리 종류 연결은 기능적으로 낮추었다. 새 기출을 추가하거나 직접 대응 문항 수를 늘린 것은 아니다. [대응표의 판정 수정](기출핵심판단_신규문항_대응표.md)을 함께 확인한다.

기출 대응은 직접·기능적·넓은 유형을 구별했다. 기존 빈곤2의 수량적 공통점은 제도의 공통 속성과 같은 연산이 아니어서 대응을 낮추었다. 빈곤3은 대안 2개를 비교하여 차감항 대체의 오류 방향을 실제 정답 근거로 만들었다. 신규 두 세트에서는 문항 간 답 단서, 권리 분류의 역할 중복, 선택 모형의 누락 조건과 동률 경계를 수정했다.

초안·수정 전 문안·미채택 대안은 보존했다. 이번 작업의 완료 상태와 실제 종료 시각은 checkpoint와 결과 보고에 기록했다. 기존100코드 연구 전체의 완료를 뜻하지는 않는다.

## 선택적 추가 실험

앞선 세트의 첫 검증·개선 후 [사회적 확산 학생용](D_추가연구/04_사회적확산_학생용후보.md)과 [15선지 해설](D_추가연구/05_사회적확산_교사용.md)을 추가했다. 정보 전달 경로와 행동 채택 조건, 노출 횟수와 원천 수를 구별한다. 현재 총 학생용 후보는 기본3세트에 추가1세트로 12문항·60선지다.

추가 실험은 처음에 기출 직접 대응을 확보하지 못했다. 이후 R8을 추가 분석하고 [2번을 실제 재설계](D_추가연구/07_관측결과에서_기준복원_대안.md)하여, 현재는 관찰 결과에서 가능한 기준을 복원하는2번만 직접 대응으로 판정한다.1·3번의 기능적 유사성 판정은 유지한다. [학술·설계 근거](D_추가연구/02_사회적확산_근거와설계.md), [모형 검증](D_추가연구/사회적확산_검증결과.json), [구현 실패 분석](D_추가연구/01_기출판단_구현실패와_조건.md), [제작 기준 교차 검증](D_추가연구/06_제작기준_교차검증.md)을 함께 남겼다.

후속3번은 [고정 상태 판단 대안](D_추가연구/08_확산3_고정상태_필수판단_대안.md)을 채택했다. 연결망·초기값·정답 진술의 내용은 유지하고 I의 시점과 II의 최종 여부를 모두 판정해야 선택할 수 있게 고쳤다. 이어 미채택자는 문턱 미달 시 채택하지 않는다는 방향도 보기에 명시했다. 현재 확산 정답은③⑤③이다. 이 개선으로 기출 대응 수준을 상향하거나 학생 난도를 검증했다고 주장하지 않는다.
