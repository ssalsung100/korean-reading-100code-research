# 연구 원리 체계 v1

2026-10-18. 이 체계는 **지문에서 필요한 관계를 복원하고, 선지가 요구한 판단에 맞춰 중간 추론을 실행하는 도구**다. 100코드 번호나 소재 이름을 맞히는 체계가 아니다. 연구 원리63개를 유지하면서 입력·판단 단서·추론·출력·경계를 조작 가능한 형태로 묶었다. 잠정 안정화26·단독 잠정29·추가 비교5·재분류3이며, 모두 연구자의 내용 검토 및 학생 재현성 검증은 별도다.

## 사용하는 순서

1. 발문이 요구하는 결과를 정한다. 문맥 치환, 실제 발생, 관점 귀속, 정량 비교는 다른 과제다.
2. 주체·대상·시점·관점·출력 범위를 고정한다. 이 확인만으로 풀이가 끝난 것은 아니다.
3. 필요한 정보 관계를 회수한다. 평균에는 가산 분모, 배율에는 공통계수, 목적에는 선택 동기의 증거가 필요하다.
4. 아래 카드의 중간 추론을 실행한다. 조건이 빠졌으면 미지원과 반대 명제의 참을 구별한다.
5. 정답에 필요한 경로와 다른 선지 판단·대안 풀이·연구용 검산을 구분한다.

한 문항에는 여러 원리가 들어간다. AGT의 출력 정보 보존은④의 적절성 판단이며 정답①의 전부가 아니다. LK의 광도 배율과 절대등급 차는 같은 답에 이르는 대안 경로다. 학생에게 둘을 모두 필수로 수행시키지 않는다. 미지 어휘의 관습적 뜻이나 문학적 해석의 경계를 몇 개의 형식 연산으로 완전히 제거할 수 있다고 주장하지 않는다.

## 조직과 계층

상위 조직7개는 찾기 위한 묶음이며 검증된 새 원리7개가 아니다. 실제 상하위 관계는 입력·중간 추론을 보존하는 범위에서만 허용한다. P002는 평균의 두 방향, P024는 부분량/역산/개선과 절대증가, P063은 집계/선택 표상을 하위로 남긴다. 반면 가중합 상쇄 P017과 축척 보정 P018, 정당화 순환 P005와 상태 되먹임 후보는 합치지 않는다.

P026은 P016, P027은 P012/P037, P034는 P050의 하위형일 가능성을 관계로 표시했으나 기존ID를 폐기하지 않았다. 112개 이전 후보의 A12/B17/C58/D25는 원리63개와 다른 단위다. C58을 새 확정 원리58개로 합산하지 않는다. [후보 보존 연결](기존후보_보존연결.jsonl)에 정의·조건·근거·유보를 모두 남겼다.

#### IR-P001 문맥 대입과 서술 관계 보존

**상태: 잠정 안정화** · 상위 원리와 복수 하위 연산

- 필요 입력: 원문 문장·대체어·주체와 대상·발문 종류

- 결정적 중간 추론: 대체 뒤에도 누가 무엇을 어떤 상태로 만드는지 비교한다. AY의 활발한 확산은 단순 발생과 다르지만 CP의 시선 행위는 더 넓은 말로도 남는다.
- 판단 결과: 문맥 관계 보존 또는 훼손
- 적용 조건: 발문이 실제 치환/문맥 대응을 요구하며 어휘의 관습적 의미를 확보해야 한다.

구조의 특정 기능 존재에서 그 기능을 더 중시한 설치 목적을 도출하지 않고 비교·우선성 표현을 명시 목적과 구체 구조에 대조한다.

- 필요 입력: 기능의 존재·설치 목적·비교 우선성 근거
- 시작 단서: 차단을 더 중시하여 설치
- 결정적 중간 추론: 경계를 만드는 기능과 그 기능을 우선하려는 의도를 분리하고 명시 목적에 대조한다.
- 판단 결과: 기능/목적 우선성 구별
- 적용 조건: 다른 기능 부재를 증명하지 않는다. 사진의 닫힌 상태만으로 의도를 확정하지 않는다.
- 비적용·경계: 차단 기능 부재를 증명하지 않음. 사진의 일부 닫힌 상태로 차단 우선 설치 의도를 확정하지 않음. 목적 변경만으로 벽 대신 창호의 차단 우선성이 입증되는 것도 아님.
- 대표 근거: QBF01-U0287-Q03-S01 — [AVL](<../../../data/기본기_연구/prepared_backlog/blind_sources/AVL.json>)
- 관계: IR-P043 ↔ IR-P044 같은 지문·독립 연산 — 유지/변경 설계 조건과 설치 목적의 우선성 판단을 분리한다.; IR-P052 ↔ IR-P044 부분 중첩 — 결과와 목적, 기능 존재와 목적 우선성은 귀속 근거의 종류가 다르다.
- 사용 수준: 대조·반례 설계용; 자동 생성의 확정 규칙 사용 보류 연구자 의견을 받았다고 간주하지 않는다.

#### IR-P048 장소별 작용 경로와 전체 순효과의 구별

**상태: 추가 비교 필요** · 독립 유지 중인 연산; 상태와 사용 범위는 별도

작용 장소별 경로와 목표를 분리하고 여러 경로의 효과 크기·선택성이 미정이면 한 경로의 개선에서 전체 순효과를 확정하지 않는다.

- 필요 입력: 장소별 경로·목표·효과 부호와 크기·되먹임
- 시작 단서: 한 기관 개선으로 전신 개선
- 결정적 중간 추론: 직접 경로와 간접 경로를 모두 합쳐야 순효과를 안다. 크기 미정이면 국소 개선을 전체 부호로 강화하지 않는다.
- 판단 결과: 경로별 효과와 총효과의 유보
- 적용 조건: BDN의 공식답 해석과 엄밀 유일성 유보를 동시에 보존한다.
- 비적용·경계: 공식③의 난소 직접 개선 해석을 실제 전신 효능으로 확대하지 않음. ㄱ·ㄷ 선택을 특정 용량 병용의 성공 보장으로 쓰지 않음. 실제 치료 권고 아님.
- 대표 근거: QBF01-U0355-Q03-S01 — [BDN](<../../../data/기본기_연구/prepared_backlog/blind_sources/BDN.json>)
- 관계: IR-P024 ↔ IR-P048 부분 중첩 — 수지 합성은 공유하지만 기관별 경로 크기 미정은 별도 식별 공백이다.
- 사용 수준: 대조·반례 설계용; 자동 생성의 확정 규칙 사용 보류 연구자 의견을 받았다고 간주하지 않는다.
