# 최초 유보한 두 선택표의 원문 보완

최초 판단과 저장 정답을 이미 읽은 뒤 수행한 보완이다. 최초 raw와 최초 답 대조 파일의 `initial_choice: null`을 변경하지 않는다. 새 blind 정답 실적으로 계산하지 않는다.

## PA08 — 2013학년도 6월 24번

저장소 원본 경로: `자료/평가원_정답표/추출/모의평가/2013_6월_국어_언어/2013_6_╛Ё╛ю_╣о┴ж.pdf`. PDF 7쪽을 텍스트 추출하고 [페이지 이미지](PA08_24_원PDF페이지.png)로 직접 확인했다. 시험지의 선택 조합은 ①ⓐⓑ, ②ⓐⓓ, ③ⓒⓓ, ④ⓐⓑⓒ, ⑤ⓑⓒⓓ이다. 최초 내용 판단 ‘ⓐⓑⓒ 참, ⓓ 거짓’은 ④와 대응하며 저장 답도 ④다.

ⓐ는 토양→뿌리의 방향, ⓑ와 ⓒ는 앞 위치의 물 손실이 뒤 위치의 이동을 유발하는 순차 관계다. ⓓ는 잎과 대기의 퍼텐셜 순서를 뒤집는다. 본문은 같은 높은 곳→낮은 곳 관계를 나무의 여러 위치에 반복 적용할 수 있도록 설계되어 있다. 선택표 보완으로 이 분석이 바뀌지는 않는다.

본문도 같은 페이지에서 확인했다. 실제 본문은 4문단이며 전사의 P1/P2 분리는 첫 문장 도중의 인위적 단절이다. `1 MPa=10⁶ Pa`의 지수 조판도 확인했다. 전사 원장을 수정하지 않았다. 같은 페이지에 25번 그래프가 보이지만 이번에 선정한 23·24번의 분석 수에 추가하지 않는다. 따라서 25번은 ‘영구 자료 부재’가 아니라 ‘초기 전사 누락으로 미선정, 후속 페이지 확보’ 상태다.

## PA16 — 2022학년도 6월 17번

저장소 HWPX의 텍스트층에도 뒤 두 열이 빠져 있음을 확인한 뒤 문제지 배포 사본을 받았다. 획득 위치는 [문제지 배포 페이지](https://mrjohnberant.tistory.com/377)의 ‘국어 문제’ 첨부파일이다. 공식 사이트의 해당 게시물은 이번 웹 도구로 열리지 않았다. 이 파일은 평가원 작성 시험지의 외부 배포 사본이며 공식 호스트에서 직접 내려받은 것으로 표시하지 않는다. 블로그 해설을 판단 근거로 사용하지 않았다.

보존한 파일: [문제지 PDF](2022학년도_6월_문제_배포본.pdf). 5쪽 [본문 이미지](PA16_본문_원PDF페이지.png), 6쪽 [17번 이미지](PA16_17_원PDF페이지.png)를 직접 확인했다. <보기>의 세 칸은 증가량·Ct에서의 발색도·Ct 순서다. 아래는 ⓐ를 ⓑ와 비교한 관계로 재표기한 선택표다.

|---|---|---|---|
|①|>|>|>|
|②|>|=|<|

|④|=|=|<|

최초 내용 판단 `>/=/<`는 ②에 대응하며 저장 답과 일치한다. ④는 증폭의 비율이 같다는 사실을 증가량이 같다는 판단으로 옮긴다. ①·③·⑤는 각자의 검출 시점에서 비교하는 발색도를 동일 시점의 양 비교와 혼동한다. 본문 P2의 증폭 관계와 P5의 검출 시점 정의를 결합하는 구조 분석은 유지한다.

본문의 [A]는 독립 문단이 아니라 P5의 구간 표지다. 원PDF는 본문 6문단으로 보이며 전사의 P7이 실제 마지막 응용 문단이다. 새로 확인한 조판과 기존 분석의 기능 단위가 대응한다. 전체 시험지의 다른 문항·문학 작품을 분석한 것은 아니다.

## 현재 남은 것

자료 누락으로 인한 두 답 번호의 대응은 확인했다. 최초 유보 3건 중 PA04-49의 표현 의미 형성 판정은 여전히 유보한다. 이 질문은 저장 답 ①을 안 상태에서 후속 의미론 검토를 해야 하며, 정답에 맞추어 최초 판단을 덮어쓰지 않는다.
