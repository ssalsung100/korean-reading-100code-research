## 한 항목의 답변 양식

아래 칸은 비워 둔다. 실제 연구자 발언이 들어오기 전 예시 답변을 연구자 의견으로 채우지 않는다.

- 검토 ID / 날짜 / 연구자:
- 원문 위치·선지 / 현재 사례집의 수정 대상 문장:
- 최초 독해에서 반드시 잡을 정보:
- 선지를 본 뒤 돌아와도 되는 정보:
- 실제 판단을 시작하는 단서:
- 학생에게 남길 말 한 문장:
- 생략해도 될 연구용 설명:
- 두 사례를 함께 다룰 방식 또는 분리할 이유:
- 대표 사례의 중요도·배치 변경:
- 적용 범위에 대한 이견·반례:
- 수정 요청: 원리 통합 / 분리 / 보류 / 설명 순서 / 표현 / 제작 조건 / 기타:
- 연구자 승인 여부: **미검토**

피드백 반영 시에는 원 발언과 AI의 해석을 나누어 저장하고 관련 IR-D·IR-P·IR-E ID를 연결한다. 원문·기존 판정을 덮어쓰지 않는다. 다음 버전에서 묶음·중요도·설명 순서·적용 범위를 실제로 변경할 수 있으며, 문체만 다듬는 단계로 축소하지 않는다. 새 기출·학생 질문·강의 경험은 출처 종류를 붙여 추가하고 기출 출현 수와 합산하지 않는다.
