# 추가 R7 — 데이터 소유와 이동

추가 이유는 신규 공유자원 지문에서 **권리를 가진다는 사실과 어느 권리를 갖는가, 대상이 이동한다는 사실과 무엇이 이전되는가**를 구별하는 판단이 필요했기 때문이다. 기존 6세트의 일반적인 조건 확인만으로 직접 대응을 주장하지 않기 위해 한 지문군을 추가했다. 새 연구 실적은 2024학년도 9월 4~7번 한 세트의 비독립 검토이며, 기존 전체 원장의 신규 고유 사례라는 뜻은 아니다.

## 노출과 원문

먼저 [전사](../../../data/기출_MD_정본/연도별/2024/9월_모평/독서/Q04-07.md)의 본문·보기·선지를 읽었다. 7번 선택표가 비어 있어 문제 PDF를 찾던 중 검색 결과에 EBS 정답표가 나타났다. **group 전체 최초 풀이 raw 저장 전 정답 노출**이므로 블라인드 장벽을 충족하지 못했다. 4~6번의 대화 내 최초 선택은 저장되지 않았으므로 성과로 세지 않는다. 이후 전부 비독립 검토로 전환했다. R006~R010 raw에 경위를 보존했다.

원문 보완은 평가원이 작성한 문제지의 [재배포 PDF](근거/R7_2024학년도9월_문제_재배포본.pdf), [2쪽](근거/R7_원문_2쪽.png), [3쪽](근거/R7_원문_3쪽.png)을 직접 확인했다. 다운로드 경로는 [재배포 게시물](https://seeonekr.tistory.com/entry/9%EC%9B%94-%EB%AA%A8%EC%9D%98%EA%B3%A0%EC%82%AC2024%ED%95%99%EB%85%84%EB%8F%84-%EA%B5%AD%EC%96%B4%EC%98%81%EC%96%B4%EC%88%98%ED%95%99-%EB%AC%B8%EC%A0%9C%EC%A7%80%EC%99%80-%EB%8B%B5%EC%A7%80)이며 이 게시물의 난도 평가를 연구 근거로 사용하지 않는다. 공식 호스트에서 받은 파일이라고 주장하지 않는다. [A]는 P4, [B]는 P5다.

정답은 기존 공식 PDF `자료/평가원_정답표/원본/모의평가/2024_9월_국어_국어영역_정답표.pdf`를 직접 읽어 ③·⑤·④·①로 확인했다. 현재 법률 일반의 정확성을 이 지문으로 검증한 것은 아니다.

## 기존 핵심과의 관계

- R7 4③과 R3 7①은 표면적으로 가진 특징을 더 강한 분류로 올리는 기능이 유사하다. 그러나 한쪽은 권리의 종류, 다른 쪽은 조직의 정보·권한 집중이므로 같은 연산의 반복이라고 합산하지 않는다.
- R7 6④와 R4 8⑤는 모두 제도의 적용 범위를 보존한다. 전자는 **대상의 제외 조건**, 후자는 **절차의 개시 조건**이므로 구별한다.
- 처음에는 신규 공유자원1번과 R7 4③을 권리 종류의 교체에서 직접으로 보았다. 후속 R9 8③과의 비교에서 특정 제도의 권리 인정 사실과 일반적 보유 함의를 구별하여, R7 연결은 기능적 유사성으로 낮추었다. 공유1의 직접 근거는 R9의 명시 예외/일반 진술 대조로 교체했다. 이전 raw와 원문 판독은 보존한다.
- 신규 공유자원2번의 권한 대상 판별은 R7 6④에 기능적으로 대응한다. 새 가치가 생성된 가공 자료와 결정권 이전이 동일한 법적 관계라는 주장은 하지 않는다. 비교 요약에서도 ‘새 가치 생성’ 조건을 지운 일반적인 가공 자료 배제 규칙으로 바꾸지 않는다.

## 코드와 제3자 태그

4~7번의 코드명 없는 논리 및 주·보조·표면 코드·경쟁 후보 반증은 R008~R010에 먼저 저장했다. 원문 노출 문제 때문에 이를 엄격한 독립 풀이 실적으로 세지 않는다. 제3자 후보색인 대조 결과는 별도 raw에 보존하며, 태그가 없으면 없는 상태를 남긴다. 이 작업으로 기존 100코드 원장이나 분류를 바꾸지 않는다.
