# 1차 통합 완료 준비도

2026-10-18, 사례집78 저장 상태 기준. **유보·사용 제한을 포함하는 1차 통합 연구의 종료와 v1 구축으로 전환할 준비가 되었다.** 모든 원리의 최종 확정이나 모든 기출의 엄밀 유일성 해소를 뜻하지 않는다. 현재 안정화한 범위와 아직 사용할 수 없는 적용을 분리했으므로 사례집 수를 늘리는 것을 다음 목표로 삼지 않는다.

## 실제 저장 상태

- 사례집78개, IR-P063·IR-D096·IR-E300까지.
- 직접 비교132문항·102지문군·191기존 장면. 이번 추가는4문항·8장면이며 신규 blind는0이다.
- 112개 현행 DEV 중36개는 참조 근거 직접 비교 완료,1개는 부분 비교,1개는 메타 연결,74개는 아직 직접 사용하지 않았다.
- 별도 연구자 검토40개, 시제품3종4문항. 모두 연구자 미검토이며 시제품은 모두 미승인이다.

|처리|개수|현재 의미|
|---|---:|---|

|F|0|이번 진단에서 처리 이유를 적지 않은 후보 없음|

**A/B29개와 C/D83개를 같은 의미의 완료로 세지 않는다.** C58개는 확정된58개 새 원리가 아니다. 기존 상세 풀이와 조건을 연결한 별도 후보 부록이다. D25개도 사라진 것이 아니라 상위 점검과 실제 하위 연산의 차이를 남긴 유보표다. ‘112개 모두 처리’는 그 지위를 기록했다는 뜻이다. 후보별 IR·IR-D·사례집·DEV·원장/원문 경로는 [통합상태표](기존후보_통합상태표.jsonl)에 있다. 기존 분석 재활용을 이번 직접 원문 비교로 계수하지 않았다.

E가0이어도 연구 메타가 없다는 뜻은 아니다. BCF S02의 정답 확인, AVV의 연구상 강도 관리, 출처·그림 복원은 장면/활동 층위에서 직접 풀이 빈도와 구분했다. 특정 장면의 메타 성격으로 후보 전체를 폐기하지 않는다.

## 원리63개의 상태

잠정 안정화26, 단독 잠정 후보29, 추가 비교 필요5, 재분류 검토3, 수정 필요0이다. 수정 필요0은 오류가 영원히 없다는 뜻이 아니라 이번 진단에서 현행 정의 자체를 즉시 고쳐야 할 미처리 충돌을 확인하지 않았다는 뜻이다. 국소 적용의 공백은 추가 비교 또는 사용 제한으로 기록했다. 상세 조건은 [원리목록](잠정안정화_원리목록.md)과 [제작 입력 범위](v1_입력범위.json)에 있다.

## 이번 직접 비교가 바꾼 판단

QZ는 두 존재명제가 정확한 부정쌍이 아니라는 이유만으로 약한 ‘적어도 하나 참’을 반박할 수 없음을 명시했다. SH는 같은m이라도 상대 천체가 다르며, 공식 기호 복원이 구슬의 분포 가정을 보완하지 않는다는 경계를 남겼다. AGT와 BFV는 선택 표상/수치 집계를 같은 계산으로 만들지 않고, 출력이 필요한 차이를 보존하는지 검사하는 상위 P063으로 통합했다. 이로써 집계정보손실과 BFP010은 D에서B로 옮겼다.
