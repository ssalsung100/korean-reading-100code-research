## 이번 개정의 판단

문체는 불필요한 정도·시점 반복과 계산 경로 설명을 줄이는 데서 개선했다. 실제 판단은 1번①에서 G와 S의 성질 귀속을 구별하게 하고, 3번②에서 어떤 지급이 부족 감소에 기여하는지를 학생에게 남기는 데서 개선했다. 2번의 정보 복원 판단은 그대로 보존했다.

3번⑤는 A 한 사람의 소득 미달만 확인해도 풀린다. 이 풀이를 인정하며, 정답 선택만으로 최소 재원 산출 이론까지 이해했다고 평가하지 않는다. 원리 연결은 기존 **IR-P063 ‘출력 표현이 보존하는 구별의 범위’**, **IR-P032 ‘정의된 지표에 맞춘 집계와 상태·개선 방향 해석’**을 계승한다. 새 100코드 경계 판정을 추가한 작업은 아니다.

비교 자료는 KICE 네 회차 여섯 문항이다. 기존 기준서의 추천과 실제 원문이 다른 부분은 원문을 우선했다. 새 외부 AI 호출·모델 비교·신규 blind 원장 작업·Git push는 하지 않았다. 개정01·연구 원본·동결 자료를 수정하지 않았고 G024/G370 hold를 유지한다.

현재 수준은 **자체 논리·표현 검토를 마친 독립 검토용 개정본**이다. 실제 학생의 반응이나 외부 독립 풀이로 평가원형 완성도가 입증된 것은 아니다. 이번 개정은 종료하고 정답을 가린 독립 풀이·비판 단계로 넘기는 것이 다음 순서다.
