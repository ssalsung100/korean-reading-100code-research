# 다음 소재의 집필 입력 카드

아래 카드를 새 소재에 복사해 채운다. 빈칸을 전문 용어로 메우는 대신 **어떤 정보를 선택하고 왜 연결할지** 결정한다. [실행 기준](11_지문집필_실행기준_v0_1.md)과 함께 사용하며 문항 카드는 본문 검토 뒤에 연다. PA-C나 IR-P를 먼저 정해 넣는 필수 칸은 없다.

## A. 지문 구성 카드 — 빈 양식

```text
작업 ID / 작성·수정일:
대상 독자와 이미 배운 교과 개념:
교과 근거 문서·위치 / 이번에 직접 확인한 범위:

설명 대상(용어 묶음이 아닌 현상·제도·판단):
중심 질문 또는 공통 개념의 복수 질문:
독자가 읽기 전에는 구별하지 못하지만 읽은 뒤 설명할 관계:
이번 글에서 다루지 않을 인접 주제와 이유:

사실·관계 자료:
  F-ID / 주장 / 출처·위치 / 직접 확인한 범위
  상태: 학술 사실 / 자체 유도 / 창작 가정 / 미확인
  성립 조건: 대상·단위·분모·시점·기준 소유자
  반례·경계 / 모형 밖으로 확대하면 안 되는 결론

구성 대안(탐색이 필요할 때):
  안별 설명 목적 / 필요한 사실 / 정보 관계 / 장점 / 포기할 이해
선택한 안 / 선택 이유 / 연구자 취향·미검증 판단:

문단 카드(실제 필요한 수만큼):
  P-ID / 들어올 때 가진 정보 / 새로 제공하는 정보
  왜 여기서 필요한가 / 다음에 어디서 재사용하는가
  삭제 시 손실: 전제·목적·구체화·범위·없음
  이동 가능한가 / 다른 배열에 필요한 보완

관계 목록:
  R-ID / 출발 정보 위치→쓰이는 위치 / 정확히 전달되는 내용
  관계 성격: 필수 전제·선택 이유·구체화·병렬 가지·결합
  유지되는 것 / 달라지는 것 / 적용 범위
  방향·단조성이 중요하면 그 성립 구간
  인문·예술이라면 주장자·공통 기준·비판 표적

사례·정의·조건·수식·도식:
  E-ID / 역할 / 고정할 것·바꿀 것 / 없앨 때 손실
  본문에 제시 / 집필 검증에만 사용 / 제외
  원자료와 가상 자료 구별 / 도식·표 완전성

본문 집필:
  학생에게 읽힐 본문만 별도 구획으로 저장
  본문의 중심 답 / 새 상황에서 추가로 적용할 수 있는 관계
  아직 알 수 없는 것 / 본문이 실제로 설명하지 않은 것

검토 기록:
  사실 확인 / 산식·논증 / 삭제·이동 / 반복 / 독자 이해
  각 항목의 증거와 미검증 범위
  기존 글·비교 기출 대비 개선 / 약화 / 목적이 다른 부분

문항 전달 가능 관계 ID:
현재 단계: 자료 조사 / 구성 선택 / 문항 없는 초안 / 설명 검토 후 전달
다음 작업의 구체 파일·문단 / 노출·유보 상태:
```

미확인인 핵심 사실은 빈칸으로 숨기지 않는다. 그 사실을 전제로 한 본문을 확정하기 전에 자료 조사로 되돌아간다. 교과 지도는 연결 후보를 찾는 자료이며 심화 관계의 학술 근거를 대신하지 않는다.

## B. 이번 시험 집필의 채워진 카드

**작업:** 빈곤 B안, [지역의 빈곤과 전체의 빈곤](09_시험집필_새지문.md). 문항 없는 시제품까지 작성.

**독자와 출발:** 통합사회의 사회적 불평등·소득 재분배·공공 부조를 배운 독자. 기존 개념묶음 ECO-14와 교과서 검토 기록을 재사용한다. FGT 지표가 교과서에서 이미 학습된 개념이라고 가정하지 않는다.

**설명 질문:** 지역의 평균적인 부족이 크다는 것과 그 지역이 전체 부족에서 큰 몫을 차지한다는 것은 왜 다른가? 읽은 뒤 독자는 개인별 부족을 지역 평균으로, 지역 평균을 전체 값으로 합치는 과정에서 분모가 무엇을 하는지 설명해야 한다.

**제외:** 제곱빈곤갭지수·빈곤층 내부 분배 민감성·최적 지급·현실의 지역 물가 조정·표본 가중 설계. 앞의 두 항목은 기존본보다 약해진 부분이며 뒤 항목들은 이번 단순 모형의 범위 밖이다.

|자료 ID|필요한 관계|상태·근거|조건과 사용 위치|
|---|---|---|---|
|F1|부족비율 및 G의 정의|기관 방법론의 사실, [학술근거 W1](근거/빈곤측정_학술근거.md)|공통 양수 빈곤선·동일 기간·비음수 개인 소득, P2|
|F2|G=H×I|정의에서 자체 유도|빈곤층이 존재할 때 I 정의, P3|
|F3|G=Σ(Nₖ/N)Gₖ|기관 자료 W2 및 자체 대수|모든 주민을 빠짐없이 한 번씩 집계, 동일 개인 비중, P4|
|F4|같은 원자료의 구획 변경 불변|F3에서 유도|사람·소득·전체 인구가 그대로, P6|
|F5|동일 전체 값과 다른 지역 상태 양립|가상 반례로 확인|지역 비중 0.2/0.8, 지수쌍 0.4/0.15와 0.8/0.05, P7의 검증|

**대안 선택:** A는 변화에 대한 지표 반응, B는 규모 간 집계, C는 목표에 따른 배분이다. B는 기존본에서 짧게 지나간 분모를 설명의 핵심으로 바꾸어 집필 방법을 시험하기에 적합하다. B가 모든 목적에서 가장 좋은 구조라는 주장은 하지 않는다.

|문단|독자가 얻을 이해|실제 재사용·손실|
|---|---|---|
|P1|평균적 생활 부족과 전체에 대한 몫은 다른 관심|P5가 답하고 P7이 사용 범위를 회수; 삭제하면 목적 약화|
|P2|부족비율·비빈곤층 0·전체 인구 평균|P3/P4의 공통 전제; 분모 변경 시 뒤 집계도 달라짐|
|P3|지역 지수에 발생 범위와 빈곤층 평균 부족이 함께 담김|P7의 구성 식별 한계와 연결; P4의 필수 전제는 아님|
|P4|평균을 합으로 되돌려 전체 평균으로 결합|P5의 수치와 P6의 불변성 근거|
|P5|작은 고지수 지역보다 큰 저지수 지역의 기여가 클 수 있음|P1의 질문에 구체적 답; 없애면 공식의 함의가 추상적|
|P6|구획이 달라도 같은 사람의 비중을 보존|P4를 새 조작에 적용; 삭제해도 유도는 남음|
|P7|집계 일관성·지역 복원·지급 판단은 서로 다른 문제|설명의 사용 범위; 배분 효과까지 설명했다고 보지 않음|

**관계 기록:** R1=P2→P3(평균의 분모 변경), R2=P2→P4→P5(평균에서 합 복원 후 다른 규모로 집계), R3=P4→P6(같은 개인 자료의 구획 변경), R4=P4/P5→P7(집계 결과의 식별 범위). P3→P4의 필수 의존 화살표는 붙이지 않는다.

**사례 선택:** P3의 같은 G·다른 H/I는 지수 내부 구성 해석, P5의 갑/을은 지역 지수와 기여분의 순위 구별, P6의 분할은 인구 자료 보존 검사다. F5의 추가 수치쌍은 검산 자료에만 남긴다. 가상 지역은 실제 지역의 빈곤 통계가 아니다.

**수정·유보:** 빈곤율 용어를 명시했고 단순 평균의 불일치를 일반적 경우로 한정했다. 계산은 검증했으나 학생의 이해·읽기 부담은 확인하지 않았다. P3 사례의 압축과 P4~P6 반복 체감은 후속 검토 위치다. 검토 결과는 [기존본·새 글 비교](10_기존지문과_새지문비교.md)에 저장했다.

## C. 이후 문항 제작 입력 카드 — 설명 검토 뒤에 작성

```text
지문 파일·버전 / 본문 검토 기록:
평가할 이해(원리명 없이):
사용할 R-ID와 지문 위치:
본문에 명시한 결론 / 새로 요구할 결론:

새 상황의 입력:
  같은 것 / 바꾸는 것 / 추가 조건
  본문 모형에 들어오는 근거 / 본문 밖 지식의 필요 여부
코드명 없는 중간 추론:
  입력→적용 관계→중간 결과→판단
필수 결합 문단 / 대안의 짧은 풀이 경로:

이후 대조할 기존 IR-P 번호·원명·사용 수준:
  해당하는 실제 연산 / 적용되지 않는 경계
  번호가 비슷해도 합치지 말아야 할 다른 연산

발문·보기·선지 초안:
각 선지 정오의 충분한 근거:
매력적인 오답의 정확한 오류(단순 부정어 바꾸기와 구별):
정답 유일성·경계값·가정 누락 검증:
본문에 새 정보가 필요해졌는가:
  본문 자체에도 필요 / 보기에서만 필요 / 문항 포기

설명문 품질의 재검토 / 문항 검증 결과를 별도로 기록:
연구자 의견·반영 위치 / 아직 해결하지 못한 점:
```

이번에는 C카드를 채워 문항을 만들지 않는다. 기존 IR-P032/063의 연결 가능성은 [연결 문서](12_100코드와_연결.md)의 관계 표까지만 기록했다. 실제 선지가 생기기 전에는 그 문항의 주·보조 코드를 확정할 수 없다.

## 새 소재로 옮길 때 바꿔야 하는 칸

과학·기술 소재라면 F표에 입력·상태 변화·관측 신호·측정 대상을 나누고, 단계 사이에 같은 말로 다른 양을 부르는 곳이 없는지 확인한다. PA11/PA16/PA21이 비교 근거다. 항상 가중 평균이나 역산을 넣으라는 지시가 아니다.

사회·제도 소재라면 규칙의 적용 대상·효과·시점·예외가 무엇을 바꾸는지 적는다. PA10/PA13/PA22가 근거다. 다른 법 영역을 하나의 규칙으로 합치지 않는다.

인문·예술 소재라면 누가 어떤 기준으로 무엇을 설명·비판하는지 적고, 공통으로 인정한 전제와 다른 적용을 나눈다. PA06/PA09/PA19가 근거다. 모든 입장을 동일한 질문에 대한 단순 찬반으로 만들지 않는다.

어느 경우든 아직 확인하지 않은 새 학문적 사실은 이번 방법론의 성공 사례로 세지 않는다. 카드가 채워졌다는 사실보다 실제 본문에서 관계가 작동하는지를 후속 검토한다.
