# LEET 언어이해 텍스트 전수 검증 v1

## 판정 원칙

- 원본에 없는 문장을 추정하여 정본 Markdown에 넣지 않는다.
- `pass_direct_*`는 같은 원본에서 추출기를 다시 실행한 결과와 Markdown 본문이 문자 단위로 일치한다는 뜻이다.
- `layout_pending`은 본문 문자는 직접 추출되었지만 HWP의 자동 문항 번호·표·그림 배치를 별도로 대조해야 한다는 뜻이다.
- `image_only_no_canonical_text`는 페이지 이미지만 정본이며 OCR 문장은 아직 정본이 아니라는 뜻이다.
- 정답표는 `normalized_answers.json`과 원본 정답표를 기준으로 관리한다.

## 현재 사용 금지 범위

- 이미지형 PDF의 빈 Markdown을 본문 데이터로 사용하지 않는다.
- OCR 초안은 원문 페이지 대조 전에는 지문·문항 분석 데이터에 합치지 않는다.
- HWP의 `<표>`와 `<그림>` 위치는 별도 자산과 매핑되기 전까지 해당 문항의 완전한 본문으로 간주하지 않는다.
