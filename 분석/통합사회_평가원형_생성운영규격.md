# 통합사회 평가원형 지문·문항 생성 운영 규격

> 50개 개념 묶음을 실제 지문과 4문항 세트로 바꾸기 위한 구조 레시피다. 레시피는 문장 표현이 아니라 관계의 순서만 규정한다.

## 길이 기준

- 로컬 평가원 독서 163세트의 지문 공백 제외 글자 수: 평균 1,198자, 중앙값 1,120자.
- 그중 사회 영역 4문항 세트 16개의 평균: 1,073자, 중앙값 1,106자, 범위 892~1,230자.
- 본 프로젝트의 기본값: **공백 제외 1,050~1,250자, 4~6문단**. 1,050자는 가급적 지키는 최소선이다.

## 지문 구조 레시피 12개

### R01｜개념 정의–분류형 (중)

- 논리 코드: 개념분석 + 분류 + 부분관계 + 비교대상
- 적합 개념: 문화, 기본권 유형, 금융 자산, 자원 유형
- 문단 기능:
  1. 상위 개념과 분류 목적 제시
  2. 분류 기준과 하위 유형 정의
  3. 경계 사례 또는 중첩 가능성 설명
  4. 새 사례에 적용할 판정 기준 정리
- 적합 문항: 내용 일치, 분류 기준, 사례 적용, 경계 사례
- 실패 조건: 유형 이름만 열거하거나 하나의 대상을 서로 다른 기준으로 중복 분류하면서 기준 전환을 설명하지 않음

### R02｜이론 비교–대조형 (중상)

- 논리 코드: 비교대상 + 저울질 + 원칙/예외 + 이항대립
- 적합 개념: 행복론, 환경 윤리, 정의론, 국제 관계론
- 문단 기능:
  1. 공통 문제와 비교축 제시
  2. 이론 A의 전제·판정 기준
  3. 이론 B의 전제·판정 기준
  4. 공통점·차이점과 적용 결과 정리
- 적합 문항: 공통점/차이점, 입장 대응, 보기 적용, 새 입장의 비판
- 실패 조건: 두 이론을 병렬 요약할 뿐 동일한 비교축에서 판단 결과가 왜 달라지는지 보여 주지 않음

### R03｜원리–과정–결과형 (중상)

- 논리 코드: 부분관계 + 함수/과정 + 인과관계 + 조건문
- 적합 개념: 시장 균형, 환율, 인구 변천, 도시 구조
- 문단 기능:
  1. 현상과 핵심 변수 정의
  2. 변수 사이 작동 과정
  3. 조건 변화에 따른 결과 분기
  4. 한계 또는 관찰 자료 해석
- 적합 문항: 과정 순서, 인과 방향, 변수 변화, 자료 추론
- 실패 조건: 원인과 결과 사이의 매개 단계가 생략되어 단순 상관관계를 인과로 단정함

### R04｜문제–원인–해결형 (중)

- 논리 코드: 문제해결도식 + 인과관계 + 보충도식 + 부분관계
- 적합 개념: 환경 문제, 정보 격차, 도시 문제, 인구 문제
- 문단 기능:
  1. 문제의 양상과 판단 지표
  2. 직접·구조적 원인
  3. 기존 해결책과 작동 원리
  4. 기존책의 한계와 보완책
- 적합 문항: 원인/결과, 해결책의 기능, 한계, 대안 적용
- 실패 조건: 한계가 제시된 정책과 보완책이 해결하는 원인이 서로 대응하지 않음

### R05｜원칙–예외–경계형 (상)

- 논리 코드: 원칙/예외 + 조건문 + 필요조건 + 반증사례
- 적합 개념: 기본권 제한, 시민 불복종, 문화 상대주의, 정책 정당화
- 문단 기능:
  1. 일반 원칙과 정당화 근거
  2. 원칙 적용의 필요조건
  3. 예외가 허용되는 추가 조건
  4. 경계 사례로 범위 제한
- 적합 문항: 필요조건, 예외 판정, 반례, 사례의 적법성
- 실패 조건: 예외가 원칙을 제한하는 것이 아니라 원칙과 무관한 별도 사실로 제시됨

### R06｜제도–절차–적용형 (중상)

- 논리 코드: 부분관계 + 조건문 + 원칙/예외 + 문제해결도식
- 적합 개념: 기본권 구제, 환경 영향 평가, 재정·통화 정책, 인구 정책
- 문단 기능:
  1. 제도의 목적과 대상
  2. 구성 요소 또는 절차
  3. 적용 요건과 효과
  4. 다른 제도와의 구별 또는 한계
- 적합 문항: 절차 순서, 적용 요건, 제도 비교, 사례 해결
- 실패 조건: 제도의 목적·요건·효과가 뒤섞여 어떤 조건에서 어떤 결과가 생기는지 불명확함

### R07｜역사적 전개–변형형 (중상)

- 논리 코드: 시간적 관점 + 인과관계 + 보충도식 + 비교대상
- 적합 개념: 인권 확대, 자본주의 전개, 산업화·도시화, 분단과 평화
- 문단 기능:
  1. 초기 제도·질서와 한계
  2. 변화를 촉발한 조건
  3. 새 제도의 형성과 이전 단계의 수정
  4. 현재적 쟁점과 지속·변화 요소
- 적합 문항: 시기별 특징, 변화 원인, 지속/단절, 가상 역사 적용
- 실패 조건: 연대기 나열에 그치고 이전 단계의 어떤 한계를 다음 단계가 수정했는지 드러나지 않음

### R08｜자료 모형–해석형 (상)

- 논리 코드: 함수/과정 + 조건문 + 비교대상 + 반증사례
- 적합 개념: 기후 그래프, 불평등 지표, 금융 수익·위험, 인구 지표
- 문단 기능:
  1. 지표·모형의 측정 대상
  2. 축·변수·산출 방식
  3. 수치 변화가 뜻하는 것과 뜻하지 않는 것
  4. 복수 자료 결합 시 추론 규칙
- 적합 문항: 자료 판독, 지표 한계, 수치 계산, 복합 자료 추론
- 실패 조건: 자료에 없는 인과나 절대량을 비율 자료만으로 추론하도록 요구함

### R09｜경쟁 가설–판별형 (상)

- 논리 코드: 경쟁가설 + 반증사례 + 조건문 + 저울질
- 적합 개념: 정책 효과, 문화 변동 원인, 도시 문제 원인, 시장 실패
- 문단 기능:
  1. 동일 현상에 대한 가설 A·B
  2. 각 가설의 예측
  3. 가설을 구분할 판별 자료
  4. 자료 결과에 따른 채택·수정 범위
- 적합 문항: 가설 예측, 판별 자료, 반증, 추가 실험
- 실패 조건: 두 가설이 같은 결과를 예측하여 제시된 자료로는 판별할 수 없는데도 하나를 정답으로 확정함

### R10｜다층 주체–거버넌스형 (중상)

- 논리 코드: 부분관계 + 문제해결도식 + 원칙/예외 + 보충도식
- 적합 개념: 기후 거버넌스, 국제 평화, 다문화 정책, 복지 정책
- 문단 기능:
  1. 공동 문제와 단독 해결의 한계
  2. 국제·국가·지방·시장·시민의 권한
  3. 주체 간 조정 기제
  4. 책임 공백·무임승차와 보완
- 적합 문항: 주체별 역할, 권한 비교, 조정 실패, 협력안 적용
- 실패 조건: 여러 주체를 열거하지만 권한·정보·유인 중 무엇이 달라 역할이 구분되는지 설명하지 않음

### R11｜조건–문턱–역전형 (상)

- 논리 코드: 조건문 + 필요조건 + 필요충분조건 + 반증사례
- 적합 개념: 합리적 선택, 재해 위험, 정책 귀착, 탄력성
- 문단 기능:
  1. 판단 변수와 기본 관계
  2. 결과가 바뀌는 문턱 조건
  3. 문턱 전후의 결과 비교
  4. 충분하지 않은 조건 또는 역전 사례
- 적합 문항: 조건 판정, 문턱 계산, 대우 추론, 역전 사례
- 실패 조건: 필요조건을 충분조건처럼 쓰거나 다른 조건이 고정되지 않았는데 결과 방향을 확정함

### R12｜영역 융합–전이형 (상)

- 논리 코드: 통합적 관점 + 인과관계 + 저울질 + 문제해결도식 + 원칙/예외
- 적합 개념: 기후·경제·정치, 인구·노동·복지, 기술·인권·윤리, 세계화·공정성
- 문단 기능:
  1. 공동 현상과 영역별 질문 구분
  2. 영역 A의 설명 원리
  3. 영역 B의 평가·제도 원리
  4. 두 원리의 충돌·보완과 통합 판단
- 적합 문항: 관점 구분, 영역 간 연결, 정책 평가, 새 사례 전이
- 실패 조건: 서로 다른 영역의 개념을 한 문단에 병치할 뿐 한 영역의 원인이 다른 영역의 판단 조건으로 어떻게 이어지는지 없음

## 4문항 기본 규격

### 1번｜내용 이해·구조 파악 (하~중)

- 허용 유형: 핵심 내용 일치, 문단 기능, 개념 정의, 전개 방식
- 금지: 문장 한 구절만 찾아 그대로 대조하면 끝나는 사소한 세부 정보

### 2번｜관계·조건 추론 (중)

- 허용 유형: 인과 방향, 필요·충분 조건, 비교축, 과정 순서, 원칙·예외
- 금지: 본문에 없는 배경지식을 알아야만 정답을 고를 수 있는 문항

### 3번｜<보기> 사례 적용 (중상)

- 허용 유형: 새 사례 판정, 제도 적용, 이론 입장, 가설 예측
- 금지: 보기의 고유명사만 본문의 같은 단어와 연결하는 표면 대응

### 4번｜반례·자료·복합 추론 (상)

- 허용 유형: 경계 사례, 조건 변화, 복수 자료, 반증, 정책 부작용
- 금지: 정답을 위해 두 번 이상 임의 가정을 추가하거나 선지 간 정보량 차이로 답이 드러나는 문항

## 변형 규칙

- 네 기능은 유지하되 지문 구조에 따라 1·2번 또는 3·4번의 순서를 바꿀 수 있다.
- 자료가 없는 지문은 4번을 반례·조건 변화형으로 대체한다.
- 어휘 문항은 만들지 않는다.
- 네 문항이 같은 개념만 반복해서 묻지 않도록 중심 개념, 관계, 적용, 경계의 네 층을 나눈다.
- 정답 배열은 세트 간 순환시키고 한 세트에서 동일 번호를 세 번 이상 쓰지 않는다.
