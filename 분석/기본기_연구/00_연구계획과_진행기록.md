# 평가원 문체·100코드 기본기 연구

기준일: 2026-09-06. 사용자 지시에 따라 후속 경제 세트 제작에 앞서 문체와 코드의 이해를 보강한다. 이 연구는 모델의 가중치를 훈련하는 작업이 아니라, 다음 대화에서도 원문 근거와 함께 재사용할 수 있는 분석 문서·사례 데이터 구축이다.

## 현재 실행 — 2026-09-08 재개

**최신 요청 실행:** [독립 연구04 — 비판의 표적과 증거 판별](독립연구_04_절차와_진행기록.md)을 시작했다. 연구03의 완료된12사례를 보존하고, 새 독립 지문12개(M~X)를 blind → 공식답 → 독립 코드 → SDSS 순서로 처리한다. #63/#36/#62/#65/#73 및 C074_075의 반례·불일치를 우선한다. 아래 연구03 설명은 이전 완료 지점으로 읽는다.

현재 최우선 작업은 [독립 연구 03: 증거 평가와 설명 경쟁](독립연구_03_절차와_진행기록.md)이다. **최초 풀이 저장 → 공식 답 확인 → 코드 없는 논리의 재검토 → 독립 코드·경쟁 코드 판정 저장 → SDSS 태그 공개 → 귀납·반례 탐색** 순서로 수행한다. 기존 해설과 답을 본 사례를 블라인드 검증으로 소급하지 않는다.

A~L 12문항·12개 독립 지문의 단계별 기록 36개를 저장했다. 재개 회차에서 새로 푼 것은 G~L 6문항이다. 최초 답은 모두 정본 공식 답과 일치하나 A는 지문 선행 노출로 별도 집계한다. [증거와 경쟁 회차 보고서](코드심층_03_독립풀이_증거와경쟁.md)에 공통 구조·시험별 구현·오답 변형·두 차례 기준 수정 이력을 기록했다. 사이트 연결은 9건, J~L은 미연결 보충 3건이다. 코드 주 순위의 불일치와 엄격한 상반 예측 판별형 평가원 표본 부족은 미해결 상태로 보존했다. 연구 전체 완료를 의미하지 않는다.

사용자는 실질적으로 같은 코드는 통합해도 된다고 허용했다. **#74/#75를 잠정 통합군**으로 연구하고, 원본 번호·태그·최초 판정은 보존한다. [코드군 통합 가설](../../data/기본기_연구/코드군_통합가설_v1.json)에 결정과 재분할 조건을 남겼다. 앞으로는 번호 차이를 전제로 경계를 만들어 내지 않는다.

기존 01·02 사례 보고서와 JSONL은 저장되어 있으나, 최초 풀이가 답·태그보다 먼저 기록된 독립 실험과는 구분한다. 문체 보고서는 평가원 표본의 근거 대조를 보강하는 단계이다. 기존 진행 보고에서 KICE 후보 202개를 정본 연결 수로 표현한 부분은 정정한다. v2 인덱스의 실제 KICE 연결은 153개(텍스트 선지 완비 149, 시각·선지 재검토 4), 미연결 49개다. LEET 연결 603개, MEET 연결 337개와 함께 총 연결 1,093개이며, 의미 검증 완료 수를 뜻하지 않는다.

## 먼저 보강할 결함

1. 기존 `전수판독` 문서는 100개 코드 항목을 다루지만, 여러 항목은 대표 문항 1개 수준이다. 코드 항목의 포괄성과 해당 코드 후보 전수 판독은 다르다.
2. 기존 후보 연결 스크립트는 MEET의 과거 raw JSONL/OCR 상태를 참조한다. 현재 검수 완료 정본을 새 연구용 파생 인덱스에 연결한다.
3. 동일 지문의 여러 문항을 독립 사례 여러 개로 세면 근거 다양성이 부풀려진다. 문항 수와 독립 지문 수를 함께 기록한다.
4. 사이트에 붙은 태그와 프로젝트에서 해석한 주 풀이 코드를 각각 보존한다. 동일 검색 결과가 나오는 코드·별칭을 독립 증거로 중복 계산하지 않는다.
5. 통계적 표현 빈도에서 문체 금지 규칙을 곧바로 도출하지 않는다. 표현의 기능과 실제 반례를 함께 확인한다.

## 코드 비교의 공통 질문

1. 이 관계를 지문에서 어디서 정의하고, 문항은 어디에서 다시 쓰는가?
2. 같은 코드의 사례들에 공통으로 남는 최소 관계는 무엇인가?
3. 소재·표상·부정 발문·정보 거리·고정 조건 중 무엇이 달라지는가?
4. 가까운 코드로 설명하면 어떤 판단 단계가 빠지는가?
5. 사이트 태그는 지문 전체, 문항 전체, 특정 선지 중 어느 범위에서 설명력이 있는가?
6. 원문에서 확인한 사실과 연구자가 권장하는 분석 규칙은 어디서 구분되는가?
