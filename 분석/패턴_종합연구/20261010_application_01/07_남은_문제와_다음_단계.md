# 남은 오류·검증 필요 사항·다음 단계

## 이번에 바로잡은 범위

발견용 12지문·39문항에서 추출한 기존 43장면을 모두 재검토했다. 기출 원문은 pilot가 연결한 로컬 발견용 전사로 읽었고, CA와 GL의 보충 그림도 확인했다. 기존 풀이 원장은 해당 장면·문항의 record_id로 한정해 대조했다. 43장면의 선지 63개와 추가 정답 장면 3개를 합친 66개 선지 연결을 새 파일에 저장했다. 같은 선지를 다시 읽은 횟수나 문항 전체 선지 수를 이 숫자로 표현하지 않는다.

- E004·E022 등에서 내용 적절성/방법 적합성과 정답 선택을 분리했다. GK①처럼 사실이지만 요구된 근거로는 불충분한 경우, AQP①처럼 일반적 진위를 판단하는 대신 본문의 평가 근거 유무를 묻는 경우도 구별했다.
- 원 인용이 다른 선지의 근거였던 E001·E002·E008·E014·E030·E031·E032는 해당 최초 풀이의 중간 추론으로 연결했다. 잘못된 인용을 보존하고 교정 근거를 별도 저장했다. 나머지 복수 선지 장면도 부족한 부분을 보충했다.
- P07의 명분/실태 경계는 E032/AJP①, S01의 약함/없음 경계는 E014/BK②에 연결했다. AJP 본문에 1950년대 시설 수용에서 1960년대 노동 동원으로의 실제 변화가 있다는 점은 유지한다. 그 변화가 ①의 ‘갱생 중심→격리 중심’을 증명하는 것은 아니다.
- AA①·AH④·AJP③의 기존 정답 풀이를 E044~E046으로 추가 추출했다. 39문항 모두 적어도 한 정답 결정 이벤트와 연결된다. 모든 원자 추론을 전수 추출했다는 뜻은 아니다.
- 13개 후보의 정보 구조·선지 변형·학생 행동·교육 설계·출제 조건·비적용 조건을 분리했다. P02와 P04를 수업 시연으로, P04를 완전 시제품으로 구현했다.

## 활용 가능성 시험에서의 판단

P02는 두 질문을 분리하고 각 질문의 근거를 비교하는 방식으로 7분 시연을 구성할 수 있었다. 명시적 연결이 있을 때에는 분리를 기계적으로 적용하지 않는 대조도 넣었다. 아직 새 문제를 학생이 풀어 내는지 확인한 것은 아니다.

P04는 명시 요건 확인에서 시작하여 기전의 전제, 한 경로와 전체 결과의 차이로 확장하는 7분 30초 시연을 구성했다. 완전 시제품에서는 두 경로를 갖춘 체계와 2개 문항을 제작했고, 본문·보기의 조건으로 정답 ③·④를 각각 확정할 수 있었다. 자체 검토에서 다른 기록의 검사 상태가 미지정된 문제를 발견하여 새 기록별 미통과 조건을 명시했다. 기록 수가 늘어도 독립성이 없으면 채택이 바뀌지 않는지, 남은 경로가 사라지면 채택이 바뀌는지도 점검했다.

이 결과로 말할 수 있는 것은 두 후보를 설명과 설계로 구체화할 수 있었다는 점이다. 패턴 학습의 효과나 평가원 문항을 안정적으로 생성하는 일반 규칙이 검증되었다는 결론은 내리지 않는다.

## 다음 단계 제안

1. 현재 시제품을 독립 독자가 본문·보기만으로 풀고 각 선지의 근거를 적게 한다. 정답 불일치뿐 아니라 해설의 조건보다 더 적은 정보로 풀리는지도 확인한다. 이번 실행에서 외부 검토자나 다른 모델에게 보내지는 않았다.
2. 소규모 수업에서 같은 정답이라도 근거 찾기, 조건의 필요/충분 구별, 대체 경로 확인, 발문의 긍정/부정 반영을 따로 기록한다. 정답률만으로 전이 성공을 판정하지 않는다.
3. P02도 완전 지문·문항으로 구현할 경우, 두 축이 분리되는 사례와 명시적으로 연결되는 사례를 함께 설계한다. 본문 규정이 바뀌면 어떤 선지 판단이 바뀌어야 하는지 미리 고정한다.
4. 검증용 6세트 적용은 별도 요청 뒤 진행한다. 후보 조건·비적용 조건·분할 기준을 먼저 고정하고, 원 조건의 예측과 사후 수정 결과를 함께 보존한다.
5. 전수 적용·기존 코드 체계 수정은 검증 결과와 별도 범위 합의가 생긴 뒤 검토한다. 이번에는 수행하지 않았다.

## 보존과 실행 범위

이번 추가 지시의 ‘기존 파일·원장·코드 체계 수정 금지’를 우선하여 신규 결과는 이 실행 폴더에만 저장했다. 기존 Astra queue·processed·CURRENT·prepared manifest에 append하거나 동기화하지 않았다. 신규 blind passage group을 시작하지 않았으므로 기존 연속 연구의 group 완료·Luna 동기화 절차를 이번 작업 완료로 대체하지 않는다.

G024/G370 hold는 유지했다. 전수 적용, 검증용 본문 분석, 다른 모델 자동 호출, Git push는 하지 않았다. 보존 대조는 [preservation_report.json](preservation_report.json), 인용·좌표·답 연결과 창작 규칙 점검은 [validation_report.json](validation_report.json)을 따른다.
