요청은 GPT-6 Astra high이다. 이 세션은 시스템상 GPT-6 기반 Codex이며 정확한 API 모델 ID·reasoning effort를 독립 확인하지 못했다. 다른 모델·서브에이전트·fresh TUI를 호출하지 않았고 설정 준수를 검증했다고 기록하지 않는다. 이 실행의 `run_metadata.json`에 요청값과 확인값을 분리했다.

## G095 노출 이력

pilot의 `pilot_review.md`는 표본 고정 뒤 2017 수능 18번(NM)의 정답·코드 요약이 우발 노출되었다고 기록한다. Sol 1단계는 그 이력을 알고 다섯 문항을 엄격 미노출 성과에서 제외했으며 해당 세션에서 정답값·기존 후보 정의는 읽지 않았다고 보고했다. 외부 적용 역시 과거 노출의 범위·영향을 확인하지 못했다고 남겼다. 작업 C는 기존 원장과 답 대조까지 사용했으므로 다섯 문항을 교육·논리 근거로 활용할 수 있지만 새로운 blind 검증 근거로 만들 수 없다.

## 원문 충실도

G350은 Sol에서 전사 표만 읽었고 강조구를 문맥상 추정했다. 외부 적용은 공식 HWP 렌더 인쇄 2·3쪽과 보강 자료로 강조구·기호·열 대응을 확인했다고 기록했다. 작업 C는 그 확인 결과와 로컬 전사를 승계했으며 원본 이미지 신규 대조를 수행하지 않았다. RX 표는 이와 달리 외부 적용에서도 보강표의 원스캔 독립 재검수가 남아 있다.

발견용 KICE 자료 중에는 편집 HWPX에 연결된 전사가 있고 LEET 2011은 공식 HWP 추출 텍스트 수준이다. MEET의 기존 검수 정본 연결도 신규 직접 검수로 바꾸지 않는다. GL④ 수식의 중복 첨자 문제는 미해결이며 GL①의 기전 선후 근거와 분리했다. CA 그림의 해석은 application 검수와 기존 판단을 승계했다. 이번 문자 좌표 검사는 전사의 내부 일치이지 원 배포 지면과의 의미·조판 일치 인증이 아니다.

이 후속 항목은 이번 실행을 형식적 계획으로 대체하는 것이 아니다. 현재 표본의 대조·사례 분석·수업·출제 명세는 작성했고, 표본 밖 반복과 학생 효과만 미검증으로 남겼다. 전체 코퍼스 재분류는 별도의 작업 범위로 둔다.

## 정답과 자동 검증의 역할

기존 답 대조는 문항 식별·발문 극성·번호 연결의 보조 자료다. Sol·외부 적용의 선택을 새 공식답 확인 결과로 소급하지 않는다. 정답 일치율이나 후보 개수로 분석 깊이를 평가하지 않았다.

자동 검사는 입력 파일 보존, 정확한 인용과 문자 구간, case·후보·근거 ID 연결, 스키마 예시 형식, 국소 설계의 논리 상태를 확인한다. 이러한 검사는 의미의 충분성, 패턴의 일반성, 실제 학생 사고, 교육 효과를 보증하지 않는다. 별도 사람이나 다른 모델의 의미 검토는 수행하지 않았다.

기존 CURRENT의 497 groups·1,663 completed cases와 G024/G370의 8 hold는 이번 작업 C의 범위 밖이다. 이 종합 완료를 전체 원 연구의 미완료 사례 해소로 기록하지 않는다. 공용 raw queue·processed·CURRENT 및 동결 폴더를 수정하지 않았다.
