# PA18 — 결측치와 이상치

자료: 2024학년도 수능 8~11. [전사](../근거/지문만/PA18.md).

## 지문 자체 분석

질문은 **데이터의 특징을 왜곡하는 값의 부재·극단값을 어떤 방식으로 다룰 수 있는가**이다. 독자는 비정상 데이터는 버린다는 단순 관점에서 대체, 대표값 선택, 정상치 합의에 의한 모형 찾기라는 다른 조작을 구별한다.

|문단|정보·역할|연결|
|---|---|---|
|P1|정확한 특징 표현의 목적, 두 문제|공통 설명 대상과 가지 설정|
|P2|결측의 정의, 평균·중앙·최빈, 자료 종류별 대체|값이 없다는 문제에 다른 값 채우기; 중앙값 정의는 P3에서도 재사용|
|P3|이상치, 측정 오류와 정상 극단값, 연봉 대표값|이상치=오류의 동일시를 차단하고 표현 목적에 따른 중앙값 선택|
|P4|평면의 점·대표 직선·멀리 떨어진 점|P3의 극단값을 위치 자료로 확장; P5의 과제 준비|
|P5|무작위 두 점→후보→허용거리→정상치 수→문턱→최대 집합|이상치가 있어도 다수 자료가 지지하는 모형을 찾는 절차|

의존: P1→{P2,P3}, P2→P3[중앙값 정의], P3→P4[문제 확장], P4→P5[공간적 과제]. 결측 대체와 직선 선택은 하나의 연속 공정이 아니다.

삭제·이동: P2의 결측 대체 부분을 없애도 P4/P5는 거의 이해된다. 다만 중앙값 정의를 다른 곳에 남겨야 P3이 자족적이다. 이는 낮은 직접 의존성이 곧 결함이라는 주장에 반대한다. P4를 지우면 P5의 직선 L과 거리의 목표가 갑자기 등장한다. P3의 정상 연봉 예를 지우면 이상치를 모두 측정 실수로 오해하기 쉽다.

P5의 문턱값과 정확히 같은 수인 경우는 본문에 명시되지 않는다. 그 경계를 임의로 ‘이상’ 또는 ‘초과’로 완성하지 않는다. 또한 처음에 고른 점이 이상치라는 사실만으로 모든 기하 배치에서 후보가 반드시 탈락한다고 일반화하지 않는다. 본문은 마지막에 성공 가능성이 높다고 표현한다.

완성 체계는 정확성이라는 공통 목적 아래 두 문제 가지, 그중 이상치 가지의 점진적 구체화다. 문항 없이도 충분히 설명할 수 있는 구조이며 각 가지의 분량이 같아야 할 이유도 없다.

## 문항 연결 — 9·10번

9번 최초 선택 ①, 확신 높음. P2의 순위상 중앙 정의에서 극단의 크기 변화가 중앙값을 덜 흔든다는 성질을 추론하고 P3의 연봉에 적용한다. 중앙값을 구할 때 이상치를 삭제하는 것은 아니다. 짝수개라면 두 중앙의 평균이므로 항상 관측값 중 하나라는 주장도 틀린다.

10번 최초 선택 ⑤, 확신 높음. A는 무작위 두 점으로 후보를 만들므로 이상치를 먼저 제거했다고 볼 수 없다. 후보 주위의 정상치 집합은 알고리즘의 가정상 집합이지 참된 정상치만 보장된 집합이 아니다. B도 후보가 이상치를 지날 가능성을 배제하지 않는다. 절차에서 정한 이름과 실제 데이터 성질을 구별한다.

P5의 성공 가능성 설명을 모든 경우의 보장으로 바꾸면 ③ 같은 단정이 생긴다. 문항의 새 B 기법은 선택 기준을 바꾸었을 때 이상치의 영향이 어떻게 달라지는지 비교할 대상을 만든다. 본문의 A 절차는 문항이 없어도 ‘이상치를 어떻게 견디는가’에 답한다.
