# 평가원 경제 독서 100코드·문항 설계 기준서 v1

## 0. 정정 및 기준의 출처

이 문서에서 말하는 **코드**는 [sdss.kr의 「100개의 코드」](https://sdss.kr/code/100.html)에 수록된 사고 관계 코드만을 뜻한다. 해당 HTML과 100코드 체계는 이 프로젝트에서 새로 만든 것이 아니다. 페이지에는 `© 2025 yiwonjun`이라고 표시되어 있다.

앞서 프로젝트에서 사용한 `T01~T22`와 같은 표기는 평가원식 오답을 만들기 위해 임시로 정리한 **선지 변형 유형**이었다. 이는 100코드의 개정판이나 대체 체계가 아니다. 이를 정식 코드처럼 제시한 것은 부정확했으며, 앞으로 다음 세 층위를 분리한다.

| 층위 | 의미 | 예 |
|---|---|---|
| 지문 구조 코드 | 지문에 설계된 관계 | #46 인과관계, #19 보충도식 |
| 문항 풀이 코드 | 정답 판단에 실제로 필요한 관계 | #84 분수식, #90 경우의수 |
| 오답 변형 | 정선지의 어느 요소를 바꾸었는지 기록하는 제작 정보 | 분모·분자 교환, 시점 이동, 적용 범위 확대 |

오답 변형은 반드시 대응하는 100코드와 함께 기록하되, 새로운 코드 번호를 붙이지 않는다.

### 자료 사용상의 주의

- 코드 검색 결과는 [sdss.kr 코드 검색](https://sdss.kr/code/)에 수록된 제3자의 기출 분석이다. 평가원이 공식적으로 붙인 태그가 아니다.
- 사이트의 정답률에는 “정답률은 추정치입니다”라는 안내가 있으므로, 난도의 절대 기준으로 사용하지 않는다.
- 사이트에 코드가 비어 있는 문항이 있다. 빈칸은 `코드가 필요 없는 문항`이 아니라 `DB에 코드가 기재되지 않은 문항`으로 취급한다.
- 이 문서의 표에서 `사이트 기재`는 검색 결과를 옮긴 것이고, `프로젝트 재분석`은 로컬 평가원 원문과 문항을 100코드로 다시 분석한 것이다.

## 2. 경제 독서에서 우선 학습할 코드

### 4.4 세 지문에서 반복되는 평가원 경제 문항의 특징

1. **한 지문, 다중 풀이 코드**: 지문의 대표 코드 하나를 네 문항에 반복하지 않는다.
2. **변수의 적용 범위 전환**: 개별/전체, 단기/장기, 수준/변화량, 가능/필연을 이동한다.
3. **중간 매개 복원**: 금리→신용→수요→물가처럼 지문의 연쇄를 선지에서는 압축한다.
4. **경쟁 경로 선택**: 광고의 제한/촉진, 규제의 편익/비용처럼 반대 방향의 경로 중 조건에 맞는 것을 고른다.
5. **표상 전환**: 문장으로 정의한 관계를 표·수식·가상 사례에 옮긴다.
6. **정보 결손과 고난도의 구분**: 필수 전제는 지문이나 <보기>에 모두 있으며, 어려움은 정보의 거리와 범주 전환에서 만든다.

### 6.1 세트 내부 제약

- 네 문항의 **주 풀이 코드**는 서로 달라야 한다. 보조 코드의 중복은 허용한다.
- 네 문항 중 최소 세 문항은 `두 정보 결합`, `두 단계 이상`, `경쟁 경로 선택` 중 하나를 충족한다.
- 같은 문단의 같은 문장을 세 문항 이상의 핵심 근거로 재사용하지 않는다.
- 내용 일치형이 있더라도 정의·조건·범위 중 둘 이상을 결합한다.
- 적어도 한 문항은 지문의 마지막 문단이나 앞뒤 문단의 지연 회수를 사용한다.
- 최고난도 문항일수록 근거는 더 명확해야 한다. 찾고 조합하기 어렵게 만들되 근거 자체를 흐리게 하지 않는다.

### 7.1 매력적 오답의 품질 기준

- 선지의 70~90%는 지문과 공유하고, 핵심 관계 하나만 바꾼다.
- 한 오답의 핵심 오류는 원칙적으로 하나이다.
- 오답마다 `어느 글자 또는 구가 바뀌어 틀렸는지`를 표시할 수 있어야 한다.
- 정답보다 오답이 현저히 짧거나 추상적이지 않도록 정보량을 맞춘다.
- 절대어 자체가 아니라, 절대어가 #2 양상을 실제로 위반하기 때문에 틀리게 한다.
- 앞부분이 참이고 뒷부분이 거짓인 선지는 뒷부분의 오류가 #43·#46·#57·#86 등 특정 코드로 설명되어야 한다.
- 같은 문항의 네 오답이 모두 인과 방향만 뒤집는 식으로 단조롭게 구성되지 않게 한다.

## 8. 그래프·표 문항 기준

- 자료는 적어도 한 문항의 정답 판단에 **독점적 정보**를 제공한다.
- 자료 해석법은 지문이나 <보기>의 조건에서 복원할 수 있어야 한다.
- 수요·공급 그래프에서는 축, 곡선, 이동과 곡선 위 이동, 고정 조건을 명시한다.
- 비율 표에서는 분자·분모와 단위를 명시한다.
- 시계열 표에서는 정책 시행 시점과 효과 발생 시점의 차이를 명시한다.
- 집단 자료에서는 값이 적용되는 모집단을 명시한다.
- 계산은 코드 적용을 확인하는 수단이어야 하며, 복잡한 사칙연산 자체가 난도의 중심이 되어서는 안 된다.

## 9. 경제 지문·문항 생성 절차

1. **교과 개념 사다리 작성**: 통합사회 기초 개념→경제 심화 개념→적용 사례의 순서를 정한다.
2. **사실 지도 작성**: 정의, 변수, 고정 조건, 인과 경로, 경쟁 경로, 수치 관계를 기록한다.
3. **지문 코드 지도 작성**: 100코드 번호로 핵심 4~6개와 보조 코드를 정한다.
4. **문항 지도 선작성**: 네 문항의 기능과 주 풀이 코드를 겹치지 않게 배분한다.
5. **정보 충족표 작성**: 정답 판단에 필요한 모든 전제가 어느 문단·자료에 있는지 표시한다.
6. **지문 작성**: 코드명은 노출하지 않고 경제 주체·변수·기간·조건의 관계로 표백한다.
7. **정답 선지 작성**: 두 정보 결합 또는 한 단계 이상의 추론으로 재진술한다.
8. **오답 작성**: 각 오답에 하나의 변형과 대응 100코드를 기록한다.
9. **블라인드 재풀이**: 배경지식 없이 모든 선지를 지문만으로 판정한다.
10. **난도·품질 분리 평가**: 정보 충족도와 정답 유일성은 품질의 필수 조건으로, 정보 거리·경쟁 경로·표상 전환은 난도로 평가한다.

## 10. 완성 전 체크리스트

### 코드

- [ ] 모든 코드명이 sdss.kr 100코드의 번호·명칭과 일치한다.
- [ ] 지문 구조 코드와 문항 풀이 코드를 구분했다.
- [ ] 오답 변형에 새 코드 번호를 붙이지 않았다.
- [ ] 사이트 기재 코드와 프로젝트 재분석 코드를 구분했다.

### 문항

- [ ] 네 문항의 주 풀이 코드가 서로 다르다.
- [ ] 각 문항의 정답 근거와 중간 추론을 기록했다.
- [ ] 최소 세 문항이 2정보 결합·2단계 추론·경쟁 경로 중 하나를 사용한다.
- [ ] 최고난도 문항의 필수 전제가 모두 제공되어 있다.
- [ ] 시각 자료가 있다면 적어도 한 문항이 그 자료에 실질적으로 의존한다.

### 선지

- [ ] 각 오답의 변형 지점이 하나로 특정된다.
- [ ] 각 변형이 어느 100코드를 위반하는지 설명할 수 있다.
- [ ] 정답과 오답의 길이·구체성·공유 정보량이 지나치게 다르지 않다.
- [ ] 외부 경제 지식 때문에 지문과 다른 판단이 생기지 않는다.
- [ ] 가능/필연, 단기/장기, 개별/전체, 수준/변화량의 기준이 명확하다.

## 11. 현재 프로젝트에 적용할 우선 규칙

1. 향후 경제 세트의 메타데이터에는 반드시 `#번호 코드명`을 쓴다.
2. 기존 문서의 `잠재 코드`는 이 기준서의 100코드와 대조해 번호를 부여한다.
3. 오답의 주체·시점·범위·방향 변형은 `오답 변형` 필드로 옮기고 코드 목록에서는 제거한다.
4. 각 세트는 지문 대표 코드가 아니라 **문항별 주 풀이 코드**를 먼저 배분한다.
5. 사이트 검색 결과는 사례 확인에 사용하되, 태그 누락과 추정 정답률을 감안하여 로컬 원문 재분석을 병행한다.
6. 경제 지문의 난도는 정보 결손이 아니라 `#43 타변수통제 + #2 양상`, `#46 인과관계 + #57 분기점`, `#84 분수식 + #10 필요조건`처럼 코드가 경쟁하거나 결합하는 방식으로 높인다.
