# 통합사회 문항 이미지 완전판 전수판독

> 기존 파서에서 빠졌던 이미지를 복구해 전체 문항 이미지 원본을 다시 대조한 기록이다.

## 결과

- 전체 이미지: **622개**
- 이미지 포함 문항: **517개**
- 기존 판독 이관: **427개**
- 추가 복원·육안 판독: **195개**(접촉표 17장)
- 판독 상태: 622개 모두 원본 육안 판독 완료

## 추가 복원 범위

- 통합적 관점·행복·자연환경·문화
- 도시 내부 구조·지역 조사·정보 사회
- 인권·헌법·정의·불평등
- 경제 체제·시장·자산 관리·국제 무역
- 세계화·평화·분단·인구·자원·에너지·미래 사회

## 재사용

- 원본과 PNG는 `자료/통합사회_문항이미지_완전판/`에 보존했다.
- 문항 생성의 자료 유형·관계 구조 참고에는 사용할 수 있다. 외부 배포 시에는 원출판물 이용 권한을 별도로 확인해야 한다.
