# PA09 — 본질과 반본질주의

자료: 2014학년도 6월 B 17~20. [전사](../근거/지문만/PA09.md).

## 지문 자체 분석

중심 질문은 **분류와 의사소통에 필요한 공통 속성이 대상 안에 발견되는 것인가, 언어적 약정으로 구성되는 것인가**이다. 읽기 전에는 정의를 잘 만들면 본질을 발견했다고 생각하기 쉽다. 글은 필요충분한 분류와 독립적으로 존재하는 본질을 분리한다.

|문단|제공 정보·기능|도입과 재사용|
|---|---|---|
|P1|본질의 필요충분 기준, 까투리 정의의 문제|겉으로 완벽한 정의가 존재론적 발견인지 의심하게 함|
|P2|개체의 동일 종류 판단·소통이라는 공통 과제, 두 입장의 답|P1의 문제를 언어 약정/실재 본질의 대립으로 명료화|
|P3|본질과 정의의 층위 연결, 이성적 동물과 사회적 동물의 반례|P1의 ‘모든/오직’을 각기 실패시키는 사례로 필요조건·충분조건을 실제 작동시킴|
|P4|탐구의 미성공을 무지 아닌 가정 오류로 해석하는 반본질주의|P3의 사례를 철학적 탐구 평가로 확장. 입장 귀속 유지|

그래프: P1→P2[논점], P1→P3[검사 기준], P2+P3→P4[입장과 근거 연결]. P3의 갓난아이/개미는 아무 반례 둘이 아니라 서로 다른 방향의 포함 실패다.

삭제·이동: P1의 까투리를 삭제해도 P2의 입장 대조는 성립하지만 정확한 정의조차 발견을 보장하지 않는 첫 문제를 놓친다. P3 삭제 시 반본질주의가 실제 어떤 정의를 어떻게 비판하는지 빈다. P2/P3 순서 교환은 가능하되 반례가 어느 주장을 지지하는지의 귀속이 늦어진다. P4의 탐구 실패를 본질 부재의 확정 증명으로 바꾸면 원문의 ‘힘을 실어 줌’과 논자의 주장을 과장한다.

문항을 없애도 사례의 비대칭은 중요하다. 예시는 이해를 쉽게 하는 부연만이 아니라 정의의 적용 범위를 시험한다. 완성 체계: 분류 기준의 완전성/본질의 존재/정의의 약정성이라는 세 층. 어려운 용어보다 이 층 사이의 잘못된 동일시를 끊는 데 설명의 깊이가 있다.

## 문항 연결 — 17·19번

17번 최초 선택 ④, 확신 높음. P2의 언어적 의미 부여를 분류 가능성과 연결한다. 공통 속성이라는 기능의 필요를 부정하는 것이 아니라 그것의 실재 방식에 반대하는 입장이다.

19번 최초 선택 ④, 확신 높음. 금의 정의 변화는 본질주의에는 더 정확한 발견, 반본질주의에는 정의의 약정성을 지지하는 자료가 된다. ‘사바컴’이 쓰이지 않은 이유를 근원 속성의 미발견으로 해석하는 것은 반본질주의와 충돌한다. P2의 입장 차이와 P4의 탐구 해석을 새로운 사례에 적용한다.

같은 사례가 두 이론에 들어갈 때 서로 다른 의미를 얻으므로, ‘새 사실→한 입장 승리’로 바로 가는 문제가 아니다. 문항 없이도 P2의 공통 기능/다른 설명 구별이 중요하다. 표면적으로 두 학설을 소개하는 글보다 비교 기준을 공유하게 만드는 정보가 실제 추론을 가능하게 한다.
