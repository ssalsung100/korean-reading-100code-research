# 평가원 독서 지문의 정보 구성 연구 v0.1

착수 2026-10-20. 폴더명은 사용자가 지정한 식별자를 유지한다. **기출 22개 지문군의 분석, 구성 후보, 기존본 진단, 서로 다른 구성안 3개, 문항 없는 새 지문 1개, 집필 실행 기준과 입력 카드까지 작성했다.** 기존 100코드 연구를 대체하는 작업이 아니라 설명 목적과 정보 관계를 다루는 독립 연구다.

바로 활용할 문서는 [집필 실행 기준](11_지문집필_실행기준_v0_1.md), [새 지문](09_시험집필_새지문.md), [집필 입력 카드](14_다음지문제작_입력카드.md)다. 새 지문을 기존본의 상위 버전으로 지정하지 않았으며 [개선과 약화의 비교](10_기존지문과_새지문비교.md)를 함께 읽어야 한다.

## 개정02와 새 집필에서 확인한 것

개정02는 세 지표의 단순 나열이 아니다. P3의 동일 총량 이전을 P4의 제곱 계산이 다시 사용한다. 남은 개선 여지는 주로 설명 과제의 범위와 깊이에 있다. 새 글은 G의 분모를 ‘개인→지역→전체’에서 계속 사용하는 방식으로 집계의 의미를 깊게 설명했다. 반면 S의 분배 민감성과 최소 지급 총액 설명은 제외되어 그 교육 목적에서는 기존본보다 약하다.

따라서 이번 성과는 ‘새 글이 전면적으로 우수하다’는 인증이 아니라, **소재의 설명 질문을 선택하는 단계부터 다른 정보 구조를 설계하고 그 이익과 손실을 검토하는 실제 방법**이다.

## 보존 규칙과 재개 위치

기존 기본기 원장·통합 v1·출제 최초본·개정01·02는 수정하지 않았다. G024/G370 hold를 유지했다. 다른 모델 자동 호출과 Git push는 수행하지 않았다. 이번 독립 연구의 판단은 이 폴더 안의 append-only raw에 남겼으며 기존 Astra/Luna 원장에 새 코드 판정 실적으로 혼합하지 않았다.

지문 자체 기록→문항 연결의 저장 순서를 보존했다. 다만 PA02는 수식이 있는 시험지 렌더에서 37·38번도 함께 보였으므로 문항 완전 차단 예외다. 전체 표본에 대해서도 과거 연구·사전학습 무노출을 보장하지 않는다.

후속 연구는 [13번 문서](13_독립표본_검증과_미해결.md)의 세 과제로 이어진다. PA04-49의 의미 판단, 시각자료가 설명을 담당하는 기출의 별도 검토, 새 글 P3/P6/P7에 대한 실제 독자 이해 검토다. 22개 기출의 본문 분석이나 두 선택표 확보를 처음부터 다시 할 필요는 없다. `기록_*.py`·`연결_*.py`는 이미 실행한 저장 스크립트이므로 재실행하지 않는다. `연구도구.py`의 초기 준비도 완료 상태를 덮어쓰지 않도록 중단 장치를 넣었다. 검증 스크립트만 필요할 때 다시 실행한다.
