# 검토용 출력본

현재 학생용 후보 4세트·12문항·60선지와 교사용 전 선지 해설의 출력본이다. 원고의 의미·문항·수치는 출력 과정에서 바꾸지 않았다. 연구 전체의 완료나 실제 학생 난도 검증을 뜻하지 않는다.

- [학생용 합본: 6쪽](학생용_4세트_합본.pdf)
- [교사용 합본: 9쪽](교사용_4세트_합본.pdf)
- [학생용 PDF와 수정 가능한 원고만 묶은 ZIP](학생용_4세트_문제와원고.zip)

합본에는 세트별 책갈피가 있다. 바닥글의 `01 · 2`는 세트 01의 2쪽이라는 뜻이다. 학생용 ZIP에는 개별 학생용 PDF 4개, 학생용 합본 1개, 현재 학생용 Markdown 4개만 들어 있다. 연구 폴더 전체를 압축한 파일이 아니다.

PDF의 외부 학술 자료 링크는 클릭할 수 있다. 작업 폴더의 연구 문서·SVG 원본은 Markdown 원고나 이 폴더의 링크를 통해 연다. 향후 검토용 응답기록지와 추가 서술형 자료는 정규4세트 ZIP에 포함하지 않았다.

## 형식

`korean-workbook-typst`의 형식 일관성 기준과 v5 평가원형 템플릿을 적용했다. 원 템플릿 두 파일은 그대로 보존하고, 본문·문항·선지·보기·표·교사용 도식·정답 보조 칸을 `typst/project_roles.typ`에서 구분했다.

학생용은 A3에 해당하는842×1191pt, 두 단, 단 폭321.8pt, 단 간격26.85pt, HCR Batang11.05pt, 자간0.12pt, 행간 토큰10.45pt를 사용한다. 본문 문단 들여쓰기는10.3pt다. 문항·보기·선지는 한 덩어리로 배치하여 단 사이에서 분리되지 않게 했다. 일부 두 번째 쪽의 빈 공간을 줄이기 위해 글자나 행간을 축소하지 않았다.

교사용은 같은 본문 글꼴과 크기를 사용한 한 단 편집이다. 긴 표가 다음 쪽으로 넘어갈 때 머리글을 반복한다. 현재 길이의 설명 문단은 통째로 유지하여 쪽 경계에서 중간 어절로 갈라지지 않게 했다. 사회적 확산 도식은 교사용에만 들어 있다. 마지막3쪽의 유보·학술 근거 문단도 생략하지 않았다.

초기 렌더에서 발견한 폰트 적용 범위, 문단 간격, 문항 분할, 도식 캡션 후행 간격 문제를 공통 역할 정의에서 고쳤다. 개별 문항에 임의의 빈 줄이나 위치 보정은 넣지 않았다.

## 확인 범위

[문안 대조 결과](문안대조_검증결과.json)에서 학생용 원고와 PDF의 전체 문자 순서가 일치함을 확인했다. 제작용 parser를 불러오지 않고 Markdown의 표시 문자를 별도로 추출했으며, 공백과 Unicode NFC 표현만 정규화했다. 숫자·연산자·조사·문장부호는 보존했다. 각 선지 표지 ①~⑤가 세 번씩 있고 정답·교사용·연구 메모가 검출되지 않았다.

교사용은 현재 원고의 문안 조각 검출과 지면 직접 검토를 병행한다. 조각 수와 검출 결과는 위 JSON에 기록한다. 조각 검사는 표 셀의 순서나 중복 여부를 독립적으로 증명하지 않는다. 직접 검토에서는 표의 행·열 대응, 다음 쪽의 반복 머리글, 다중 행 선지, 보기 테두리, 정답 보조 칸, 도식과 설명의 간격을 확인했다. 수정된 도식 지면도 다시 확인했다. 후속 문안 변경은 영향을 받는 PDF만 다시 빌드하고 문안 대조와 해당 지면 검토를 수행한다.

[묶음 검증](묶음_검증결과.json)에서는 합본의 문자 순서가 개별 PDF의 순서와 같고 책갈피가 맞는지 확인했다. ZIP의 포함 목록은 명시적으로 제한하고, 실제 압축 항목과 대조했다. PDF 검수는 원고의 학문적 정확성·추론 깊이·학생 난도를 대신 검증하지 않는다.

## 재생성

실제 사용 도구는 Typst 0.15.1(9dfd3a08), PyMuPDF, Windows의 HCR Batang 글꼴이다. 공식 Typst 배포 파일을 받아 공식 release digest와 일치함을 확인했다. 설치 파일은 임시 경로에 있으므로 다른 환경에서는 실행 파일을 별도로 지정해야 한다. 글꼴 파일은 이 폴더에 재배포하지 않는다.

```bash
python3 출력본/빌드.py --typst /path/to/typst --font-path /path/to/fonts
python3 출력본/합본과_학생묶음.py
```

위 명령은 이 작업 폴더를 현재 디렉터리로 두는 예시다. `빌드.py`는 자신의 파일 위치로 원고 경로를 결정한다. 재생성 후에는 수정된 문안의 의미 검증과 해당 지면 검토도 수행해야 한다. 자동 통과만으로 새 문안의 정답 유일성이 보장되지는 않는다.
