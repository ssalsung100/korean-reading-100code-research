# Blind-only 수식 표기 보충 — G032

원문에서 위첨자로 조판된 지수와 증가율 분수 표기만 복원했다. 아래 표기는 의미 판정이 아니라 원문 수식의 서식 복원이다.

- 초기 연구의 비례식: `(체중)^{0.67}`
- 체중이 `W`에서 `2W`로 변할 때 체중 증가율: `\frac{2W}{W} = 2`
- 같은 조건의 초기 연구 기초 대사량 증가율: `\frac{(2W)^{0.67}}{W^{0.67}} = 2^{0.67} ≈ 1.6`
- 클라이버의 비례식과 대사 체중: `(체중)^{0.75}`

`0.67`과 `0.75`는 밑줄에 붙는 위첨자 지수다. 본문 표기상 증가율은 증가 후 값을 증가 전 값으로 나눈 분수다. 원문 run 순서와 문자 형식 식별자는 같은 blind-only 자료의 `G032_math_runs.json`에 보존했다.
