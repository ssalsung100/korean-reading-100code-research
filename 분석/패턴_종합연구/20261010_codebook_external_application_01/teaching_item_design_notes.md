# 교육·창작 전이의 근거와 설계 제안

이 문서는 원문 판단을 토대로 만든 행동·설계 제안이다. 학생의 실제 오답 빈도, 수업 전후 효과, 생성 문항의 실측 난도는 관찰하지 않았다. 아래의 교육 효과와 오적용 예방은 전부 가설이다. 고정 표본에서 확인한 사례 연결과 아직 확보하지 못한 전이는 구분한다. 동결 코드북의 상태를 상향하지 않는다.

## P01: 술어·구성·평가 행동의 담당자를 보존하기

근거는 JN④의 양안 조건을 단안 직선 원근에 붙인 장면, RY②의 경쟁 복합체를 세균용 직접 방식에 붙인 장면이다. AYG①·③~⑤는 학자별 주장 귀속, ATN④·⑤는 평가 대상 행동 확인의 보조 활용이다. 단항 귀속과 평가 행동의 근거 탐색이 같은 한 절차로 충분하다는 증거는 없다.

학생 행동의 최소 규칙은 선지의 대상과 핵심 술어를 짚고, 원문에서 같은 술어의 담당자를 찾은 뒤 두 연결을 비교하는 것이다. 관계에 양 끝이 있으면 두 항을 함께 읽는다. 적용 신호는 두 방식·주체·대상이 서로 다른 구성이나 주장을 갖고 선지가 그 대응을 바꾼 경우이다. 하나의 대상에 효과 강도나 전제만 추가된 경우, 이미 제시되지 않은 동기를 발명한 ATN③에는 단순 귀속 교환 규칙을 적용하지 않는다.

아하 포인트의 설명 순서는 JN④의 한 눈/두 눈 → RY②의 항체/성분 → AYG의 학자별 주장이다. 각 예에서 명칭을 외우는 것이 아니라 구성/조건을 어떤 대상이 갖는지 연결을 보존한다. ATN⑤의 평가 행동 근거는 별도 확장 시연으로 둔다. 학생이 이 순서에서 추상 행동을 더 잘 재현한다는 효과는 가설이다.

새 지문에는 두 경로의 결과가 비슷해 보여도 구성 또는 성립 조건을 명확하게 달리 제시한다. 예를 들어 경로A는 운반체에 수용체를 붙이고 경로B는 운반체에 표적을 붙이도록 설계할 수 있다. 두 구성의 기능도 설명하여 이름 암기만으로 해결되지 않게 한다. 오답은 술어를 유지한 채 담당 경로만 교환하고, 참 선지는 원문 연결 또는 사례에서 보존된 연결을 사용한다.

정답 유일성은 모든 선지의 대상-술어 쌍을 원문과 비교하고 동의어·허용되는 양방향 기능을 점검하여 확인한다. 한 경로가 두 기능을 동시에 수행하도록 써 두면 교환 선지가 참일 수 있다. 정답 한 항목만 유난히 상세한 용어를 쓰거나 보기의 대상과 정답의 이름만 일치하면 논리 대신 어휘 중복 지름길이 생긴다.

## P02: 같은 질문의 답끼리 비교하기

직접 근거는 NK의 시험 수단/대상/누적/종류, NN⑤의 경계 명확성/종류, RX의 실제 존재/키트 판정, YS⑤의 위협/효능감, YT⑤의 공통 위협/다른 효능감이다. 상위 질문은 반복되지만 동결 P02.viewpoint_axes와 RX의 두 축 교차 분류는 구체적 하위 행동이 다르다.

학생 행동은 선지에 묻는 질문을 짧게 말한 뒤 원문에서 같은 질문에 대한 답을 회수하는 것이다. 두 주체를 비교한다면 질문을 고정하고, 여러 속성이 있으면 한 속성의 일치가 다른 속성에도 전이되는 연결 근거가 있는지 확인한다. 적용 신호는 둘 이상의 독립적으로 답할 수 있는 질문과 각 답이 있는 경우이다. 원문이 두 속성의 필연적 연결을 정의한 경우에는 무조건 분리하지 않는다. 위협과 효능감의 정의상 구별을 실제 통계적 무상관으로 확대하는 것도 오적용이다.

설명 순서는 NK②의 시험 방식은 공통·다른 축은 차이 → YT⑤의 위협은 공통·효능감은 차이 → RX의 실제 상태와 판정의 교차이다. 앞의 두 장면에서는 같은 축끼리 비교하면 되고, RX에서는 두 질문의 답을 함께 두어 네 경우를 분류해야 한다. 모두 표로 작성해야 한다는 규칙은 없다.

새 지문에는 같은 두 대상이 속성1에서는 같고 속성2에서는 다르게 배치되거나, 실제 상태와 관측 판정처럼 네 조합이 가능한 구조를 준다. 정의가 두 축을 연결하는 예외가 있으면 그 연결도 명시한다. 선지는 한 축의 공통점을 다른 축의 공통점으로 옮기거나, 속성의 정의를 유지해 참인 비교를 만들 수 있다.

정답 유일성은 모든 축의 연결을 원문이 허용하는지 확인하여 판정한다. 관측 판정을 완벽하다고 먼저 정의한 뒤 진/위 판정 오답을 만들면 실제 상태와 판정이 독립되지 않는다. ‘모두’가 들어 있는 한 항목만 오답이 되게 만드는 등 양화 표현만으로 선택 가능한 지름길을 피하려면 같은 한정 범위를 여러 선지에 균형 있게 둔다.

## P03: 비교 척도·고정 조건·방향 근거를 갖춘 뒤 비교하기

근거는 JO③의 같은 관찰자 운동 조건에서 거리/겉보기 속도, RX의 같은 실제 상태 집합에서 오류 비율/성공 비율, AYF②의 공급원 비용 변화이다. AYE⑤와 AYG의 조건 수 비교는 방향 근거가 없는 오적용 경계이다. 이 사례들이 동결의 inverse_order·conditional_chain·relative_ratio 중 한 하위 절차와 정확히 같다고 확정하지 않았다.

학생 행동은 무엇의 무엇을 비교하는지 짚고, 고정한 조건을 찾아, 본문이 실제로 준 증가·감소·역순 관계만 이어 보는 것이다. 적용 신호는 전후/두 경우, 공통 척도, 방향 관계가 모두 있는 경우이다. 서로 반대 효과가 함께 바뀌는데 크기가 없거나, 공통 C에 대한 대소만 있거나, 충분한 문턱만 주어졌다면 비교를 멈춘다.

설명 순서는 JO③의 명시 방향 → AYF②의 명시 비용 방향 → AYF③의 비교 정보 결손 → AYE⑤의 방향 관계 자체 부정이다. ‘더 많다’가 모두 같은 추론이 아니라는 점을 두 실패 장면으로 보여 준다. RX의 비율 분모는 별도 소단원으로 다룬다.

새 지문에는 비교 대상·척도·통제 조건과 방향 관계를 먼저 둔다. 여러 요인을 합치는 설계를 한다면 효과의 크기 또는 합성 규칙을 추가하지 않는 한 순효과 정답을 확정하지 않는다. 선지는 명시 방향을 뒤집거나, 고정 조건을 하나 삭제하거나, 명시되지 않은 단조 관계를 추가하는 방식으로 만들 수 있다.

정답 유일성은 빠진 변수의 값이 달라도 목표 결론이 같아지는지를 점검한다. AYF③처럼 A>B와 A<B가 모두 원문과 양립하면 방향을 단정하는 선지를 정답으로 쓰면 안 된다. 숫자 없이도 원문 정의만으로 답이 정해진다면 불필요한 계산을 난도처럼 부과하지 않는다. 조건 수만 세면 답이 나오는 보기로 만들 경우에는 ‘조건 수와 효율은 비단조’라는 의도와 충돌할 수 있다.

## P04: 필요한 전제의 결손과 결론 범위를 제한하기

서로 다른 근거를 따로 유지한다. JO②는 양안 경로의 시야 중첩, RV④는 발색 경로의 표지 물질, RY③는 LFIA 투입 경로의 액상 시료, YS④는 주어진 위티 모형 안에서 권고 이행 경로의 높은 위협, AYG②는 차선 주장 지원의 적용 범위이다. 마지막 두 장면은 동결 explicit_requirements·measurement_mechanism·authority_scope와 완전 동일한 하위형으로 확정하지 않았다.

학생 행동은 먼저 어떤 결과 또는 어떤 경로를 적용하려는지 특정하고, 그 경로에 정말 필요한 전제라는 근거를 찾은 뒤 사례에서 전제가 있는지 확인하는 것이다. ‘도움이 된다’, ‘많을수록 낫다’, ‘대표적이다’를 필요조건으로 만들지 않는다. 전제가 없을 때에는 그 경로가 막힌다는 범위에서 결론을 멈춘다. JO⑤에서 한 눈을 가려도 단안 경로가 남는다는 점이 전체 결과 부정의 오적용 신호이다.

아하 포인트는 JO②의 양안 불가≠모든 입체 지각 불가 → RV④의 표지 없음≠외부 검사 모두 불가이다. 두 장면은 한 경로와 전체 결과의 차이를 보여 준다. YS④는 명시된 네 조합의 닫힌 모형에서만 높은 위협 필요가 도출되는 장면으로 뒤에 둔다. 일반 심리 현상의 보편 요건이라고 가르치지 않는다.

새 지문에는 전제의 필요성이 정의·누적 요건·기전 중 어디서 오는지 명시하고, 동일한 결과에 다른 경로가 있다면 그것도 원문에 둔다. 오답의 조작점은 필요조건의 삭제, 충분조건을 필요조건으로 바꾸기, 한 경로의 실패를 전체 결과의 실패로 확대하기이다. 참인 사실이나 유리한 조건을 한 선지에 넣더라도 그 사실이 해당 결과의 요건인지 따로 검토한다.

정답 유일성은 같은 결과의 대체 경로, 예외, 입력 상태를 검토하여 확보한다. 원문이 ‘A이면 B’만 주고 ‘B이면 A’를 정답 전제로 요구하면 복수 해석 위험이 있다. YT의 역추론은 P04의 전제 결손 행동으로 대신 가르치지 않는다. 원문 결손 때문에 필요성이 확인되지 않은 경우는 비적용 단정이 아니라 불확실로 남긴다.

## P05: 실제 결합 문맥에 치환어를 넣어 비교하기

근거는 NO②의 결론에 도달→다다름, YU⑤의 아무 영향 주다→기여의 의미 성분 차이이다. 서로 다른 두 지문에서 실제 후보 치환을 수행했다. ATP의 폐단은 의미 치환이 아니라 지시 대상 연결이므로 경계 사례이다.

학생 행동은 주어·목적어·수식 범위를 유지하고 쉬운 풀이말 또는 후보 단어를 대입한 뒤 원문 뜻과 같아지는지 확인하는 것이다. 적용 신호는 단어 용례/치환을 묻고 실제 문맥이 뜻을 제한하는 경우이다. 익숙한 한자어라는 이유로 선택하거나, 부정형이면 뜻 차이가 사라진다고 보는 것은 오적용이다. YU⑤의 영향 없음과 도움 없음은 같은 뜻이 아니다.

설명 순서는 NO의 결론에 ‘이르다’ → 도착/돌아감/유래 차이 → YU의 중립 영향/도움 차이이다. 형태가 비슷한 동사를 암기하는 대신 결합 문맥과 추가 의미 성분을 확인한다.

새 지문에는 뜻을 고정하는 목적어·후속 행위·한정어를 충분히 둔다. 선지는 문법적으로는 들어가도 의미 범위가 다른 후보, 방향이 반대인 후보, 원문의 의미를 유지하는 후보로 구성한다. 핵심은 실제 문맥에서의 의미 보존이며 다른 문맥의 사전 뜻을 정답 근거로 쓰지 않는다.

정답 유일성은 다의어·허용되는 비유 용례를 검토해야 한다. 문법적 어색함만으로 네 항목이 제거되면 의미 판단의 지름길이 된다. 두 후보가 같은 문맥에서 모두 자연스럽고 같은 뜻이면 복수정답이다. 독해 구조와 무관한 단어 퀴즈로만 변하지 않도록 판단에 쓰인 문맥 기능도 해설에 남긴다.

## P07: 선후 근거의 종류를 구별하고 상태를 배치하기

RW①은 결합 기전의 명시 선후이고 ATP①·⑤는 기존 문제/예상 문제/회고 대상의 배치이다. 두 지문에서 상위 원칙은 확인되지만 causal_sequence와 historical_placement를 하나의 절차로 통합하지 않았다. NL④의 정당화 순환, YT의 집단번호는 비적용 경계이다.

학생 행동은 ‘일차적으로/이후’, ‘앞으로’, ‘고치려다’, 과거를 회고하는 서술 등 실제 선후 근거를 찾은 뒤 각 시점에 이미 성립한 상태와 아직 예상되는 상태를 구분하는 것이다. 설명 문장의 출현 순서, 열 번호, 실험 집단번호는 선후 근거가 아니다.

설명 순서는 RW①의 실제 결합 순서 → ATP⑤의 마지막 표현이 기존 대상을 회고함 → NL④는 시간 순서가 아닌 개념 의존이라는 경계이다. 선후를 먼저 물어야 하는 장면과 시간 축 자체가 없는 장면을 함께 보여 준다.

새 지문에는 각 단계에서 무엇이 결합·제거·남는지를 명시하거나, 예측/시행/회고를 구별하는 시간 근거를 준다. 선지는 중간 단계에 나중 상태를 옮기거나, 예측을 이미 발생한 사실로 만들거나, 회고 대상을 새로운 사건으로 바꾸는 방식으로 설계할 수 있다.

정답 유일성은 단계 간 생략된 지속 상태와 반복 발생 여부를 확인해야 한다. 같은 상태가 여러 단계에 걸쳐 유지되면 특정 단계 귀속만으로 오답을 만들 수 없다. 단순히 ‘이후’라는 단어가 포함된 선지를 모두 참으로 만드는 지름길도 피한다. 글의 뒤에 나온 표현을 무조건 나중 사건으로 읽는 행동은 ATP⑤가 직접 반박한다.

## S03: 한 문항 시연으로만 제안하는 전개 동작 확인

YR④의 ‘소개한 후 과제 제시’는 소개 부분은 맞고 끝의 과제 제시는 없다. 마지막은 통합 이론의 후속 연구 의의 평가이다. 코드북 S03.discourse_actions와 맞는 직접 수행 사례가 확인됐다. 다만 이번 고정 세트에서 독립적인 두 번째 전개 문항은 없으므로 넓은 교육 규칙의 효과나 반복성을 확정하지 않는다.

시연 행동은 선지의 두 동작을 각각 말하고 원문 문단 기능에 대응시키는 것이다. 끝 동작만 보라는 요령은 아니다. 기능을 묻는 복합 선지가 적용 신호이고, 주장 내용 자체의 참 여부나 문학의 지각 주체를 묻는 문항은 오적용 신호이다.

새 지문은 소개→비판 검토→통합→의의 평가 중 실제 동작을 명확하게 구현할 수 있다. 오답은 앞 동작을 보존한 뒤 ‘새 과제 제시’ 또는 ‘새 이론 도출’처럼 실제 없는 동작을 추가한다. 동작의 정의가 모호하면 의의 평가를 과제로도 해석할 수 있어 복수정답 위험이 생긴다. 참인 선지의 길이만 길거나 마지막 문장 어휘가 그대로 반복되면 읽기 기능 확인 없이 선택되는 지름길도 점검한다.

## 잔여 후보의 수업·창작 전이 상태

R04는 NN·AYF·AYG·ATO를 연결하는 설명 질문으로 활용할 근거가 있지만, 비판/지지/대안이라는 하위 조작이 하나의 수업 절차로 충분한지는 미확인이다. 시연 순서는 원문 재진술인 NN①이 왜 비판이 아닌가 → AYF⑤의 증가가 왜 감소 가능성 지지가 아닌가 → AYG②가 왜 적용 범위 밖인가 → ATO⑤의 경고가 왜 제안이 아닌가이다. 각 장면의 논증 역할을 학생이 더 잘 판정하게 된다는 기대는 교육 가설이다.

R02·R03·R06~R12는 독립적인 반복 근거가 부족하여 확정 행동 카드나 생성 규칙으로 채택하지 않는다. 특히 RY④에서 유병률·오류 비용이 다른 새 검사 문제를 만들려면 어느 오류를 먼저 줄일 것인지 목표를 명시해야 한다. YT형 문항에서 결과→조건의 역추론을 요구하려면 반응 모형의 완전성과 보기의 부합을 명시하고 다대일 결과에는 유보 답이 남도록 해야 한다. 이는 해당 원문이 보여 주는 설계 제약의 기록이며 일반 전이 가능성 검증 완료가 아니다.

## 생성 문항의 유일성 검토 절차

1. 정답 의도보다 먼저 원문의 전제·적용 범위·대체 경로를 고정한다.
2. 모든 선지에 대해 실제 근거→필요한 중간 추론→일치/차이를 적고, 내용 판정과 발문의 선택 조건을 분리한다.
3. 미정 변수에는 서로 반대 결론의 값을 넣어도 원문과 양립하는지 검토한다. 양립하면 그 결론을 단정하는 항목은 참 정답이 될 수 없다.
4. 같은 답을 주는 더 짧은 유효 경로는 허용한다. 원문 없이 용어 중복·형태·한정어만 보고 선택되는 경로와 의도하지 않은 두 개의 참 선지는 설계 결함 후보로 따로 검토한다.
5. 실제 학생 풀이와 생성 문항 시범 검증을 거치기 전에는 오답 빈도·학습 효과·난도·창작 품질을 관찰된 사실로 쓰지 않는다.
