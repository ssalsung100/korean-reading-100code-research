# RX `<보기>` 선택지 보강 — blind-only

- passage_group: G119
- case_id: RX
- blind source 역할: RX의 기존 `RX.json`에 누락된 `<보기>` A/B 선택지 표를 원문 구조대로 보강한다.
- 공식 답·SDSS·기존 해설·기존 코드 판정은 포함하지 않는다.

## `<보기>` 표

| 행 | A열 | B열 |
|---|---|---|
| ① | 진양성 | 진음성 |
| ② | 진양성 | 위음성 |
| ③ | 위양성 | 위음성 |
| ④ | 위음성 | 진음성 |
| ⑤ | 위음성 | 위양성 |

원문 조판에서 표 머리글은 `A`와 `B`이고, 각 행은 번호·A열·B열 순서로 배치되어 있다. 기존 RX blind source의 지문·발문은 변경하지 않는다.
