# 402 중단 뒤 국소 복구와 연속 연구

2026-10-17. 저장소 파일 우선. 기존 개별 풀이를 공개한 사후 통합 연구이며 새 blind 성과는 0이다. 연구자 미검토.

## 시작 시 실제 저장 상태

- 사례집 01~35가 모두 존재한다. 25~30은 기존 체크포인트05에 연결되어 있다. 31~35는 본문·원리·판단·제작 효과·출처 등록까지 저장되었지만 checkpoint, coverage_remaining, validation_report, README, 진행기록은 30번 상태였다.
- 실제 원리는 IR-P049까지 49개, 판단은 IR-D045까지 45개, 제작 효과는 IR-E089까지 89개다. 다음 신규 ID는 각각 P050·D046·E090이다. 31~35를 다시 작성하지 않는다.
- source_registry는 메타 전용 BCF를 포함한 71행이다. 직접 비교는 70고유 문항·56지문군·104기존 장면이다. 체크포인트05의 63문항·97장면에서 7문항·7장면이 추가된 상태다.
- DEV105의 AVL·AVR·AVV·AVX·BAX, DEV111의 BCT·BDN·BEA·BEB·BEE는 해당 근거 장면 대조가 저장되어 있다. 두 DEV의 대조 완료는 원유보 해소나 단일 원리 통합을 뜻하지 않는다.
- DEV112·113·114는 기존 발전 원장에 존재하지만 통합 사례집·판단의 사용 기록은 없다. DEV114는 자료 정본·중복·노출 상태를 다루는 연구 메타이므로 풀이 원리 출현과 분리한다. 현행 발전 기록은 112행이며 마지막 번호 114와 행 수를 혼동하지 않는다.
- 직전 조회 대상 U0478-Q03(X)은 기존 개별 보완의 본문·전체 선지·유보가 있지만 통합 source_registry와 사례집에는 없다. 조회만 했다는 사실을 완료로 올리지 않고 여기서 실제 비교를 재개한다.

## 유지할 한정

BCT의 반대론도 ‘억압할 수 있다’는 가능성 주장이다. BDN의 난소 직접 개선은 전신 순효과를 보장하지 않는다. BEB의 정확 가능 범위와 느슨한 상한을 구별한다. AVV·AVX의 표현 변환·정보 삽입/삭제·저장 규약 변경을 분리한다. IR-P012·015의 저장된 보완을 승계한다. 기존 93개 유보와 G024/G370 hold를 유지한다.

## 작업 범위

이번 저장은 이 통합 폴더에 한정한다. 원문·기존 풀이·sweep·backfill·동결 코드북·Astra 원장·processed·CURRENT를 수정하지 않는다. 다른 모델 호출, 전수 재분석, 원본 전수 해시 검사, Git push를 수행하지 않는다. 후속 완료 범위와 다음 대상은 이 파일 끝에 추가한다.
