# 교재 학습 단위 v1 — 잠정 구성안

연구 원리63개를 그대로63개 단원으로 만들지 않는다. 아래12개 단위는 **학생이 서로 헷갈리는 판단을 대비하고 실제 행동을 연습하도록 묶은 교육 제안**이다. 한 단위가 한 차시라는 뜻도 아니다. 연구자의 설명 방식·학생 질문·수업 시간에 따라 나누거나 순서를 바꿀 수 있다. 학습 효과는 아직 검증하지 않았다.

각 단위의 기출은 [대표·경계 인덱스](대표경계사례_인덱스.md)의 사례ID·장면ID·원문으로 연결된다. 이번 직접 대조21장면 외의 사례는 기존 연구의 제안을 승계했으며, 이 문서 작성을 신규 기출 풀이로 세지 않는다. 정답 경로·다른 선지·대안 풀이·연구용 반모형은 수업 지면에서도 표시를 달리한다.

## LU01 말이 나타내는 일과 문장에서 실제로 일어난 일

연결 원리: P001·P056. 대표 AY/CP, 경계 HU/FY. 이번 v1에서는 기존 사례01·49~51의 분석을 승계했다.

- 핵심 구별: 단어 뜻의 일부 포함, 문맥에서의 치환, 사건의 실제 발생은 다르다.
- 독해 중: 주체·목적어·상태 변화가 있는 문장만 관계로 잡는다. 모든 단어의 뜻을 동의어 목록으로 바꾸지 않는다.
- 선지 뒤 회수: 대체어를 실제 문장에 넣고 ‘누가 무엇을 어떻게 했는가’를 다시 말한다. ‘가늠할 수 없다’에서는 낱말에 양 판단의 뜻이 있는지와 수행 가능성을 따로 본다.
- 학생 행동: AY의 ‘성행→일어남’에서 사라진 활발함을 한 구절로 적고, CP의 ‘응시→바라봄’에서 남은 시선 행위를 적는다. ‘뜻이 조금 다르다’만으로 배제하지 않는다.
- 비교 이유: 더 넓은 표현이 허용된 CP와 핵심 상태를 잃은 AY를 함께 보아 의미 완전 일치라는 과잉 규칙을 막는다. HU는 발문 자체가 달라진 경계다.
- 여러 풀이: 사전적 의미 성분에서 시작하거나 문장 관계에서 시작할 수 있다. FY의 존숭과 믿음은 관습적 뜻 지식이 필요하므로 문맥만으로 모두 증명했다고 하지 않는다.
- 연습: 같은 말이 쓰인 가능문·부정문·실제 사건문을 나누고 ‘의미 포함’과 ‘치환’ 발문을 번갈아 붙인다. 보기의 문법적 결합까지 확인하게 한다.
- 과잉 일반화 위험: 정보량이 완전히 같아야 대체 가능하다거나 두 행위가 함께 일어나면 동의어라는 설명은 금지한다.

## LU02 기준을 적용하기 전에 어느 영역의 기준인지 정하기

연결 원리: P016·P026·P038·P055·P058. 대표 MO/FR, 경계 NL②/HG/DO.

- 핵심 구별: 기준 안에서의 참거짓, 기준 밖의 대상, 지정 관점의 적용, 필자가 수용한 견해를 나눈다.
- 독해 중: 기준의 소유자와 대상 영역을 붙여 둔다. ‘모든 언어’, ‘모든 인간 행위’로 범위를 넓히지 않는다.
- 선지 뒤 회수: MO의 보기에서 A/B가 어떤 설명을 예술 판단에 옮기는지, FR의 ‘모든 이’에 명시 제외 대상이 들어오는지 확인한다.
- 학생 행동: MO에서 A/B 아래 ‘명제성 인정/비인정’을 먼저 적는다. B에게 한쪽 거짓은 알 수 있지만 어느 쪽 거짓인지는 표시하지 않는다. FR에서는 주장 집합 안에 노비를 넣은 뒤 제외 규칙과 대조한다.
- 비교 이유: 기준에 해당하는지 묻는 문제와 진리값을 지정하는 문제를 구별하고, 모든이라는 말 자체가 오답 표지가 아님을 익힌다. NL②는 글쓴이가 비판한 기준도 지정 관점 안에서는 적용해야 한다는 경계다.
- 여러 풀이: 원문 정의 직접 대입과 반례 한 개 제시는 각각 충분할 수 있다. HG의 자기 적용을 일반 문장의 거짓 판정이나 순환 논증으로 바꾸지 않는다.
- 연습: 예외가 주장 집합 안/밖에 놓인 두 보기를 비교한다. DO의 새 전략도 규칙 대상인 경우와 규칙이 종료되는 가상 경우를 나눈다.
- 과잉 일반화 위험: 분류 밖이면 거짓·무의미·무기능이라는 도식을 만들지 않는다. P026의 독립성은 재분류 검토 중이다.

## LU03 같은 단어보다 누가 어떤 설명에 쓰는지 보기

연결 원리: P037·P041·P047·P050·P053. 대표 MM, 경계 X/BCU/ATO.

- 핵심 구별: 말의 등장, 실제 서술 행동, 특정 주체의 논거, 수용자가 받는 인상은 서로 다르다.
- 독해 중: 모든 논자의 말을 외우기보다 ‘판단의 뜻’, ‘행위 동기의 설명’, ‘비판용 사례’처럼 역할을 붙인다.
- 선지 뒤 회수: MM⑤의 ‘승인 감정 표현’을 (다)의 의미 설명과 (라)의 동기 설명에 각각 넣어 본다. 감정이라는 단어가 양쪽에 있다는 이유만으로 공동 견해라 하지 않는다.
- 학생 행동: 주체–대상–설명 역할의 세 칸을 만들고 각 칸을 뒷받침하는 문장 위치를 하나씩 적는다. X에서는 ‘양립 가능/귀속 지지/명시 충돌’을 구별하여 표시한다.
- 비교 이유: MM은 설명 역할의 직접 대응이 강하고 X⑤는 가능한 해석과 그 주체에게 귀속할 근거가 다른 경우다. 같은 강도로 모순이라고 가르치면 X의 유보가 사라진다.
- 여러 풀이: 해당 이론의 직접 정의를 회수하거나 경쟁 이론과 설명 역할을 대조할 수 있다. 경쟁 이론에 그 어휘가 없다는 부정은 별도 증명이 필요하다.
- 연습: ATO의 인용을 실제 수정 채택 제안으로 바꾸려면 무엇을 더 써야 하는지 적는다. BCU의 객관적 인상 문장만 지운 뒤 실제 선별 과정에 관한 오류가 남는지 판단한다.
- 과잉 일반화 위험: 주체명만 바꾸면 복합 선지 전체가 맞는다는 제작법, 명시 문장만 견해로 인정하는 독해법을 피한다.

## LU04 결과·기능·의도를 한 문장으로 합치지 않기

연결 원리: P006·P039·P040·P044·P051·P052·P054·P060. 대표 BRM, 경계 ASN/BDY/AVL/MJ.

- 핵심 구별: 결과가 생김, 그 결과를 원함, 기능이 있음, 그 기능을 우선함, 발생을 인정함, 규범적으로 승인함을 나눈다.
- 독해 중: 직접 동기 진술과 관찰 가능한 결과를 구별한다. 문학에서는 넓은 정서와 특정 장치의 기능을 별도 표시한다.
- 선지 뒤 회수: BRM④의 목적 부정은 ‘입증하지 않는다’ 뒤의 ‘부수적 산물·얻고자 했던 것 아님’까지 읽는다. ASN에서는 몸짓의 관찰 대상과 후속 반응으로 돌아간다.
- 학생 행동: ‘행위→결과’와 ‘결과의 기대→행위 선택’ 두 화살표를 따로 그리고, 실제 문장이 어느 화살표를 지지하는지 붙인다. ASN은 근거 강도를 교사용 유보와 함께 적는다.
- 비교 이유: BRM의 명시적 목적 부정과 ASN의 해석적 기능 귀속은 배제 강도가 다르다. BDY는 의도와 이론이 부여한 효과가 공존하는 경우로 대비한다.
- 여러 풀이: 직접 지시문 우선 경로와 앞뒤 발화의 누적 해석 경로가 가능하다. 후반 정보라고 무조건 버리지도, 후반 감정을 앞 행동의 단일 목적에 붙이지도 않는다.
- 연습: 만족 발생은 유지하고 목적 근거만 제거한다. ‘주된 기능/일부 기능/기능 사용’을 바꿔 요구 범위를 비교한다. MJ에서는 현상 설명과 불공평 평가를 분리한다.
- 과잉 일반화 위험: 결과가 나중에 생기므로 목적이 될 수 없다는 시간 논증, 다른 기능이 중심이므로 해당 기법이 없다는 논증을 금지한다.

## LU05 근거가 어디를 지지하며 얼마나 멀리 가는지 따라가기

연결 원리: P005·P008·P009·P011·P012·P027·P031·P034·P035. 대표 NL/BEX, 경계 AWF/NM/AF. 여러 소단위로 나눠 사용할 수 있다.

- 핵심 구별: 정당화 의존, 결합 예측 실패, 비교 간선 부족, 가능성 지지와 결정 반증은 서로 다른 연산이다.
- 독해 중: ‘왜/때문/보장/다시 의존’에서 화살표의 뜻을 근거 관계로 적는다. 원인과 시간 화살표와 구별한다.
- 선지 뒤 회수: NL④의 세 고리와 BEXㄱ의 두 고리를 회수한다. BEXㄴ은 다시 돌아오는지, 절대 근거에서 끝나는지를 확인한다.
- 학생 행동: 각 주장 옆에 ‘이것을 믿을 이유’를 쓰고 출발 주장을 재사용한 곳에만 표시한다. 근거가 부족하면 내용의 거짓까지 적지 않는다. AF에서는 이유를 찾기 전에 질문이 전제한 행위를 본문 권고에 대조한다.
- 비교 이유: NL은 본문 논증의 재구성, BEX는 보기의 정의 적용이다. 같은 원리가 서로 다른 발문에서 구현됨을 보인다. NM의 예측 실패는 어떤 전제가 틀렸는지의 문제여서 순환과 합치지 않는다.
- 여러 풀이: BEX는 ㄱ 확인만으로③/④가 남으므로 ㄴ도 필요하다. AWF는 관측과 예상의 어긋남으로 가능성을 지지하며 정확한 효과량 추정까지 요구하지 않는다.
- 연습: 독립 근거 추가, 이미 있던 주장 재선언, 표적과 무관한 관측 추가를 비교한다. 가설만 고정했는지 보조 조건도 고정했는지 표시한다.
- 과잉 일반화 위험: 비약화=입증, 불일치=특정 가설 거짓, 원 모양=순환 오류라는 자동 규칙을 만들지 않는다.

## LU06 숫자의 이름·기준·끝점을 먼저 고르기

연결 원리: P032·P036·P057. 대표 JY/HD/GV, 경계 BQE/LK.

- 핵심 구별: 총합·차·비·역수·기울기·도달시간은 같은 숫자 표에서도 다르게 정해진다.
- 독해 중: 지표가 무엇을 비교하는지 정의와 단위를 확보한다. 감도라는 이름에 한 산식을 암기해 붙이지 않는다.
- 선지 뒤 회수: JY의 목표가 총량/좌우 편향/초점 중 무엇인지에 따라 집계식을 고른다. HD에서는 기준 시작값과 최종 변화의 일정 비율에 이르는 시간을 찾고 GV에서는 같은 입력 변화에 대한 출력 변화폭을 본다.
- 학생 행동: 계산 전에 ‘비교량=…’ 한 줄을 쓰고 현재 상태와 조치 방향을 별도 칸에 적는다. 보정 방향을 현재 치우침으로 읽지 않는다.
- 비교 이유: HD의 최종 상대 변화와 GV의 민감도는 명칭이 같아도 같은 계산이 아니다. BQE는 단위 검사만으로 역수 방향이나 평균식 타당성을 해결할 수 없다는 경계다.
- 여러 풀이: LK 거리 순위는 거리지수 비교로 충분하다. 정밀 거리를 구하는 계산은 해당 선지의 필수 경로가 아니다.
- 연습: 같은 네 검출값의 합을 바꾸되 편차를 유지하는 변형, 비율은 같고 절대 기준값은 다른 센서를 비교한다(E155~158·185).
- 과잉 일반화 위험: 모든 보정은 관측과 반대, 감도는 그래프 높이, 단위가 같으면 식도 옳다는 설명을 피한다.

## LU07 평균·경계·가능한 값의 범위를 구별하기

연결 원리: P002·P017·P022·P023·P049. 대표 ATD, 경계 BQE/AXB/BEB; 가중 변화 BQF는 심화 대조다.

- 핵심 구별: 전체 비율의 경계, 정확한 평균, 구성의 절대 크기 역산, 가능값의 목록은 다르다.
- 독해 중: 구성 집단·분모·비중이 무엇인지 적고, 실제 분모가 합쳐지는지 본다.
- 선지 뒤 회수: ATD의 집단별35%/12%와50%의 관계로 돌아간다. BQE에서는 혼합 부피 비가산 문장을 찾아 평균 적용 자체를 검토한다.
- 학생 행동: 정확값 계산 전 ‘모두 문턱 아래인가’를 표시한다. 한 집단을50%로 바꿔도 다른 집단의 양의 비중과12% 때문에 전체가 엄격히 아래임을 설명한다.
- 비교 이유: ATD는 계산 없이 경계가 나오지만 BQE는 단위가 같아도 평균식의 분모가 성립하지 않는다. BEB는2이하가3이하를 반박하지 않는다는 상한/가능값 표현의 경계다.
- 여러 풀이: ATD의 약24% 가중 계산은 대안 검산이다. 학생에게 모든 비율을 계산해야 과반을 판단할 수 있다고 가르치지 않는다.
- 연습: 비중을 모르는 경우, 한 집단이 문턱을 넘은 경우, 분모가 합쳐지지 않는 경우를 비교한다. 표본 외삽의 편향 방향과 정확 오차량은 구별한다.
- 과잉 일반화 위험: 평균 상승으로 성분의 절대 크기 확정, 변화합0으로 원래 값의 합 보존, 느슨한 상한을 반례로 오해하는 설명을 경계한다.

## LU08 비례식에 남는 계수와 실제 비교 조건 찾기

연결 원리: P018·P019·P020·P021. 대표 LK, 경계 AXY/BID/BII; 보존 목표 AVR은 대조로 쓴다.

- 핵심 구별: 같은 계수 범위와 동일 계수값, 조건부 작용 방향과 실제 전후 결과를 나눈다.
- 독해 중: 수식만 외우지 말고 계수의 공통성·각 변수의 지수·모형의 적용 대상을 함께 읽는다.
- 선지 뒤 회수: LK에서 반지름과 온도비의 각 지수를, AXY에서 유효길이/파장 계수 범위를 회수한다.
- 학생 행동: 두 대상의 식을 각각 쓴 뒤 나누고 실제 같은 항에만 소거 표시를 한다. AXY의 k1/k2를 지울 조건이 없으면 그것을 남긴다.
- 비교 이유: LK는 같은 모형의 복합곱 배율, AXY는 공통계수가 필요한 길이비다. ‘비례니까 비율만 보면 된다’라는 과잉 일반화를 막는다.
- 여러 풀이: LK③은 절대등급 차로도 풀린다. 지문이 제공한 독립 경로를 지워 비례식만 필수라고 보고하지 않는다.
- 연습: 입력 하나만 바꾸되 중복 등급표도 일관되게 고치는 변형과, 숫자 하나만 바꿔 두 근거가 충돌하는 변형을 대조한다(E232~234).
- 과잉 일반화 위험: 계수 미정이면 언제나 반대, 분모 감소면 언제나 비율 증가, 보존 목표가 달라도 같은 보정 방향이라는 규칙을 피한다.

## LU09 더 나아진 수지와 실제 증가를 따로 비교하기

연결 원리: P024·P033·P048. 대표 AYN/BHM, 경계 AWM/BDN. 원문 유보를 숨기지 않는 교사용 단위다.

- 핵심 구별: 부분 손실·순변화·시점 보유량, 한 경로 개선·전체 순효과를 구별한다.
- 독해 중: 유입/유출의 대상·기간·부호를 잡는다. 모든 정보를 식으로 바꾸기보다 물어볼 수 있는 양을 구분한다.
- 선지 뒤 회수: AYN⑤에서 C→A의 누락 수지항과 A→유속의 단면 조건을 각각 찾는다. BHM은 저장·두 분해 경로와 보기의 전후 비교로 돌아간다.
- 학생 행동: ‘무엇과 비교한 증가인가’를 먼저 쓴다. −2→−1의 가상 순량에서 개선은 있지만 절대 증가가 없음을 설명한다.
- 비교 이유: AYN의 바닥 융해 두께/순두께 해석과 BHM의 정성 예상/엄밀 충분성은 같은 문제로 합치지 않는다. 공통 수지식을 쓰되 다른 출력에 필요한 조건을 익힌다.
- 여러 풀이: 공식 정답의 의도된 정성 경로를 먼저 설명하고, 충분성 반모형은 교사 심화 또는 학생의 반례 질문에 사용한다. 모든 시험 풀이에서 가상 수치를 만들어야 한다고 하지 않는다.
- 연습: [제작 카드C02](다중AI_출제입력카드.md)의 서로 다른 시간 구간 수지를 사용한다. BDN의 미지 효과량을 임의로 정해 치료 결론을 만드는 연습은 하지 않는다.
- 과잉 일반화 위험: 국소 개선=전체 개선, 초기 균형이 유일 필요조건, 기출의 정성 예상=현실 의료 효과 보장은 금지한다.

## LU10 입력에 있던 정보와 출력으로 알 수 있는 정보

연결 원리: P003·P004·P010·P030·P045·P046·P063. 대표 AGT/BFV, 경계 KG/RW/AVX/AWE.

- 핵심 구별: 입력 사용·출력 보존·동일 정보 잔존·다른 단서의 기여·다른 기능 신호를 나눈다.
- 독해 중: 원자료→처리→최종 출력의 세 칸을 만든다. 장치의 이름보다 실제 출력 항목을 적는다.
- 선지 뒤 회수: AGT④의 ‘골격 이미지로는’과 머리 점, BFV③의 ‘수리분류학자의 계통수’와 거리 집계로 돌아간다.
- 학생 행동: 묻는 속성에 동그라미를 치고 출력에서 그 속성을 표시하거나 복원하는 수단을 찾는다. 없다고 보이면 서로 다른 입력이 같은 출력인 예를 하나 제시한다.
- 비교 이유: AGT는 선택 표상, BFV는 개수 집계다. 계산 방식은 다르지만 필요한 차이를 출력이 보존하는지라는 상위 검사를 공유한다. 분기론 그림에는 형질 표시가 있다는 경계도 함께 제시한다.
- 여러 풀이: BFV는 거리의 뜻과 출력 항목을 바로 대응하는 짧은 경로가 가능하다. 전체 거리 행렬이 같은 반모형은 연구 검산이며 모든 학생의 필수 계산이 아니다.
- 연습: 원영상 별도 통로 추가, 골격 자체 항목 추가, 허용 입력 제한을 비교한다. 숫자 하나라도 가역일 수 있는 작은 모형을 대조한다.
- 과잉 일반화 위험: 모든 요약은 모든 정보 소실, 남은 신호가 하나면 어떤 목표든 복원, 변수 이름3개면 독립 정보3개라는 설명을 막는다.

## LU11 경로가 있다는 것과 목표를 보장한다는 것

연결 원리: P007·P013·P014·P015·P025·P042·P043·P044. 대표 BPJ/BEA/BJE, 경계 AVH/DW/ATY.

- 핵심 구별: 직접선·매개 경로·규칙 출력·같은 목표의 충족·검사 간 함의를 구분한다.
- 독해 중: 간선이 영향·정보·지지·논리 함의 중 무엇인지 붙인다. 장치를 더했다는 사실 자체를 개선으로 읽지 않는다.
- 선지 뒤 회수: BPJ의 간접 전달과 BEA의 중간 보를 확인한다. BJE는 번호 증가 구조와 후보 생성·검사의 정확한 조건으로 돌아간다.
- 학생 행동: 생략하려는 검사를 쓰고 앞 검사를 통과한 반례가 있는지 찾는다. 현재 BJE에서는 재방문 불가→5방문이면5정점이라는 중간 문장을 실제로 말한다.
- 비교 이유: BPJ는 직접선이 없어도 전달, BEA는 전달되어도 직접은 아님이라는 서로 다른 오류 방향이다. BJE의 생략은 단서의 기여보다 강한 논리 함의를 요구한다.
- 여러 풀이: BJE 정답에 필요한 증명과 최소 검사 수/최소 비용의 연구 확장을 구분한다. AVH는 실제 분리 감소와 측정 대표성이라는 발문 목표를 먼저 읽는다.
- 연습: 순환 간선을 하나 추가해 실제 누락 경로가 생기는지 점검한다(E024). 추가했다고 항상 실패하는 규칙을 만들지 않는다. 같은 기능 기전의 수단 두 개가 목표 전체를 대체하는지는 별도로 검사한다.
- 과잉 일반화 위험: 경로 존재=항상 출력 변화, 유지=규칙 부재, 공통 기능=완전 대체, 단서가 남음=검사 생략 가능을 구별한다.

## LU12 사건의 성립·시점·효과를 분리해 규칙 적용하기

연결 원리: P028·P029·P059·P061·P062. 대표 GA/NY, 경계 RS/MS.

- 핵심 구별: 성립 요건·성립한 사건의 책임, 사실의 발생·증거 발견, 권리 발생·행사·효과를 구별한다.
- 독해 중: 규칙 문장의 조건과 결과를 붙이고 결과가 여러 개면 효과별로 칸을 나눈다. 나뉜 칸의 의존관계는 남긴다.
- 선지 뒤 회수: GA는 체결 당시 하자를 상정한 문장, NY는 해지권 제한과 인과관계 부재에 따른 지급 책임 문장으로 돌아간다.
- 학생 행동: NY에서 ‘해지권/지급 책임/반환’을 세 칸으로 적고 각 예외의 화살표를 그린다. 미고지 사실에서 귀책이나 실제 해지를 채워 넣지 않는다.
- 비교 이유: GA는 책임을 성립조건으로 옮기는 오류, NY는 한 예외의 효력을 다른 효과에 복사하는 오류다. 같은 법 지문이라는 이유로 단일 규칙 적용이라고 축약하지 않는다.
- 여러 풀이: NY④는 위반 성립/불성립을 나누어도 제한된 반환 불가 결론에 이를 수 있다는 기존 D088의 보완을 심화로 둔다. 기본 설명에서는 실제 본문 예외를 먼저 대응한다.
- 연습: [제작 카드C03](다중AI_출제입력카드.md)의 창작 예약 규약을 사용해 예외 제거와 반대 결론 확정이 다른 것을 보인다. MS는 옛 사실의 문서 발견과 새 권리 상태를 두 시간축에 배치한다.
- 과잉 일반화 위험: 하자는 반드시 사후 발생, 절차가 있으니 급부 실현 가능, 나중 발견이면 새 사실, 면책이면 사건 무효라는 설명을 피한다. 현재 법률 안내로 사용하지 않는다.

## 배치와 수정

처음부터 LU01~12를 순서대로 완주하도록 정하지 않는다. 문장 대응에 어려움이 있으면 LU01~04, 수량 비교에 어려움이 있으면 LU06~09, 정보·과정 판단에 어려움이 있으면 LU10~12를 선택한다. 첫 진단에서는 기존 문항을 새 blind 시험으로 가장하지 않고, 학생이 어떤 중간 문장을 실제로 말하는지를 관찰한다.

한 학습지에는 대표 하나·경계 하나·조건 하나만 바꾼 연습 하나를 기본 묶음으로 제안한다. 다른 풀이를 제시한 학생에게는 지문 근거와 충분성을 확인한 뒤 대안 경로로 인정한다. 단원명·배열·분량의 변경은 연구 원리의 동일성 판정을 자동 변경하지 않는다.
