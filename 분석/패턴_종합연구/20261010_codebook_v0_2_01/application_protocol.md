# 외부 표본 적용/비적용 사전 판정 프로토콜

이 문서는 후속 독립 검증의 사전 규칙이다. 이번 실행에서는 검증용 6세트에 적용하지 않았다. 동결은 규칙을 사전에 고정한다는 의미이며 패턴의 타당성을 확정한다는 의미가 아니다.

## 입력과 노출 관리

동결 manifest의 SHA-256을 확인한 뒤 새 결과 폴더를 만든다. 표본 ID·분할·hold·노출 이력은 값이 제거된 `management_metadata.json`으로 확인한다. G024/G370은 제외 상태를 유지한다. G095/NM은 기존 정답·코드 노출과 이번 관리 메타데이터 재노출 이력을 가진다. 해당 실행 주체의 미노출 독립 검증에 포함하지 않는다. 다른 모델을 자동 실행하거나 표본을 임의로 교체하지 않는다.

검토자에게 본문·문항의 정본 또는 정본 연결 전사와 필요한 도표를 제공하되, 공식 답·SDSS·기존 풀이·예상 패턴은 별도 보관한다. 카드의 발견용 anchor는 훈련용 설명으로만 제공한다. 외부 표본에 어떤 카드가 예상되는지 알려 주지 않는다. 이 동결 작업 자체는 정답·정본 자료를 수집할 권한이나 검증 실행 지시를 추가하지 않는다.

## 사전 판정 순서

1. **출처 충분성:** 지문·발문·보기·필요 선지·도표를 식별한다. 원문이 없거나 관련 부분이 잘렸다면 미확인으로 저장한다. 해설의 코드명이나 답 일치만으로 적용을 확정하지 않는다.
2. **코드 없는 풀이 저장:** 새 표본을 실제 연구할 때는 기존 group barrier에 따라 group 전체의 최초 풀이를 먼저 보존한다. 선택 답·확신도·노출·정보 위치·중간 추론·비정답 판단을 저장하고 덮어쓰지 않는다.
3. **공식 답 대조:** group 전체 blind 저장 후 공식 답과 대조한다. 최초 판단 오류와 이후 정정을 별도 기록한다. 정답을 맞혔다는 사실을 패턴 적용 근거로 대신하지 않는다.
4. **최소 장면 고정:** ‘원문 근거 → 선지의 이동/확인 → 중간 조작 → 내용·역할 판정 → 발문에 따른 선택’을 사건으로 적는다. 지문 구조만 보이면 그 구조 장면만 적고 문항 활용을 추정하지 않는다.
5. **카드 대조:** 해당 카드의 최소 근거를 하나씩 충족/불충족/미확인으로 기록한다. 하위형을 선택하거나 기존 하위형에 맞지 않음을 남긴다. 새 조작을 가장 비슷한 이름에 억지로 배속하지 않는다.
6. **역할별 판정:** 구조, 문항 활용, 풀이 도움, 설명만, 경계, 미확인, 미분류를 각각 판단하여 pattern_relation에 기록한다. 한 사건의 다른 선지가 서로 다른 역할이면 choice_ids를 나누거나 별도 관계로 저장한다.
7. **반대 근거·대안 풀이:** 비적용 조건과 인접 패턴을 실제 근거로 점검한다. 같은 정답으로 가는 다른 타당한 풀이가 있으면 허용하고, 유효 경로를 필수 경로로 승격하지 않는다.
8. **잠금 후 비교:** group의 논리·독립 판정을 저장한 후에만 SDSS 등 제3자 후보를 공개한다. 기존 연구의 group 전체 독립 코드 판정 전 SDSS 공개 금지 규칙을 우회하지 않는다. 예상 패턴은 독립 적용이 잠길 때까지 공개하지 않는다.
9. **비교·보고:** 최초 적용/비적용/미확인, 검토 후 변경, 차이의 이유를 모두 보존한다. 외부 결과는 발견용 재사용 수와 분리해 계수한다. 경계·반례 때문에 조건을 바꾸려면 v0.2를 고치지 않고 새 버전으로 제안한다.

## 판정 결정표

|상황|판정과 기록|
|---|---|
|원문과 중간 추론이 있고 카드의 최소 근거·조건을 충족|해당 역할만 confirmed_new; 참조·추론·조건 체크 저장|
|충분한 자료에서 적용 조건 불성립 또는 명시 비적용 조건 확인|non_applicable_new; 필요하면 boundary_case와 배제 근거 저장|
|원문·도표 누락, 인용이 다른 선지 판단을 설명, 중간 연결 불충분|unconfirmed; 빠진 자료·미검증 단계 기록. 비적용과 구별|
|판단은 분명하나 13개 후보로 설명되지 않음|pattern_id=null, unclassified. 별도 관찰 메모는 가능하나 후보 신설·통합은 별도 연구|
|지문이 행동을 설명하나 실제 해당 행동으로 선지를 판정하지 않음|explanatory_only; 필요하면 structure_present. item_utilized 자동 부여 금지|
|특정 선지에 도움이 되지만 다른 풀이도 가능|solution_helpful 가능. necessity는 선택적/유효 경로로 기록|
|카드 조건을 모두 만족하지만 예상 판단이 실패|조건 내부 반례 후보로 보존하고 양성 활용에서 보류; 단순 경계 사례로 약화시키지 않음|
|둘 이상의 카드가 서로 다른 실질 조작을 설명|복수 패턴 허용. 같은 문항·장면 수는 중복 제거|

## 인용의 의미적 충족 점검

문자열이 원장에 존재하는지와 그 문장이 해당 선지를 뒷받침하는지는 별개의 점검이다. 새 확인을 했으면 자료의 경로·정본 수준·문단/선지·인용·중간 추론과 검토 날짜를 적는다. 원문이 없으면 ‘정본 미검증’이며 기존 해설만으로 확인 완료라고 표시하지 않는다.

이번 동결에서는 application의 `citation_audit.jsonl`에 있는 교정을 승계했다. 정본 원문과 원장은 열지 않았으며 의미적 충족을 새로 재검증했다고 보고하지 않는다. GL④ 수식의 기존 유보, KICE 편집 HWPX 연결 전사와 원 배포 지면의 차이, LEET 2011의 HWP 추출 텍스트 수준을 유지한다.

## 보류한 통합·분할과 반례

- **P04:** AA의 명시 요건, GM의 측정 기전, BK의 권한 범위를 서로 다른 하위 판단으로 유지한다. 공통 조건 검사만 같다는 이유로 전제 발견 과정까지 같다고 하지 않는다.
- **P01:** 단항 귀속과 원인 유형·관계 양 끝·평가 근거 탐색을 유지한다. 확장형이 다른 행동을 요구하면 후속 분할 근거로 기록한다.
- **P03:** 역순 비교·조건부 연쇄·상대비를 유지한다. 비교어의 공통성만으로 통합하지 않는다.
- **P07:** 중간 처리 상태·기전 순서·역사적 배치를 유지한다. E032/AJP①은 명분/실태 경계, E031/AJP②는 규정/실행 경계로 구분한다.
- **S05/P02:** 중첩은 인정하되 규범·실행의 특수 조건 때문에 통합 판단을 유보한다.
- **S01:** 약함/전무 경계는 E014/BK②에 연결한다. 갱신 전후와 비교 강도의 차이를 유지한다.
- 기존 경계 사례는 조건 밖 비적용의 예이며 강한 반례로 세지 않는다. S01~S06은 한 지문 잠정 후보 상태를 유지한다.

## 교육·창작 가치의 사후 평가

적용 수를 본 뒤 강의·교재·창작 가치를 자동 점수화하지 않는다. 강의는 학생의 관찰 가능한 행동, 교재는 설명 순서와 경계 사례의 배치, 창작은 원문 안의 조건 완결성과 유일답 확보 가능성을 별도로 평가한다. 실제 학생의 사용·오답·효과는 관찰 자료가 있을 때만 기록한다. 검증 통과 여부와 신규 문항 설계 품질도 별도 결과다.
