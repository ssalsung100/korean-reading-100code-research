현재 30개 문항군, 90문항이다. 2022·2023학년도 홀수형과 2027학년도 단일형의 전 문항군 전사를 마쳤다. 문항군별 원본 페이지와 SHA-256, 정답은 [manifest.json](manifest.json)에 기록하며, 학년도별 통합본은 전 문항군의 순서·중복·정답을 다시 검사한 뒤 승격한다.

## 승격 규칙

1. OCR과 외부 전사본은 후보 문장을 찾는 데만 사용한다.
2. 본문, 발문, 선지, `<보기>`, 수치, 기호를 공식 페이지에서 직접 확인한다.
3. 페이지 머리말·쪽 번호가 OCR 본문에 섞인 부분을 제거한다.
4. 원문의 내용 문단은 유지하되 지면의 자동 줄바꿈은 합친다.
5. 정답은 `normalized_answers.json`의 공식 정답표 대조값과 일치시킨다.
6. 파일과 공식 페이지의 SHA-256을 manifest에 고정한 뒤 자동 검사를 통과시킨다.
