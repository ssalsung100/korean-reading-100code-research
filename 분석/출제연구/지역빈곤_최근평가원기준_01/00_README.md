# 지역 빈곤 — 최근 평가원 기준 대조와 3문항 제작

**학생용 지문·5지선다 3문항, 15선지 전체 해설, 기출 대응과 자체 검토를 작성했다.** 작성일은 2026-10-22이다. 제작 기반은 [지역 빈곤 학생용 편집본](../지역빈곤_학생용편집_01/01_학생용_지문.md)이며, 이전 H/G/S 빈곤 측정 세트 개정02와 별개다.

바로 풀어 보려면 [학생용](03_학생용_지문과3문항.md) 또는 [독립풀이용.zip](독립풀이용.zip)을 사용한다. ZIP에는 학생용 Markdown 한 파일만 들어 있으며 정답·해설·제작 진단·연구 메모는 제외했다. 연구 검토는 [읽기 안내](07_연구자_읽기안내.md)에서 시작할 수 있다.

## 기준 범위와 실제 수행

핵심 기간은 **2022학년도 수능부터 2027학년도 9월 모의평가까지**다. 최신 포함 시험은 실제로 2026-09-02 시행되었으며, 저장소 마지막 연도를 추정한 것이 아니라 [공식 출제 발표](https://www.korea.kr/briefing/pressReleaseView.do?newsId=156778992)와 [정답 확정 발표](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=294&boardSeq=107212&lev=0&m=020402&opType=N&page=1&s=moe&searchType=null&statusYN=W)를 확인했다. 2027학년도 수능은 2026-11-19 예정이므로 제외했다.

15개 시험의 경제·사회 중심 지문 목록과 사회사·윤리 경계 사례를 확인하고 다음 **6세트·26문항·130선지**를 직접 심층 대조했다.

|---|---|---|
|중심 참조|2023학년도 6월 14~17|이중차분법·정책 평가|

단일 지문 다섯 편과 복합 한 세트를 동일 길이 단위로 취급하지 않았다. 2020학년도 BIS·교육청·LEET·MEET·시작 시험 이전 모평은 최근 핵심 근거에 합산하지 않았다. 준비된 자료와 기존 연구를 재사용했으며 엄격한 blind 성과나 새 기초 연구 전수 완료로 기록하지 않는다.

## 비교에서 제작으로 이어진 결정

- **정보량 부족·설명 과잉은 일괄 채택하지 않았다.** 평균→합→전체 평균은 필요한 매개이며, 대표 수치의 결론을 직접 설명하는 구성도 유지했다. 독립 규칙이 많은 복합 지문과 원고를 같은 단위로 비교하지 않았다.
- **P3 삭제 주장은 기각하고 실제 출제 활용을 보강했다.** 새 2번은 빈곤율×빈곤층 평균으로 지역 지수를 구한 뒤 인구를 반영하여, 다른 지역 지수와 같은 기여분의 양립을 묻는다.
- **지급 효과의 조건을 국소 보완했다.** 기존 마지막 문단을 둘로 나누고, 빈곤선까지 지급된 금액만 부족액을 줄인다는 한 문장을 추가했다. 새 3번은 같은 총액을 지급해도 초과 지급 여부에 따라 지수 감소폭이 달라지는지를 묻는다.
- **실제 검산 수정 1건을 반영했다.** 2번④의 비교 방향을 바꾸어 전체 인구 가중치와 빈곤 인구 가중치를 혼동하는 오답 경로가 선지의 진위에 영향을 주도록 했다.

세 문항의 정답은 ④·③·⑤다. 기본 확인과 적용 문항을 구별하고, 짧고 충분한 대안 풀이를 인정했다. 정답 선택에 필요하지 않은 전체 표 계산을 평가 성과로 과장하지 않았다.

## 완료 상태와 한계

학생용 문안, 전체 해설, 기출 대응, 자체 검토와 저장을 완료했다. 정답이나 필수 근거를 미해결로 남긴 문항은 없다. 그러나 학생 난도·오답 선택률·학습 효과·평가원과의 동등 품질은 검증하지 않았다. 여섯 세트의 목적 표집에서 얻은 경제·사회 관찰이며 모든 분야의 규칙이나 빈도 조사로 확대하지 않는다.

가중 평균·구획 불변·역복원 자체가 최근 여섯 세트에서 반복 출제되었다는 주장은 하지 않는다. 이 관계들은 신뢰 가능한 기존 빈곤 측정 근거를 재사용한 새 소재의 구현이고, 기출에서 계승한 것은 문서에 특정한 대상·조건·비교 축을 보존하는 판단이다. 지원안은 정의상 변화의 가상 비교이며 현실 정책의 인과효과 추정이 아니다.

사용자 지정 실행 설정을 변경하거나 다른 모델을 자동 호출하지 않았다. 모델 비교, Git push, 기존 원장 전체 해시 검사는 하지 않았다. 기존 연구·원장·v1·동결 자료와 G024/G370 hold는 수정하지 않았다. 이번 판단과 진행은 이 폴더의 `연구판단_raw.jsonl`에 남겼다.
