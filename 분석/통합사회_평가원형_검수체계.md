# 통합사회 평가원형 자동·수동 검수 체계

## 1. 사실 검수

- [ ] 통합사회 교과서·개념 지도와 충돌 없음
- [ ] 심화 경제 개념은 기초 개념을 건너뛰지 않음
- [ ] 수치·법률·제도·현황은 출처 또는 가상 자료임을 표시
- [ ] 사상가의 입장을 다른 이론과 혼합하지 않음

## 2. 지문 구조 검수

- [ ] 공백 제외 1050자 이상인가?
- [ ] 문단이 4~6개인가?
- [ ] 중심 개념이 정의됨
- [ ] 연계 개념의 기능이 중심 개념과 연결됨
- [ ] 기초→핵심→심화 설명 순서를 어기지 않음
- [ ] 외부 선행 개념은 지문 안에서 재정의됨

## 3. 문체 검수

- [ ] 논리 코드 이름을 본문에 노출하지 않음
- [ ] 불필요한 소제목·번호식 나열 없음
- [ ] 같은 접속어 반복 없음
- [ ] 교과서 문장을 길게 복제하지 않음

## 4. 문항 검수

- [ ] 문항은 정확히 4개이고 각 5선지인가?
- [ ] 어휘 문항이 없는가?
- [ ] 정답 유일성
- [ ] 본문만으로 해결 가능
- [ ] 오답마다 실패 이유 존재
- [ ] 정답 위치 편중 방지
- [ ] 부정 발문 남발 금지
- [ ] 보기 문항 최소 1개
- [ ] 고난도 문항 최소 1개

## 실패 코드

|코드|의미|재생성 지시|
|---|---|---|
|F01|사실 충돌|충돌 문장만 근거 범위 안에서 수정하고 문항 정답도 재검사|
|S01|구조 관계 미실현|설계 코드에 필요한 두 항의 관계 문장을 보강|
|S02|학습 순서 역전|심화 개념 앞에 필요한 기초 정의를 이동·삽입|
|L01|길이 부족|새 개념을 추가하지 말고 작동 과정·경계 조건을 확장|
|W01|평가원 문체 이탈|표지어 남발·목록식 문장을 연속 설명으로 재작성|
|Q01|복수 정답|오답 하나의 조건·범위·주체를 수정하여 실패 이유를 유일하게 만듦|
|Q02|본문 근거 부족|본문에 판정 기준을 보강하거나 외부 지식 요구 선지를 교체|
|Q03|오답 무근거|각 오답에 하나의 명시적 오류축을 부여|
|Q04|보기 표면 대응|새 사례의 조건을 바꾸어 개념 적용 과정이 필요하게 수정|
|C01|배정 개념 누락|누락 개념을 지정 역할에 삽입하고 관련 문항·해설까지 동기화|

## 재생성 지시문 템플릿

```text
[실패 코드] {code}
[실패 위치] {location}
[관찰 사실] {evidence}
[수정 범위] 실패한 문단/문항만 수정
[보존 조건] 통과한 문단, 중심 개념, 정답 번호는 보존
[수정 지시] {instruction}
[재검사] 동일 체크리스트를 다시 적용
```

## 합격 판정

- 자동 검사 항목이 모두 통과하고, 사실·정답 유일성·문체에 대한 수동 검토가 완료되어야 최종본으로 이동한다.
- 실패 시 세트 전체를 다시 쓰지 않고 실패한 문단 또는 문항만 수정한다.
