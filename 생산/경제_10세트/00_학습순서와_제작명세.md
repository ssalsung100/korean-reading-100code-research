# 통합사회·경제 배경지식 평가원형 10세트 제작 명세

## 0. 제작 원칙

고난도는 정보 부족에서 만들지 않는다. 정답 판단에 필요한 정보는 충분히 제공하되, 해당 정보가 서로 떨어져 있거나 다른 표상으로 제시되고, 적용 대상·시점·범위를 구별하거나 경쟁하는 관계 중 적절한 경로를 선택해야 하도록 설계한다.

전제가 부족해서 풀 수 없는 문항은 어려운 문항이 아니라 성립하지 않은 문항이다. 문항의 난도가 올라갈수록 정답의 근거는 더 명확해야 하며, 어려움은 그 근거를 찾고 결합하고 전환하는 과정에서 발생해야 한다.

## 1. 전체 경제 학습 순서

통합사회와 심화 경제 자료의 개념을 선수 관계에 따라 다음과 같이 배열한다.

1. 희소성·경제 문제 → 합리적 선택 → 기회비용 → 한계 분석
2. 경제 활동과 국민 경제 순환 → 가계·기업·정부 → 경제 체제
3. 수요·공급 → 시장 균형 → 연관재 → 탄력성 → 동시 변동
4. 소비자·생산자 잉여 → 가격 규제 → 조세·보조금 → 독과점
5. 시장 실패 → 외부 효과·공공재·정보 비대칭 → 교정 정책 → 정부 실패
6. 국내 총생산 → 명목·실질 지표 → 물가 → 고용 → 경기 변동
7. 총수요·총공급 → 재정 정책 → 통화 정책 → 정책 조합
8. 기회비용 → 비교 우위 → 특화 → 교역 조건 → 관세와 무역 후생
9. 외환 수요·공급 → 환율 → 교차 환율 → 경상 수지·자본 이동
10. 소득·지출 → 금융 자산 → 수익·위험 → 분산 투자 → 복리·실질 수익률
11. 재정 수입·지출 → 비례·누진·역진적 부담 → 복지와 재분배
12. 기업의 생산·비용·수입 → 이윤 극대화 → 기업가 정신·사회적 책임

## 3. 공통 생성 규격

- 각 세트는 지문 1개와 어휘 문항을 제외한 5지선다형 4문항으로 구성한다.
- 첫 문단 또는 연결 문단에서 통합사회 핵심 개념을 정의한다.
- 통합사회 개념은 첫 문단의 장식으로만 두지 않는다. `일반 원리→설명하기 어려운 상황→심화 개념`, `구체적 현상→공통 관계→개념 정의`, `두 판단의 충돌→구별 기준` 가운데 적절한 도입 방식을 사용한다.
- 핵심 문항은 최소 두 개의 정보나 두 단계 이상의 관계를 결합하되, 모든 문항을 단선적인 `A→B→C` 형태로 만들지 않는다.
- 적어도 한 문항에는 같은 평가 대상에 상반된 효과를 주는 경쟁 경로 또는 조건에 따른 경로 선택을 포함한다.
- 정답에 필요한 전제는 지문 또는 `<보기>` 안에 둔다. 다만 전제가 서로 떨어져 있거나 다른 표현·표·그래프로 제시될 수 있다.
- 배경지식은 풀이 속도를 높일 수 있으나 정답 판단의 필수 조건이 되지 않게 한다.
- 각 세트 끝에 문항별 근거, 선지 변형 방식, 품질 점수, 난도 점수, 정보 충족도를 기록한다.
- 품질과 난도를 각각 100점 척도로 분리한다. 품질 85점 이상, 난도 80점 이상을 기본 통과선으로 삼는다.
- 복수 정답, 핵심 사실 오류, 외부 지식 없이는 복원할 수 없는 전제 누락은 다른 항목의 점수로 상쇄하지 않는다.

### 3.1 네 문항의 역할

다음 기능을 한 세트 안에 분산하되 번호는 고정하지 않는다.

1. 개념·관계 통합형
2. 지문 구조·적용 범위 판별형
3. 표·그래프 또는 새로운 사례 적용형
4. 경쟁 경로·복합 추론형

네 기능을 기계적으로 하나씩 배정할 필요는 없지만, 같은 문장·같은 관계·같은 계산 절차를 두 문항 이상에서 반복하지 않는다. 적어도 한 문항은 새로운 상황으로의 적용을, 한 문항은 떨어진 정보의 결합을 요구해야 한다.

### 3.2 경제 모형의 조건

경제 명제를 제시하거나 선지로 변형할 때 다음을 확인한다.

- 다른 조건 가운데 무엇이 고정되는가.
- 가격 변화와 수요·공급 자체의 변화 가운데 무엇을 뜻하는가.
- 단기와 장기 중 어느 기간을 분석하는가.
- 개인·기업·정부·사회 전체 가운데 판단 주체는 누구인가.
- 가격·수량·총액·후생 가운데 판단 대상은 무엇인가.
- 소국·대국, 완전 정보·정보 비대칭 등 모형의 적용 범위가 명시되었는가.

조건을 생략하면 참·거짓이 달라지는 명제는 조건을 본문이나 `<보기>`에 직접 제시한다.

### 3.3 시각 자료

- 시각 자료가 포함된 세트에서는 적어도 한 문항의 정답 판단에 자료의 구체적인 배치·수치·형태가 필요해야 한다.
- 자료를 읽는 일반 원리는 지문이나 자료 조건으로 복원할 수 있어야 한다.
- 본문에서 이미 확정한 결론을 그림의 설명문으로 반복하지 않는다.
- 그래프의 축척·기준점·이동 전후·고정 조건을 판정할 수 있게 한다.

### 3.4 선지 생성

- 오답은 정답과 전제·용어·중간 관계를 가능한 한 많이 공유하고, 주체·시점·범위·방향·귀속 가운데 핵심 관계 하나를 변형한다.
- 한 오답에 독립적인 오류를 여러 개 넣어 다른 이유로도 제거할 수 있게 하지 않는다.
- 정답만 길거나 조건이 세밀해지는 문장 단서를 통제한다.
- 공유 정보량이 높더라도 다른 해석으로 정답이 될 가능성이 생기면 즉시 폐기한다.

### 3.5 문항 난도 분산

기본 권장 분포는 `중상 1＋상 2＋최상 1`이다. 주제에 따라 달리 배치할 수 있으나 다음은 지킨다.

- 세트 안에 판별 부담이 다른 문항이 세 단계 이상 존재한다.
- 최고난도 문항은 단순 산술이 아니라 관계 결합이나 표상 전환을 포함한다.
- 네 문항이 같은 계산 또는 같은 범위 판별을 반복하면 탈락시킨다.

## 4. 품질 평가 축

1. 사실·모형 정확성 15: 개념·수치와 적용 조건이 정확한가.
2. 정보 충족도·정답 유일성 15: 지문 안에서 전제를 복원할 수 있고 정답이 하나인가.
3. 지문 구조·문체 20: 통일된 논리 축, 지연 회수, 평가원식 서술을 갖추었는가.
4. 문항·선지 30: 추론의 질, 오답의 독립성, 정답 단서 통제, 문항 역할·난도 분산이 적절한가.
5. 배경지식 학습 가치 15: 통합사회 진입 개념에서 심화 개념으로 이어지고 다른 상황에 전이되는가.
6. 형식·시각 자료 5: 표와 그래프가 정확하고 실제 판단에 사용되는가.

정보 충족도와 정답 유일성은 난도 점수가 아니라 문항의 성립 조건이다. 복수 정답이나 정답 불성립이 있으면 세트 품질은 최대 69점, 외부 지식 없이는 정답을 확정할 수 없으면 최대 74점, 핵심 사실이나 모형 조건에 오류가 있으면 최대 59점으로 제한한다.

## 5. 난도 평가 축

1. 개념 부담 10: 새 개념의 수와 정의 부담
2. 기능적 재등장·관계 복잡도 15: 같은 개념이 다른 기능으로 회수되고 관계들이 서로 제한하는 정도
3. 직선 추론 단계 15: 정답까지 필요한 관계 변환의 수
4. 경쟁 경로 15: 상반된 효과나 복수 경로 가운데 조건에 맞는 경로를 선택하는 부담
5. 정보 간 거리 10: 필요한 전제가 떨어져 제시되는 정도
6. 표상 변환 15: 문장·수식·표·그래프 사이의 변환 부담
7. 적용 대상·시점·범위 전환 10: 개인/전체, 단기/장기, 명목/실질 등의 전환 부담
8. 선지 근접도 10: 정답과 오답이 공유하는 정보와 핵심 변형의 미세성

개념 부담은 용어 수만으로 높이지 않는다. `새 개념 수＋동일 개념의 기능적 재등장＋개념 간 관계`를 함께 보되 이를 기계적인 개수 경쟁으로 사용하지 않는다. 관계의 수보다 서로 경쟁하거나 적용 범위를 제한하는지가 중요하다.
