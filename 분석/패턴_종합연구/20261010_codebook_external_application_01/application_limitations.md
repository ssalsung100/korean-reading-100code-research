# 적용의 한계와 독립성 기록

대상은 동결 코드북 v0.2를 G064·G095·G119·G157·G350·G310의 21문항에 직접 적용하는 작업이다. 기존 100코드의 전수 분류, Sol stage1과의 일치율 산출, SDSS 태그 대조, 코드북 개정, 새 연구 frontier 소비는 수행하지 않았다. 최신 요청의 고정 범위·기존 기록 미열람·다른 모델 호출 금지를 우선했다. 기존 연구의 Astra/Luna 주기와 공용 queue를 수정하거나 Luna를 호출하지 않았다. 이번 판단은 별도 폴더의 최초 풀이 raw와 상세 annotation에 보존한다.

## 실제 수행자·effort

현재 세션의 시스템상 정체성은 GPT-6 기반 OpenAI Codex이다. 런타임의 정확한 모델 ID와 reasoning effort는 도구 응답·환경변수에 노출되지 않아 미확인이다. `CODEX_MODEL`, `CODEX_REASONING_EFFORT`를 확인했으나 값은 제공되지 않았다. 현재 세션을 Astra 또는 gpt-6-astra의 특정 effort로 확인했다고 기록하지 않는다. 코드북의 작성자 이름과 이번 실행 모델의 정체성은 별개이다. 다른 모델·서브에이전트·fresh TUI는 호출하지 않았다. 이 제한은 freeze_manifest.json에도 null과 설명으로 보존한다.

## 절차 독립성과 과거 노출

동결 코드북 JSON은 열람했다. 따라서 코드북을 전혀 모르는 blind 패턴 발견 실험이 아니다. 원문 풀이 전에 기존 Sol stage1 독립 풀이·후보 목록, 기존 100코드 풀이·정답 기록, SDSS 및 sealed 답 자료를 읽지 않았으며 결과 동결 후에도 비교 자료를 공개하지 않았다. 공식 정답도 미열람이다. `initial_solution_raw.jsonl`의 선택은 원문 근거의 독립 판단이며 공식 정답으로 인증된 값이 아니다. 정답률을 계산하거나 높은 선택 확신도를 패턴 타당성으로 대체하지 않는다.

G095의 이전 노출 이력은 사용자가 명시했다. NK·NL·NM·NN·NO 각각의 이전 열람 범위, 정답 기억 여부, 영향 정도는 확인하지 못했다. 현재 세션에서 과거 판단을 열지 않았다는 절차상 사실은 있으나 엄격한 미노출 성과라고 주장하지 않는다. 다른 다섯 지문도 현재 세션의 사전 열람이 없다는 사실과 과거 전 생애 노출 여부 미확인을 나누어 기록한다. G095의 이력을 모든 지문의 노출로 확대하지 않는다.

## 열람 범위

의미 내용으로 읽은 자료는 AGENTS.md, 지정 codebook_v0.2.json, 21개 blind-only 원문 JSON의 지문·발문·보기·선지, RX_choice_table.md, G350_visual01.md·visual02.md·emphasis_restored.md, G350 공식 인쇄2·3쪽 이미지이다. codebook은 처음 전체 출력이 잘렸고 이후 13개 카드의 원칙·하위형·최소 증거·적용/비적용 조건·경계 필드를 모두 다시 확인했다. 열람되지 않은 코드북 상세 필드를 모두 읽었다고 주장하지 않는다. 카드의 기존 사례 이름은 코드북에 포함된 설명 범위에서만 보았고 해당 기존 풀이 파일로 이동하지 않았다.

prepared_backlog/manifest.jsonl는 6개 group의 case ID, blind 경로, 결손 메타데이터를 필드 선택으로 읽었다. 해당 manifest의 이미 consumed된 상태도 표시됐지만 답·SDSS 내용은 출력하거나 읽지 않았다. 이를 과거 전체 세션의 미노출 인증으로 사용하지 않았다. 코드북 동결 폴더의 다른 파일은 수정 검증용 바이트 해시만 계산했으며 의미 내용은 열지 않았다. 디렉터리 파일명 검색에 Sol stage1의 경로가 보였지만 그 분석·코드·source_inventory 파일 내용을 열지 않았다.

G350의 공식 페이지2에는 앞 지문의 문항2·3이 같은 이미지에 부수적으로 나타났다. 해당 부분을 마스킹한 blind 그림만 보았다고 과장하지 않는다. 앞 지문을 분석·태깅하거나 대상 범위에 편입하지는 않았다. 기존 솔루션·정답의 노출은 아니다.

## 적용 판정의 범위

‘적용’은 명시한 풀이 경로에서 원문 구조가 문항 판단에 실제 쓰였다는 뜻이다. 정답 직접 결정과 비정답 선지 검토를 role에 나누었다. ‘구조상 존재’는 등장하나 그 행동을 수행한 것까지 확정하지 않았다는 뜻이다. ‘경계·비적용’은 근거가 있는 비해당/오적용 경계이며 ‘불확실’은 최소 증거가 부족한 후보를 유보했다는 뜻이다. 잔여는 unclassified로 별도 기록한다. 활용된 패턴이 모든 풀이에서 필수였다고 주장하지 않는다.

P01의 평가 행동과 구성 귀속, P02의 견해 비교와 진/위 분류, P03의 정성 방향과 분모 고정, P04의 기전·방법 전제와 논증 범위, P07의 기전 순서와 역사적 지시 배치는 서로 다른 하위 조작이다. 코드북에 정확히 맞는 하위형을 확정하지 못한 상위 적용에는 subtype_id=null을 남겼다. 이를 기존 하위형의 검증 완료로 집계하지 않는다. 구조 mode는 분석적 구현/내용상 설명을 표시하며 단순히 기술 대상이 원리를 설명한다는 이유로 학생이 그 행동을 직접 수행했다고 계수하지 않는다.

미표시된 다른 카드의 비적용은 제시된 발문·선지에서 그 조작 장면이 판정 대상이 아니라는 범위이며 패턴별 이유를 JSONL에 적었다. 자료가 빠져 최소 증거를 확인하지 못한 상황을 자동으로 비적용 처리하는 규칙은 아니다. 원문 결손·불확실 판단은 따로 남겼다. 문자에 해당 말이 없다는 것만으로 세계에 그 구조가 없다고 주장하지 않는다. S01·S02·S04·S05·S06에 새 활용을 억지 배속하지 않았다. S03은 이번 세트의 YR에서만 수행됐으므로 다른 새 지문에 대한 반복은 미확보이다.

## 검증의 강도

자동 검사는 정확한 6group/21case/105선지, 필수 필드, 근거 ID 해소, 텍스트 인용의 원문 문자 범위, 입력 해시 불변, 코드북 SHA 일치, 하위형 ID의 존재, 원본·동결 폴더 불변, 산출물 해시를 확인한다. 이는 문서 누락·잘못된 경로·인용 불일치·동결 오류를 잡는 형식·추적성 검사이다. 인용이 관련 전제를 충분히 지지하는지, 대안 풀이가 더 좋은지, 패턴의 의미와 경계가 타당한지, 모든 판단이 공식 정답과 일치하는지는 자동 검사로 보증하지 않는다.

현재 모델은 모든 문항의 선지를 원문과 대조하고 반례·대안 경로를 기록했다. 그러나 별도 사람 또는 다른 모델의 의미 검증은 수행하지 않았다. 독립 평가자 간 일치도도 없고 이론적 타당성의 최종 검증 완료라고 선언하지 않는다. 선택 확신도는 현재 판단의 주관적 값이다.

## 교육·창작·빈도 전이

고정된 목적 표본이므로 활용 건수는 이 세트의 장면 추적용 기술 통계만 허용된다. KICE·LEET·MEET 전체 빈도·대표성·표본 추출율·통계적 일반화를 추정하지 않는다. G350을 제외한 시험 계열은 이번 허용 입력만으로 독립 정본 확인하지 않았으므로 기관별 구현 차이의 확정 비교를 만들지 않았다.

교육 노트는 원문에서 수행 가능한 행동을 제안하며 실제 학생의 흔한 오답·학습 향상을 보고하지 않는다. 생성 제약과 복수정답 위험은 논리 검토 제안이며 새 창작 지문·문항을 만들어 외부 평가한 것이 아니다. 다른 분야 전이는 새 원문에서 같은 최소 증거와 경계가 확보될 때만 다시 검토해야 한다.

원본 파일, 기존 코드북 및 동결 폴더는 수정하지 않았다. 자동 Git push, 외부 게시, 메시지 전송은 수행하지 않았다. 저장 결과의 해시는 이번 적용 내용을 고정하며 타당성의 인증 점수가 아니다.
