# PA14 — 항암제의 작용

자료: 2016학년도 9월 B 25~26. [전사](../근거/지문만/PA14.md). P3/P4는 한 문장 중간의 전사 단절이므로 합친다. 치료 지침이 아닌 기출의 기전 설명 분석이다.

## 지문 자체 분석

질문은 **암의 증식·성장 과정 중 어디에 개입하느냐에 따라 항암제의 작용과 적용 범위가 왜 달라지는가**이다. 독자는 약 이름 목록에서 표적·개입 단계·효과 범위의 관계로 이동한다.

|단위|내용·역할|도입 이유와 재사용|
|---|---|---|
|P1|세포 분열 방해와 정상 세포 손상; 선택적 표적의 목적|일반적 증식 억제와 선택적 억제의 차이를 설정|
|P2|신호 왜곡에 의한 증식, 혈관이 필요한 종양 성장|두 약제를 비교할 공통 생물학적 과정과 분기점 제공|
|P3+P4|암 종류별 신호 경로, Bcr-Abl, 이마티닙|특정 경로를 막는 기전이 적용 범위의 좁음과 연결|
|P5|산소·영양 공급, VEGF, 항체 결합, 여러 암의 효과|공통 성장 조건을 표적으로 삼는 기전이 더 넓은 적용과 연결|

그래프: P1→P2[선택성의 필요], P2→{P3+P4,P5}[개입 지점의 병렬 분기]. 한 약이 실패하여 다음 약이 등장했다고 읽을 근거는 없다. 각 이름은 ‘어디를 막는가’에 붙는다.

삭제·이동: P3+P4와 P5의 순서는 바꾸어도 기전 설명이 성립한다. P2를 지우면 각각의 약효 설명은 남지만 증식과 종양 성장의 다른 단계를 비교하기 어렵다. P5의 혈관 연결·산소 공급 설명을 지우면 왜 혈관을 막는 것이 암 성장 억제인지 인과 고리가 소실된다. 95% 수치는 특정 표적 존재의 범위를 한정하며, 숫자를 없애도 대표 작용 설명은 유지된다.

문항 없이도 선택성/적용 범위는 학문적으로 다른 구별이다. 특정 암에만 효과가 있는 약이 정상 세포에 덜 작용하도록 설계되었다는 사실과 ‘모든 암에 효과적’이라는 평가는 같지 않다. 완성 체계는 암 성장 과정 위에 얹힌 두 차단 경로다.

기출의 생의학 내용을 최신 치료의 정확한 목록이나 처방으로 확장하지 않는다. 제작에 옮길 수 있는 것은 전문 용어 수가 아니라 공통 과정·개입 위치·효과 범위의 대응이다.

## 문항 연결 — 25·26번

25번 최초 선택 ⑤, 확신 높음. P3+P4의 변형 효소와 P5의 분비 성장인자를 대조한다. ②의 직접 세포분열 방해/혈관 공급 차단은 경로가 다를 뿐 최종 증식 억제와 비억제로 나뉘지 않는다.

26번 최초 선택 ②, 확신 높음. 시험관 외부 액체에 영양분이 있어도 종양 내부까지 공급하는 혈관 조건이 없다. 증식 신호와 성장에 필요한 공급 조건은 별도이므로 Bcr-Abl을 더하면 크게 자란다는 결론은 지지되지 않는다. 본문은 새 실험 상황의 결과를 직접 말하지 않았고 P2와 P5의 필요 조건을 학생이 연결한다.

특정 암의 신호 단백질과 공통 성장 조건의 분리는 비교표 이상의 기전 이해다. 이 정보는 문항이 없어도 두 약의 적용 범위 차이를 설명하는 데 필요하다. 외부 공급량과 실제 조직 도달을 구별하는 원리는 이 지문에서 전이 후보가 되지만 모든 생명 현상을 혈관으로 환원할 수는 없다.
