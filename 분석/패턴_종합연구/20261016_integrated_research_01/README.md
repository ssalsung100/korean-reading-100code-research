- BQE⑤의 단위 오류와①의 차원은 맞지만 실제 분모가 틀린 오류를 대비했다. 단위 일치를 식의 충분조건으로 가르치지 않는다.
- ALR·ALU·BRX의 제목·강조·전개 요구와 문학 기법의 단순 사용 여부를 구별했다. BRW는 실제 작품의 깊이가 아니라 제시된 감상 행동을 평가하며 공식 [B] 범위와 예비시험 정본 연결을 유지했다.

- AQM·ASN·ASW에서는 특정 장치·행동의 기능과 전체 주제·정서를 구별했다. ASN의 해석 유보를 유지하고, 제작 메모의 두려움 감추기를 원선지의 두려움 떨쳐 버리기와 동일시하지 않았다. ASW③의 마찰 회피도 진정한 본업 관심을 전부 위장으로 만들지 않는다.

- DEV101의 현행 연결 제거를 유지했다. 목적/수단이 지문에 존재한다는 사실과 문항이 중간 수단을 최종 목표로 오인하는 연산을 이용한다는 판단을 구별했다.
- ATY에서 아스피린의 진통 기능을 부정하지 않았고, AVL에서 창호의 차단 기능을 부정하지 않았다. 공통 기능은 완전 대체를, 기능의 존재는 목적 우선성을 각각 보장하지 않는다.
- AVK·AVL의 목적 변경만으로 선지 정오가 반드시 뒤집히지는 않는다. 남아 있는 형상 조건·수단 선택의 이유까지 검토하도록 제작 효과를 근거 소실·미확정으로 분리했다.

새 통합본에서 아직 직접 비교하지 않은 범위는 **1,604문항·2,105장면 기록**이다. 이는 기존 연구를 미완료로 되돌리거나 그 문항을 다시 전부 풀라는 뜻이 아니다. 기존 완료 연구를 필요한 원리별로 연결할 남은 범위다. 93개 유보를 전부 해소할 때까지 다른 명확한 장면의 활용을 멈추지 않는다.

DEV101의 ATO·ATY·AVH·AVK 네 근거를 모두 직접 대조했다. 같은 건축 지문의 AVL도 사진과 함께 비교했다. 다음 첫 비교는 **AVV·AVX·BAX(DEV105)**이며 세 원문 직접 비교는 미착수다. 이어 DEV111의 BCT·BDN·BEA·BEB를 검토한다. 이는 다음 전선이며 최종 목차가 아니다. KICE 우선 생성 근거 원칙을 유지하고 시험별 표본 수로 교재 중요도를 결정하지 않는다.

재개할 때 이 README와 체크포인트를 읽고 필요한 원문만 선택한다. 이미 반영된 backfill 수정 이력을 옛 raw에 다시 적용하지 않는다. 기존 590문항 전체를 새 전선지 해설로 만드는 작업도 수행하지 않는다. 대표·경계 사례에서 이번에 보완한 부분만 깊이가 늘었으며 나머지 분석 깊이 차이는 남는다.

연구자 피드백은 현재 전부 미검토다. 향후 답변은 문체뿐 아니라 묶음·중요도·설명 순서·적용 범위를 바꾸는 입력으로 반영한다. 학생 질문과 강의 경험은 별도 출처 종류로 추가하며 기출 표본 수에 합산하지 않는다.
