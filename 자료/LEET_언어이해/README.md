# LEET 언어이해 기출·정답 원본

## 출처와 범위

법학적성시험 공식 홈페이지의 공개 기출문제 게시판에서 언어이해 게시물을 전수 확인해 내려받았다.

- [공식 LEET 기출문제 게시판](https://leet.uwayapply.com/board/BoardList.htm?board_id=84)
- 범위: 2009학년도 예비시험, 2009~2027학년도 LEET 언어이해
- 각 회차의 홀수형·짝수형 문제지와 정답표를 원본 파일로 보관
- 게시판에 홀·짝 구분이 없는 2027학년도 문제지는 `question`으로 표시

## 파일

- `manifest.json`: 게시물 URL, 첨부파일 URL, 원문 파일명, 종류, 크기, SHA-256
- `normalized_answers.json`: 정답표를 문항 번호-선지 번호로 정리한 기계 판독용 색인
- `extracted_assets_manifest.json`: 텍스트·그림·페이지 렌더링 추출 목록과 원본 연결 정보
- `검증/텍스트_전수검증_v1.md`: 원본별 재추출 일치 여부와 현재 사용 가능 범위
- `검증/코퍼스_검증게이트_v1.md`: 원본 해시·파생 파일·정답 형식·OCR 격리 자동 검증 결과
- `검증/OCR_초안_구조검증_v1.md`: OCR 파일 완결성과 원시 TSV 혼입 여부. 철자 검증서는 아님
- `검증/PaddleOCR_초안_구조검증_v1.md`: 2022·2023·2027 고해상도 PaddleOCR 초안의 원본/페이지 해시, 15쪽 완결성, 정본 격리 검사
- `검증/작업형_시각자료_검증_v1.md`: 작업형 3개 문제지에서 분리한 표·그래프·도식의 원본·결과 해시, 좌표, 크기, 누락 검사
- `검증/공식페이지_대조완료_전사검증_v1.md`: 공식 페이지 대조 완료 문항군의 파일·페이지 해시, 문항별 선지 수, 공식 정답 일치 검사
- `검증/QZip_반복지문_불일치_v1.md`: 2022·2023 외부 반복 전사본의 내부 불일치 후보. 공식 검증 자료가 아님
- `검증/QZip_Paddle_공식페이지_대조대기열_v1.md`: 2022·2023 불일치 후보를 공식 페이지 위치에 정렬한 수동 검토용 목록
- `검증/2027_이중OCR_공식페이지_수동대조대기열_v1.md`: 2027 Tesseract·PaddleOCR 차이와 저신뢰 토큰을 이용한 공식 페이지 검토 순위
- `검증/공식페이지_확정교정_v1.md`: 공식 페이지 이미지를 직접 판독하고 실제 페이지 SHA-256을 확인한 교정 원장
- `검증/HWP_레이아웃_검증상태.md`: HWP 자동 번호·표·그림 배치의 미검증 범위와 렌더링 시험 결과
- `검증/verified_image_answer_overrides.json`: 공식 정답표 페이지를 눈으로 대조하여 전사한 이미지형 정답표
- `게시판/`: 공식 게시판 페이지 원본 HTML
- `원본/{학년도}/`: 공식 첨부파일 원본
- `텍스트/{학년도}/`: 원본의 텍스트 층에서 직접 추출한 검색용 Markdown. 이미지형 PDF에는 추정 OCR 문장을 넣지 않음
- `이미지/{학년도}/`: HWP BinData 및 PDF 내장 이미지 추출본
- `표/{학년도}/`: HWP의 표를 별도로 추출한 Markdown
- `페이지/{학년도}/`: 텍스트가 없는 스캔 PDF의 페이지 전체 PNG 렌더링
- `시각자료_원본/`: 2022 홀수형·2023 홀수형·2027 단일형 공식 페이지에서 전수 확인해 자른 표·그래프·도식 13개와 출처 해시·좌표 목록
- `전사_검수완료/`: 공식 페이지를 직접 읽어 문장·선지까지 대조한 문항군별 Markdown. 완결된 문항군만 둠
- `OCR_초안/{학년도}/`: 이미지형 PDF의 비정본 OCR 초안. 공식 페이지 대조 전에는 분석 데이터로 사용 금지
- `_중복_초기다운로드/`: 첫 분류 실행에서 생성된 중복 파일(복구 가능한 보관용)

총 20개 언어이해 게시물에서 59개 파일을 확보했다.

| 종류 | 수량 |
| --- | ---: |
| 홀수형 문제 | 19 |
| 짝수형 문제 | 19 |
| 단일형 문제 | 1 |
| 정답표 | 20 |

2009~2021 자료는 HWP가 포함되어 있고, 2022학년도 이후에는 PDF가 주로 제공된다. 원본 형식은 변환하지 않고 그대로 보관했다.

정답표 정규화 결과는 `normalized_answers.json`에 기록했다. 2009학년도 예비시험부터 2021학년도까지의 HWP 정답표와 2026·2027학년도 PDF 정답표는 원본의 텍스트 또는 표에서 직접 추출했다. 2022~2025학년도 정답 PDF는 이미지형이므로 OCR로 추정하지 않고, 공식 페이지 렌더링을 눈으로 대조하여 홀수형·짝수형 각 30문항을 전사했다. 이 8개 정답표는 `verified_visual`, 나머지 직접 추출 정답표는 `parsed`로 구별한다. 2027학년도는 홀·짝 구분이 없는 단일 정답표로 기록했다.

문제지와 정답표의 파생 추출물은 `extracted_assets_manifest.json`에서 원본별로 확인할 수 있다. 전체 59개 원본에 대해 검색용 Markdown을 만들었고, 내장 그림 411개, HWP 표 591개, 이미지형 PDF의 페이지 렌더링 83쪽을 보관했다. 2022·2023학년도 문제지와 2022~2025학년도 정답표, 2027학년도 문제지는 텍스트 추출이 되지 않는 이미지형 PDF이다. 2027학년도 PDF의 일부 내장 이미지는 글줄 단위의 작은 이미지이므로, 해당 회차는 `페이지/2027/`의 페이지 렌더링을 우선 사용한다.

## 검증 상태와 사용 규칙

- `pass_direct_pdf_text`: 2024~2026학년도 문제지 6개. 같은 공식 PDF에서 다시 추출한 본문과 Markdown 본문이 문자 단위로 일치한다.
- `pass_direct_hwp_text_layout_pending`: 2009학년도 예비시험~2021학년도 문제지 28개. HWP 텍스트 스트림의 재추출 결과와는 문자 단위로 일치하지만, 자동 문항 번호와 표·그림의 위치는 별도 자산을 함께 대조해야 한다.
- `image_only_no_canonical_text`: 2022·2023·2027학년도 문제지 5개. 공식 페이지 이미지가 정본이며, 검증 전 OCR 문장은 정본 Markdown에 넣지 않는다.
- `answer_key_parsed`: 정답 출처 20개 전부가 직접 추출 또는 공식 이미지 시각 대조를 거쳤다는 뜻이다. 개별 전사 방식은 `normalized_answers.json`의 `status`와 `method`에서 확인한다.

`pass_direct_*`는 추출기가 원본 텍스트를 재현했다는 판정이지, 원문 전체의 시각적 배치까지 사람의 눈으로 교정했다는 뜻이 아니다. 특히 `layout_pending` 자료와 OCR 초안은 표·그림·문항 번호를 원본 페이지와 대조하기 전에는 완전한 지문·문항 데이터로 취급하지 않는다.

### 이미지형 문제지 검증 진행 상황

- 2022 홀수형, 2023 홀수형, 2027 단일형은 공식 PDF를 3배로 렌더링한 PaddleOCR 보조 초안 15쪽씩이 완결되었다. 구조 감사 결과는 3개 시험지 모두 오류 0건이다.
- 2022·2023은 외부 반복 전사와 OCR의 차이를 공식 페이지에서 직접 확인하고 있으며, 2027은 Tesseract·PaddleOCR의 차이 및 저신뢰 위치를 공식 페이지에서 직접 확인하고 있다.
- 공식 페이지로 확인한 교정 항목은 `검증/공식페이지_확정교정_v1.md`에만 기록한다. 이 원장은 부분 검증 기록이며, 여기에 항목이 있다고 해서 해당 시험지 전체의 전사가 끝났다는 뜻은 아니다.
- 지문·문항 분석의 작업형은 2022·2023 홀수형과 2027 단일형으로 한정한다. 2022·2023 짝수형은 원본과 검증된 정답표만 보존하고 별도 OCR·수동 전사 대상에서는 제외한다.
- 작업형 3개 문제지의 완전한 줄·선지·도식 대조는 아직 남아 있다. 따라서 `텍스트/`의 이미지형 문제지 정본은 계속 비워 둔다.
- 작업형 3개 문제지에서 문항 판단에 직접 쓰이는 표·그래프·도식 13개는 `시각자료_원본/`에 분리했으며, 각 크롭은 공식 전체 페이지와 해시로 연결된다. 이는 시각 자료의 누락 방지용 자산이지 문제지 전체 전사가 끝났다는 표시는 아니다.

## 주의

문제·정답의 저작권은 법학전문대학원협의회에 있다. 프로젝트 내부의 구조·관계 분석용으로만 사용하며, 외부 배포 시 이용 조건을 확인한다.
