# 교과 개념과 심화 지식의 연결

## 연결표

|기존 자료에서 확인한 개념|이번에 확장할 질문|새 심화 지식|지문 안에서 발전시킬 관계|새 사례에 적용할 일|
|---|---|---|---|---|
|공공 부조·최소 생활 보장|빈곤이 줄었다는 것은 무엇인가?|빈곤선과 빈곤율|개인의 소득 → 기준 미만 분류 → 전체 인구 비율|소득 변화가 경계 통과로 이어지는지 판별|
|소득 재분배|빈곤 인원이 같아도 부족은 줄 수 있는가?|빈곤갭지수|부족액 → 기준에 대한 비율 → 전체 인구 평균|규모와 부족 총량을 분리|
|희소한 재원의 배분|부족을 모두 메우는 데 어느 정도 자원이 필요한가?|완전 표적 지급의 자원량|정확한 개인 정보·다른 변화 없음 → 부족액 합|총액 역산과 현실 비용의 적용 범위 제한|
|불평등의 완화|같은 부족 총량을 누구에게 얼마나 남기는가?|제곱빈곤갭지수|개인별 부족 제곱 → 큰 부족의 상대적 비중 증가|지원 방식별 지표 순위 비교|
|경제 지표의 활용|보고값에서 어느 정보까지 알 수 있는가?|요약값의 식별 범위|서로 다른 허용 입력 → 같은 집계값 가능|같은 지표와 같은 분포를 구별; 추가 정보의 중복 확인|

위 연결은 이번 제작 제안이다. 학생이 이미 세 빈곤 지표를 배웠다거나, 개인별 배움의 이력을 확인했다고 주장하지 않는다.

## 외부 근거 확인

2026-10-19에 다음 기관 자료를 직접 열람했다. 영어 원문을 길게 번역해 옮기지 않고 정의와 조건을 확인해 새 설명을 구성한다. 현행 국가별 빈곤선이나 금액을 비교하는 자료로 사용하지 않는다.

|ID|자료·직접 위치|확인한 사실|제작에 사용할 범위|
|---|---|---|---|
|W1|[World Bank, Introduction to Poverty Analysis](https://documents1.worldbank.org/curated/en/775871468331250546/pdf/902880WP0Box380okPovertyAnalysisEng.pdf), Chapter 4 §§4.1~4.3, PDF 42~44쪽(인쇄 43~45쪽)|빈곤율의 깊이 비민감성, 빈곤갭, 제곱빈곤갭, 완전 표적 이전의 자원량과 거래비용·유인 효과 배제|측정의 목적과 방법을 연결하는 개념 근거. 원문 사례 숫자는 가져오지 않음|
|W2|[World Bank PIP Methodology, 2022-04판 §4.1](https://worldbank.github.io/PIP-Methodology-2022-04/surveyestimates.html)|H는 y<z의 인구 비중, G는 비빈곤층 0 처리 후 전체 평균, S는 개인별 제곱 후 평균|산식·경계·집계 순서의 명시적 기준. 최신판이라고 소개하지 않음|
|W3|[World Bank SARMD Guidelines §4.3](https://worldbank.github.io/SARMD_guidelines/poverty-methodology.html)|FGT 계열에서 지수 0·1·2가 규모·갭·심각성을 나타내며 큰 부족을 다르게 반영|세 지표가 실제 분석 도구라는 근거. 문서의 과거 PPP·국가별 금액은 재사용하지 않음|
|W4|[World Bank DataBank, SI.POV.NAGP](https://databank.worldbank.org/metadataglossary/world-development-indicators/series/SI.POV.NAGP)|비빈곤층의 부족은 0, 국가별 빈곤선과 시점 간 비교의 조건|빈곤의 깊이·발생 범위가 함께 반영됨을 확인. 서로 다른 빈곤선의 지표를 단순 비교하지 않음|

FGT의 원논문은 Foster, Greer, Thorbecke(1984), “A Class of Decomposable Poverty Measures”, *Econometrica* 52(3), 761–766이다. 이번에는 W3의 문헌 목록으로 서지를 확인했으며 원논문 전문을 읽었다고 보고하지 않는다. 산식과 성질의 직접 근거는 위 기관 방법론이다.

## 사실·모형·새 추론의 구별

**학술적으로 확인한 구조:** 빈곤선 미만 인구의 비중, 개인별 부족비율의 전체 평균, 그 제곱의 전체 평균이라는 측정 방법. 제곱 방식은 더 큰 부족에 상대적으로 더 무게를 둔다. G는 빈곤 인원과 깊이를 모두 반영하므로 ‘오직 깊이만 측정한다’고 단정하지 않는다.

**창작에서 명시할 단순화:** 모든 사람에게 동일 가중치와 같은 양의 빈곤선 적용, 개인 소득 0 이상, 고정 인구, 소득 단위와 관측 기간 일치. 지원 사례를 쓰면 외부 재원·지급액의 개인 소득 귀속·다른 소득 변화 없음·행정비용 여부를 정한다. 실제 조사에서 가구 규모와 표본 가중치를 처리하는 복잡한 방법까지 구현했다고 주장하지 않는다.

**이번에 직접 도출할 논리:** 같은 요약 지표가 다른 분포에서 나오는지는 창작한 수치를 대입하여 확인한다. 지원 방안의 순위는 그 사례의 규칙과 숫자에서 계산한다. 이런 국소 결과를 W1~W4의 실증 발견으로 인용하지 않는다.

## 설계자용 수학적 계약

N>0, z>0, yᵢ≥0. `gᵢ=max(0,(z−yᵢ)/z)`.

- `H=#{i:yᵢ<z}/N`
- `G=(Σgᵢ)/N`
- `S=(Σgᵢ²)/N`
- 부족액 총합은 `NzG`.
- H>0일 때 빈곤층만의 평균 부족비율은 `G/H`. 이는 H·G에 추가되는 독립 정보가 아니다.
- `[Σgᵢ/N]²`와 `Σgᵢ²/N`은 일반적으로 다르다. 단, 모든 gᵢ가 같으면 같을 수 있으므로 ‘항상 다르다’고 쓰지 않는다.
- H=0이면 모두 비빈곤층이고 G=S=0이다. 이때 `G/H`를 사용하지 않는다. N·z만 있는 상황과 모든 세부 자료가 추가된 상황을 구별한다.

위 식들은 근거의 정의에서 도출한 설계자용 정리다. 학생용에 전부 기호식으로 제시할 의무는 없다. 필요한 규칙을 언어로 명확히 줄 수도 있다.

## 설명에서 피할 과장

S가 G보다 ‘더 정확한 진짜 빈곤’을 무조건 나타낸다고 하지 않는다. 두 값은 서로 다른 평가 기준을 반영한다. S를 사회 전체 불평등의 완전한 측정치로 소개하지 않는다. 일정 금액 지급 후 지표의 기계적 변화와 실제 정책의 인과 효과를 구별한다. 실제 정책의 노동 공급·물가·행정비용·재원 부담이 모형 밖에 있다면 그 한계를 적는다.
