## P01. 속성과 행위의 귀속 대상을 되돌리기

**규칙:** 여러 주체·기관·원인이 비슷한 대상을 다룰 때, 선지의 행위나 속성을 원문에서 그것을 담당한 대상에 다시 연결하라.

- 적용 조건: 원문에 둘 이상의 구별된 대상과 각 대상의 역할·주장이 있고 선지가 그 대응을 교환하거나 엉뚱한 관계 쌍을 만든다.
- 적용하지 말 것: 주체가 이미 맞고 논점이 효과의 강도나 적용 조건인 경우. 심리의 추가 성분이 입증되지 않은 AVT를 단순 주체 교환으로 처리하지 않는다.
- 연결 구조: 대상별 역할·견해 병치 → 한 술어 또는 관계 끝점의 이동 → 대상-술어/대상-관계-대상 복원 → 원문과 어긋난 귀속 배제
- 통합·구분 근거: AG·BI·ANW는 같은 단항 귀속 수정으로 통합할 근거가 있다. AJQ는 두 항 관계, BY는 원인 종류, AQP는 평가 행동까지 복원하므로 확장 사례로 표시한다. 이 셋의 전이가 실패하면 분할한다. P02는 대상이 같아도 서로 독립된 판단 축을 보존하는 별도 조작이다.
- 근거 규모: 구조 확인 6개 고유 지문, 실제 문항 활용 6개 고유 지문·6개 고유 문항. 6개 장면. 동일 문항의 여러 장면은 문항 수 1로 계산.

- 다음 검증: 새 지문에서 대상 이름만 바뀐 귀속 오류를 잡는지, 원인 식별·근거 부재 탐색까지 같은 규칙으로 해결되는지 따로 기록한다.

## P02. 변경·일치가 성립한 판단 축만 유지하기

**규칙:** 두 속성이나 판단이 함께 제시되면, 한 축의 변화·일치를 다른 축으로 옮기지 말고 선지가 주장하는 축마다 근거를 확인하라.

- 적용 조건: 입증 책임/입증 정도, 과학성/진릿값, 구성 재료/환원 가능성처럼 독립적으로 답할 수 있는 질문이 원문에 둘 이상 있다.
- 적용하지 말 것: 원문이 두 속성의 필연적 연결을 명시하는 경우에는 무조건 독립으로 취급하지 않는다. AC는 연결 방향이 정의로 주어져 있다.
- 연결 구조: 서로 다른 축에 대한 진술 → 한 축의 결론을 다른 축으로 전이 → 축마다 변화/동의 여부를 분리 → 유지된 책임 또는 한정된 공통점 확인
- 통합·구분 근거: AB의 책임/정도 분리는 OZ·PA의 속성별 비교와 같은 칸 보존 행동으로 묶었다. AB는 시간 순서까지 필요하므로 P07과의 복합 가능성을 남긴다. 모든 다차원 지문이 활용 사례가 되는 것은 아니다.
- 근거 규모: 구조 확인 2개 고유 지문, 실제 문항 활용 2개 고유 지문·3개 고유 문항. 3개 장면. 동일 문항의 여러 장면은 문항 수 1로 계산.
- 100코드 사후 대응: AB 주 #24·보조 #5/#3/#16, OZ·PA 주 #23·보조 #75와 대응. 한 번호와 일대일 대응하지 않는다.
- 검증 상태: 다른 소재에서 반복 관찰했으나 검증용 미적용. 학생 오류율·교육 효과 미확인.

## S06. 시기별 집단을 근거 없이 동일시하지 않기

**규칙:** 앞뒤 시기에 다른 이름의 집단이 등장하면, 같은 집단이라는 연결 근거가 있을 때만 재등장이나 지위 역전으로 해석하라.

- 적용 조건: 선지가 시간적으로 나뉜 집단 사이의 동일성을 주장한다.
- 적용하지 말 것: 대명사·별칭·구성원 등의 동일성 근거가 주어진 경우. 이름이 다르다는 이유만으로 다른 집단이라고 확정하지 않는다.
- 연결 구조: 초기 억압 집단/후기 등용 집단 → 같은 세력으로 연결 → 동일성 연결 근거 탐색 → 근거 없는 재등장 주장 배제
- 통합·구분 근거: ANV는 같은 국가의 명시된 전후 변화라 동일성 확인 문제가 아니다. P01은 이미 식별된 대상 사이의 술어 교환이고 이 후보는 대상 동일성 자체가 미확인이다.
- 근거 규모: 구조 확인 1개 고유 지문, 실제 문항 활용 1개 고유 지문·1개 고유 문항. 1개 장면. 동일 문항의 여러 장면은 문항 수 1로 계산.
- 100코드 사후 대응: AQN 주 #17·보조 #3·표면 #5. 실제 변화 관계가 입증되지 않아 변화라는 소재어로 분류하지 않는다.
- 검증 상태: 한 지문에만 확인되어 반복 패턴으로 확정하지 않음. 학생 오류율·교육 효과 미확인.
- 다음 검증: 비문학의 명칭 변화·문학의 대명사 지칭에서도 같은 동일성 증거가 필요한지 검사한다.
