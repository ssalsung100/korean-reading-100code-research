## 독립 제작자에게 주는 공통 과제

통합사회 공공 부조·소득 재분배에서 출발하여 빈곤 측정의 심화 지식을 설명하는 독서 지문 1개와 5지선다 3문항을 작성한다. 중심 참조는 2023학년도 6월 모의평가 14~17번 이중차분법 지문이다. 정의·전제·새 사례 적용의 연결을 참고하되, 이중차분법 자체를 다른 이름으로 바꾸어 재생산하지 않는다.

IR-P063과 IR-P032를 우선 활용한다. 숫자·등장인물·표·문단 순서·정답 위치는 독립적으로 설계한다. 빈곤율·빈곤갭·제곱빈곤갭을 모두 사용할지, 두 지표에 집중하고 별도 보충 정보를 둘지도 설명 목적에 따라 결정할 수 있다. 특정 지급 방안이나 인구 규모, 특정 반모형, 이미 작성된 문항 구조를 공통 정답으로 지정하지 않는다. 다른 설명 방법을 추가하면 출처와 풀이에 필요한 정의를 제공한다.

학생에게 필요한 모든 규칙을 본문이나 보기에 제공한다. 전문어와 수식 수를 난도의 대용물로 쓰지 않는다. 초안 저장→자체 비판→실제 수정→전 선지 재검사를 수행하고, 정답 유일성과 설명문의 완성도를 각각 보고한다.

## 증거 층위와 사용 제한

- **S:** 원기출·기존 교과 자료·기관의 방법론 문서. 자료의 존재가 특정 학생의 학습 완료를 입증하지 않는다.
- **A:** 저장소의 기존 풀이·원리 판정. 사후 연구이며 신규 blind가 아니다.
- **H:** 이번 소재 선정·비교·제작 제안. 기출의 공식 출제 의도나 실증 교육 효과가 아니다.
- **L:** 창작 모형의 허용 입력·분모·경계·비교 기준·유일성 조건.
- **U:** 전문가 문체 평가·학생 난도·실제 학습 효과 미검증.
- **R:** 사용자 요청은 반영했으나 완성 소재에 대한 별도 연구자 검토 의견을 수신한 것으로 기록하지 않는다.

기존 원문·원장·v1·동결 자료는 수정하지 않는다. G024/G370 hold를 유지하며 근거로 사용하지 않는다. 이 묶음의 존재는 타 모델 호출이나 비교 실험을 실행하라는 승인으로 읽지 않는다. 향후 호출은 별도 실행 요청에 따른다.

독립 검토 단계에는 새로 생성한 학생용 자료만 먼저 제공하고, 검토자의 답·전제·중간 추론을 저장한 다음 제작자 해설을 공개한다. 다수의 같은 답을 논리 검증의 대용물로 사용하지 않는다.

## 출처 파일의 읽기

원자료에 저장한 발췌는 필요한 부분만 복사한 파생본이다. 전체 연구 원장을 대신하지 않는다. 원래 저장소 경로와 레코드 ID는 `근거발췌.json`에 보존했다. 원기출 PDF는 평가원 문제지의 외부 미러 배포본이며, 직접 평가원 서버에서 내려받은 것으로 표시하지 않는다. 학술 문헌의 외부 링크는 해당 파일의 주장을 확인하는 데 사용하며 학생이 미리 읽어야 하는 필수 자료가 아니다.
