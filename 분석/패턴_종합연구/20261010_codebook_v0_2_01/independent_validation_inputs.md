# 다음 독립 검증에 제공할 입력 목록

아래는 제공 목록의 사전 정의이며 이번에 검증용 자료를 열거나 배포한 것은 아니다. 자동 모델 호출도 하지 않는다.

|시점|필요 입력|제공·분리 기준|
|---|---|---|
|검증 시작 전|`freeze_manifest.json`과 `freeze_manifest.sha256`|manifest의 SHA-256을 먼저 확인하고 manifest에 든 파일의 해시를 확인한다. 날짜·버전도 함께 기록한다.|
|검증 시작 전|`codebook_v0.2.json` 및 MD|13개 후보의 상태·상위 원리·하위 조작·최소 근거·비적용 조건을 그대로 사용한다. 검증 결과에 맞추어 덮어쓰지 않는다.|
|검증 시작 전|`application_protocol.md`, `counting_rules.md`, `annotation_schema.json`, `external_annotation_template.json`|역할별 판정과 계수 기준, 입력 형식, 근거 미확인 처리 기준을 고정한다.|
|검증 시작 전|`management_metadata.json`|표본 ID·분할·hold·노출 여부만 제공한다. 정답/코드 값이 포함된 원 `sample_annotations.json`은 그대로 제공하지 않는다.|
|필요한 사전 연습|`event_mapping_v0.2.jsonl` 및 MD, 발견용 사례집|발견용 12지문에서의 anchor·경계와 역할 구별을 설명하는 자료다. 검증용 예상 패턴 목록으로 사용하지 않는다.|
|독립 풀이 단계|후속 승인된 외부 표본의 정본 본문·발문·보기·전체 선지·도표|정답·기존 풀이·태그를 제거한 자료. 완전성·출처 연결은 별도 확인해야 한다. 이 동결 폴더에는 검증용 본문을 포함하지 않는다.|
|group 전체 최초 풀이 저장 후|별도 봉인된 공식 정답과 답표 출처|최초 기록 보존 후 대조한다. 이번 폴더에는 검증용 정답을 포함하지 않는다.|
|group 전체 독립 논리·코드/패턴 기록 잠금 후|필요한 기존 해설·SDSS·외부 비교 판정|사후 비교용. 독립 판정 전에 예상 패턴·기존 코드가 전달되지 않게 한다.|
|결과 저장|새 검증 결과 폴더와 빈 주석 파일|sample_split을 validation 또는 external로 표시한다. 최초 판정·정정·미확인·비적용·미분류·반례를 모두 보존한다. 발견용 계수와 별도 보고한다.|

현재 실행 주체는 G095/NM의 미노출 검토자가 아니다. 미노출 독자를 배정할 수 없다면 해당 표본의 독립성 제한을 명시하고 미노출 검증 성과로 합산하지 않는다. 단순히 새 세션을 열었다고 노출 이력이 해소되는 것은 아니다.

사례 인용을 다시 검증하려면 원문·정본 수준·해당 선지·인용 위치가 모두 필요하다. application의 인용 교정이 존재하더라도 현재 검토자가 정본을 확보하지 못했다면 재검증 완료로 표시하지 않는다. GL④ 수식 유보는 별도로 전달한다.

검증자가 제출할 최소 결과는 코드 없는 최초 풀이, 공식답 대조 기록, 사건별 원문→조작→판정 경로, 역할별 pattern_relation, 하위형 또는 미분류 이유, 반대 근거·대안 풀이, 인용 검증 수준, 동결 버전 해시, 최초 판정과 변경 이력이다. 강의·교재·창작 가치 평가는 적용 빈도와 별도 기록한다.
