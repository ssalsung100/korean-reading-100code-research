# 코드북 v0.2 고정 검증 세트 적용

G064·G095·G119·G157·G350·G310의 6지문·21문항·105선지를 원문 근거로 분석했다. 이전 Sol stage1 풀이·후보, 기존 100코드 풀이·정답·SDSS는 열지 않았다. 코드북은 지정 SHA-256과 일치하며 원본·기존 동결 폴더를 수정하지 않았다.

- [지문·문항·선지별 분석](text_item_solution_matrix.md): 지문 기능, 실제 사용/미사용 정보, 최소 논증 사슬, 읽기 단계/선지 단계, 대안 경로, 패턴 적용과 경계.
- [상세 적용 기록](case_annotations.jsonl): 지문 6record와 문항 21record. 정확히 맞는 고정 하위형만 subtype_id를 부여하고 나머지 상위 적용은 null로 보존.
- [원문 근거 연결](evidence_links.jsonl): 텍스트 인용 347개와 공식 이미지 확인 3개. 원문 해시·JSON pointer·문자 위치 또는 이미지 영역 포함.
- [잔여 후보와 반례](pattern_residuals.md): 12개 후보 계열. R11의 범위 확대와 동기 추가는 두 성분으로 분리. 어느 후보도 확정 신규 카드로 승격하지 않음.
- [교육·창작 노트](teaching_item_design_notes.md): 행동 규칙·신호·오적용, 기출 연결, 구현 구조·선지 조작·정답 유일성 검토. 학생 효과는 가설.
- [한계·독립성·원문 결손](application_limitations.md): G095 이전 노출, RX B열 결손 보강, G350 강조구/보기 표 직접 확인, 원본 조판 미대조 범위, 실행 모델 미확인.
- [동결 manifest](freeze_manifest.json)와 [해시 기록](hashes.sha256): 입력·산출물 해시, 열람 범위, 실행자 정보, 검증 범위.

같은 폴더에서 `python3 validate_and_freeze.py --verify`로 형식·인용·입력 불변·동결 해시를 재확인할 수 있다. 이 명령은 읽기 전용이다. `author_application.py`는 동결 이후 재작성을 거부한다.

자동 검사 통과는 의미적 타당성 인증이 아니다. 공식 정답 대조·외부 독립 의미 검증은 수행하지 않았으며 최초 선택의 정답률도 계산하지 않았다. 정확한 런타임 모델 ID와 effort가 노출되지 않아 미확인으로 보존했다. G095의 노출 이력을 다른 지문 모두에 확대하지 않는다.
