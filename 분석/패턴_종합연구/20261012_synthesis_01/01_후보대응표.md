# 기존 후보와 잔여의 근거 기반 대응표

13개 코드북·20개 Sol 후보·13개 잔여 행(R11을 a/b로 분리)의 출처를 모두 보존했다. 46은 입력 목록의 행 수이며 새 패턴 수가 아니다. 표의 동일성은 명시한 부분·장면에 한정된다. 지문층·문항층·풀이층 관계를 같은 종류의 통합으로 해석하지 않는다.

관계: **동일 원리**는 입력·중간 연산·결론 제약이 같다. **하위 유형**은 상위 조건에 추가 조건을 붙인 경우다. **부분 중첩**은 공유 단계가 있으나 잔여 연산이 다르다. **별개의 원리**는 간선 의미 또는 판단 단위가 달라 서로 대체할 수 없다. **근거 부족**은 현 자료만으로 통합·반복성을 확정할 수 없다. N 식별자는 잠정 신설·확장 후보이며 [계층과 조건](03_패턴계층과_적용조건.md)에서 정의한다.
