# 연구자 읽기 안내 — 사례집69~75

**모두 연구자 미검토다.** 각 링크에는 필요한 원문과 실제 발문·보기·전체 선지, 선지별 중간 추론, 강의 설명 후보, 간단한 선택 칸이 있다. 아래 쟁점 중 하나에 한 문장 의견을 남기는 것부터 시작할 수 있다.

| 검토 자료 | 다루는 상황 | 먼저 판단할 쟁점 |
|---|---|---|
| [69 효율과 출력](연구자검토_69_효율이낮아지면출력도줄어들까.md) | 광자를 전자로 바꾸는 장치에서 파장과 효율이 변함 | 같은 세기를 같은 광자 수로 읽는 지문 규약의 범위를 어디까지 인정할까? 공식③은 유지한다. |
| [70 등식과 상한](연구자검토_70_같아야하는값과작기만하면되는값.md) | 공정 보험의 금액 비교와 열기관의 실제 변환 비율 | 정답에 꼭 필요한 조건과 오답 검토에만 쓰는 조건을 학생에게 구분해 줄까? |
| [71 관점의 기준](연구자검토_71_그사람의기준으로판단한다는뜻.md) | 철학자별 지식 판별 기준과 콰인의 비판 | 특정 관점으로 판단하는 것과 글쓴이의 동의를 분리하는 설명을 어떤 순서로 할까? |
| [72 효과별 예외](연구자검토_72_계약을끝내도보험금을줘야할까.md) | 해지권이 있어도 보험금 지급 책임이 남는 경우 | P062를 잠정 원리로 보관하고 해지/지급/반환 세 칸을 수업에 사용할까? |

| [74 최소들 중 최대](연구자검토_74_가장작은값중가장큰값.md) | 분포별 최소 평균 부호 길이의 비교 | 정의 대입의 짧은 경로를 먼저 설명하고 두 비교 범위는 보강으로 둘까? |
| [75 조합과 방향](연구자검토_75_몇개를세고어느방향을비교할까.md) | 자리별 배열 생성과 진공 표의 여러 변수 | SC⑤의 통제된 누적 과정을 학생이 재현할 만큼 어떻게 설명할까? |

우선순위가 필요하면69의 해석 유보,72의 새 잠정 원리,75의 역방향 설명부터 검토할 수 있다. 어느 것도 연구자의 최종 교수 철학이나 단원 구성으로 확정하지 않았다.
