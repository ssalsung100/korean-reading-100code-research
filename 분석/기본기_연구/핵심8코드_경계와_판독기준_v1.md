# 핵심 8코드의 경계와 판독 기준

작성: 2026-09-07. 이 문서는 #2·#4·#10·#12 및 #43·#45·#46·#49 비교 연구의 해석 기준이다. 코드 사이트의 공식 해설을 대체하는 정의서가 아니라, 실제 기출을 읽을 때 어떤 판단을 기록할지 명시한 프로젝트 연구 기준이다.

근거 문서: [양상·양화·조건 비교](코드심층_01_양상양화조건.md), [변수·함수·인과·상관 비교](코드심층_02_변수함수인과상관.md). 원표 명칭과 후보 수는 [100코드 연결 현황](100코드_사례연결_현황_v2.md)을 따른다.

## 1. 한 문항에 붙은 코드의 범위부터 확인한다

코드 사이트의 문항 표지는 다음 세 범위 중 어디를 설명하는지 명시되어 있지 않을 수 있다.

| 판독 범위 | 기록할 내용 | 확인 사례 |
|---|---|---|
| 지문 구조 | 지문 전체가 구성하는 관계 | LEET 2023 13~15의 나이·기간·코호트 효과 |
| 정답 결정 | 공식 정답을 고르기 위해 필요한 관계 | 같은 지문의 15번에서 고정된 연령과 남은 두 효과 |
| 특정 선지 | 하나의 선지를 수용·배제하는 관계 | KICE 2024 수능 4번 ①의 선거 시점과 경마식 보도량 |

경마식 보도 문항의 정답 ⑤는 참여 독려의 재진술이다. ①은 선거일에 가까워질수록 보도가 증가한다는 방향을 뒤집는다. 따라서 #49는 문항 안에 근거가 있지만, 정답 선지 자체의 핵심 관계로는 설명력이 약하다. 이런 경우에는 `특정 오답에 적용 / 정답 주 코드로는 보류`라고 적는다. 곧바로 사이트 오류라고 판단하지 않는다.

부정 발문에서는 거짓 선지가 공식 정답이다. `정답 선지의 관계`와 `참인 진술의 관계`도 구분한다.

## 2. #2 양상과 #4 양화

| 구별 질문 | #2 양상 | #4 양화 |
|---|---|---|
| 달라지는 것 | 동일 명제의 가능·필연·개연 강도 | 명제가 적용되는 대상의 범위·수량 |
| 고정해 볼 것 | 누구에 대한 어떤 판단인지 | 각 대상에 적용하는 성질·관계 |
| 대표 변형 | 가능성을 보장으로 바꿈 | 일부·특정 집단을 전체로 넓힘 |
| 주의 | ‘할 수 있다’라는 어미만으로 결정하지 않음 | ‘모두’라는 단어만으로 결정하지 않음 |

두 코드는 독립된 선택지처럼 항상 갈라지지 않는다. “모두가 그럴 수 있다”는 문장은 대상 범위와 성립 강도를 함께 가진다. `각 대상에게 가능한 경우가 있음`과 `모든 대상에게 동시에 성립하는 경우가 있음`도 같지 않다. 실제 지문이 어느 범위까지 전제를 주는지 먼저 확인해야 한다.

작업 절차는 대상과 명제를 고정한 뒤 강도만 바꿔 보고, 강도를 고정한 뒤 대상 범위만 바꿔 보는 것이다. 정답 판단이 어느 변경에 민감한지 설명하면 주·보조 코드의 역할이 드러난다. 이것은 자동 분류 규칙이 아니라 근거를 드러내는 검토 질문이다.

## 3. #10 필요조건과 #12 조건문

`A이면 B`에서 B는 A의 필요조건이다. 따라서 같은 명제를 #12와 #10으로 기술할 수 있다. 두 코드의 구별을 별개 논리식의 구별로 암기하면 오히려 혼동한다.

| 문항이 주목하는 것 | 중심으로 기록할 코드 | 확인할 오독 |
|---|---|---|
| 주어진 A에서 B로 진행하는 적용 | #12 조건문 | 조건 누락, 역·이의 부당한 사용 |
| 결과 A에 B가 빠질 수 있는지 | #10 필요조건 | 필요 요건을 충분한 보장으로 바꿈 |
| B만 있으면 A도 성립하는지 | 원문에 양방향 근거가 있는지 확인 | #11 필요충분조건을 근거 없이 부여 |

추론에서 조건문의 방향을 기록하되, 권고·전형적 사례·효과적인 방법을 바로 필수 요건으로 바꾸지 않는다. “B이면 효과적으로 수행될 수 있다”와 “B가 없으면 수행할 수 없다”는 다르다. 특히 교육·제도·정책 지문에서 ‘도움이 된다’는 설명을 강한 논리적 필요조건으로 올리기 쉽다.

반대로 지문이 생략한 중간 요건을 문항이 복원하게 한다면 겉으로 `필요하다`가 없어도 #10이 중요할 수 있다. 코드 판정은 표면어보다 정답으로 이어지는 관계를 따른다.

## 4. #43 타변수통제와 #46 인과관계

두 코드는 인과에 관여하는 서로 다른 질문을 다룬다. #43은 비교를 통해 어떤 효과를 분리할 수 있는지, #46은 원인에서 결과로 어떤 경로가 이어지는지에 초점을 둔다.

| 사례 | 통제·비교의 역할 | 인과 경로의 역할 |
|---|---|---|
| 슈퍼문 | 같은 계절·달 위치에서 지구 궤도 이심률만 변화 | 이심률 → 태양과 거리 → 조차 |
| 이중차분법 | 무정책 상태에서 두 집단의 변화가 같다는 가정 | 관측 변화에서 반사실적 변화를 빼 정책 효과 평가 |
| APC | 같은 연령·시점·코호트 중 무엇을 고정했는지 판별 | 고정되지 않은 효과들의 합성 관계가 남음 |

‘통제’가 모든 관측값의 동일성을 뜻하지는 않는다. 이중차분법에서는 출발 수준이 달라도 평행추세 가정이 성립할 수 있다. 같은 시기에 관측했다는 것만으로 평행추세가 입증되는 것도 아니다. APC에서는 하나의 변수를 고정해도 남은 두 효과를 각각 식별하지 못할 수 있다.

따라서 연구 기록에는 `고정된 조건`, `변경된 조건`, `아직 구분되지 않은 효과`를 따로 쓴다. 그 뒤에만 효과 방향이나 크기에 관한 결론을 적는다.

## 5. #45 함수와 #46 인과관계

| 판단 | 함수 관점 | 인과 관점 |
|---|---|---|
| 기계·생물 과정 | 입력, 처리 요소, 출력의 대응 | 어떤 작용이 다음 상태를 발생·억제하는지 |
| 측정·분류 | 지표를 어떤 방식으로 결과에 대응하는지 | 지표가 실제 현상을 발생시킨다고 단정할 수 있는지 |
| 경제적 선택 | 상대방의 선택에 따른 자기 판단·보수 | 제도나 유인이 행동·결과에 미치는 경로 |

중산층 판별 점수표는 지표를 점수와 분류 결과에 대응시킨다. 점수표의 출력이 바뀌었다고 사람의 객관적 경제 상태가 그 때문에 달라졌다는 뜻은 아니다. 마찬가지로 측정 모형의 입력·출력 관계를 곧바로 현실의 인과관계로 읽지 않는다.

확산 모델 문항에서는 구성 요소를 아는 것과 각 요소의 산출물을 아는 것이 다르다. 요소가 여러 개라는 사실만으로 #40 부분관계를 핵심으로 삼기보다, 선지가 교환한 입력·산출·학습 단계의 역할을 확인해야 한다.

## 6. #49 상관관계와 #46 인과관계

이 프로젝트의 원표에서 #49의 별칭에는 ‘촉진’·‘억제’가 포함되어 있다. 사이트 표본은 통계적 공변 이외에도 증감 방향을 넓게 다룬다. 따라서 사이트의 사용 범위를 먼저 보존하고, 개별 기출 분석에서 다음을 구분한다.

1. 변수의 증감 방향을 그대로 적용하는가?
2. 방향을 결정하기 위해 중간 작용 위치와 경로를 복원해야 하는가?
3. 단순한 동시 변화에서 인과를 부당하게 추정하는가?

세 번째만을 #49의 유일한 유형으로 삼지 않는다. 비타민 K 문항의 헤파린 선지는 후속 단계의 억제를 선행 단계의 억제로 옮긴다. 워터마킹 문항은 줄무늬의 방향과 밝기 변화를 측정하는 방향을 교환한다. 둘 다 #49 후보지만 결정적인 오류 위치는 서로 다르다.

## 7. 코드별 사례 비교의 최소 기록

같은 코드를 가진 문항끼리 비교할 때 다음 여섯 항목을 채운다.

- 원문에 실제로 주어진 관계와 적용 범위
- 공식 정답을 선택하는 데 필요한 근거와 중간 판단
- 코드가 정답·특정 오답·지문 전체 중 어디에 적용되는지
- 다른 사례와 공유하는 관계와 달라지는 표상·주체·시점
- 가장 가까운 다른 코드가 담당하는 판단 단계
- 표·그림·선지 누락 및 해석의 남은 불확실성

한 지문의 여러 문항은 문항 변형 비교에 유용하지만 독립 지문 여러 개의 증거가 되지는 않는다. 사이트 미표지 보충 사례는 별도로 표시한다. 공식 정답 일치는 자료 연결의 증거이며 코드 해석의 정당화는 실제 풀이 근거에 의해 따로 이루어진다.

## 9. 2026-09-08 독립 연구에 따른 후속 경계 수정

위 표의 논증군 검토축인 ‘사실 설명과 규범 입장의 차이’는 초기 탐색용 기준으로 보존하되, 두 코드의 확정 구분으로 사용하지 않는다. [독립 연구 03](코드심층_03_독립풀이_증거와경쟁.md)에서 다음 반례·문제가 확인되었다.

- 기존 기준: #74는 사실 설명, #75는 규범적 입장으로 구분할 수 있다는 단순화.
- 문제점과 원문 근거: MEET 2012학년도 12번(F)의 사이트 ‘경쟁입장’ 사례에는 텍스트와 행위 의도에 대한 해석 차이도 있다. 규범적 선택만이 아니다. LEET 2026학년도 28번(D)은 관측의 지지 평가보다 집단별 정치 지향의 귀속을 요구한다.
- 수정된 작업 기준: 사실/규범 여부만 보지 않고 **동일 관측에 대한 대체 설명의 기대를 비교하는가**, 또는 **주체별 견해를 유지하고 귀속하는가**를 분리한다. 이 행동 구분을 SDSS 저자의 공식 정의라고 주장하지는 않는다.
- 외부 연결 한계: 저장된 #74·#75 검색 HTML이 동일하고 표시 태그는 별도로 존재한다. 검색어를 그대로 원래 태그로 복제하지 않는다.

추가로 G(2020학년도 6월 모평 30번)에서 인과 경로를 상세히 분석하고도 ‘필요하다’라는 결론 강도를 경쟁 코드에 반영하지 못한 문제가 드러났다. 기존 #2/#46의 뜻을 바꾸는 것이 아니라, **코드 없는 최초 풀이의 결론·양상 표현을 후보 코드 목록에 다시 대조하는 절차**를 추가한다. 새 사례의 최초 판정은 보존하고 수정 근거는 각 `_03_SDSS대조.md`에 남겼다.
