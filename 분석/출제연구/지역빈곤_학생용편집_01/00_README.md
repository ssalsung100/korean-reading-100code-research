P3의 두 수치 예시, P5의 중간 합계와 전체 지수 계산, 가법적 분해라는 명칭은 교사용으로 옮겼다. P2의 조건과 P4의 평균→합→전체 평균은 유지했다. P6의 구획 변경은 개인 비중 보존에 집중하고, P7의 지급 효과 한계는 한 문장으로 남겼다.

원자료인 [7문단 시험 지문](../../지문구성_연구/20261019_kice_passage_architecture_01/09_시험집필_새지문.md), 22개 기출 분석과 v0.1은 보존했다. 지정한 편집 자료와 PA13·PA17만 참고했으며 새 전수 연구·모델 비교를 시작하지 않았다. 외부 검토 보고서를 받았다고 가정하지 않았다.

학생용의 수치·모형 조건은 기존 것에서 바꾸지 않았고 기존 검산을 재사용했다. 교사용에 표시한 기여분/전체 지수의 비중 계산만 추가 확인했다. 학생 반응은 관찰하지 않았으므로 이해도·난도 개선을 실증한 원고는 아니다. 압축으로 P3의 유도와 P5의 인구 비중 계산을 독자가 보충해야 하는 정도는 늘었다.

다음 의견은 학생용의 해당 문장과 [03 전후 비교](03_주요편집_전후비교.md)에 연결해 반영하면 된다. 특히 P3의 곱 관계와 P6의 개인 비중 설명이 충분한지가 남은 확인 지점이다. 기존 파일을 덮어쓰지 않고 후속 수정은 별도 버전으로 남긴다. 연구자의 별도 승인이나 추가 검토자료 작성을 선행조건으로 두지 않는다.
