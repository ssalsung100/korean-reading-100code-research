## 2. 경제 지문의 고유 골격

### 2.1 전형 E1 — 모형의 전제와 시차

`정책 목표 → 전달 경로 → 시간차 또는 제약 → 의도와 다른 결과`

- 통화 정책 지문은 금리 조정의 작동 절차 자체보다 정책 효과가 나타나는 시점과 경기 국면의 불일치를 문제화한다.
- 선지는 중간 경로를 생략해 처음 변수와 최종 결과를 연결하거나, 단기와 장기의 결과를 교환한다.
- 생성 적용: 정책 수단을 기계처럼 설명하지 말고, 같은 수단의 효과가 시점·기대·공급 반응에 따라 달라지게 한다.

### 2.2 전형 E2 — 기존 견해, 반증 사건, 보완

`기존의 역할 분담 → 기존 견해가 전제한 조건 → 현실의 반증 → 새 정책의 추가 → 상호 작용`

- 미시·거시 건전성 지문은 새 제도가 옛 제도를 폐기한다고 쓰지 않는다. 기존 정책이 다루지 못한 전체 위험을 새 정책이 보완한다.
- 핵심 함정은 개별 금융 회사의 건전성과 금융 시스템 전체의 안정을 같은 것으로 처리하는 것이다.
- 생성 적용: 개별 행위자에게 유리한 결과와 시장 전체의 결과를 분리한다.

### 2.3 전형 E3 — 한 현상의 상반된 효과

`행위자의 의도된 효과 ↔ 의도와 별개인 효과 → 효과가 갈리는 조건`

- 광고 지문은 광고가 경쟁을 제한한다는 설명과 경쟁을 촉진한다는 설명을 모두 유지한다.
- 두 설명 중 하나를 정답으로 고르는 것이 아니라, 구매자의 반응·진입 가능성 등 어떤 조건에서 각각 성립하는지를 추적하게 한다.
- 생성 적용: 정책이나 제도를 일률적으로 좋거나 나쁘게 평가하지 않고, 수혜 집단·비용 부담 주체·기간에 따라 귀결을 분기한다.

### 2.4 전형 E4 — 구조적 딜레마

`목표 A를 위한 선택 → 목표 B의 훼손 / 목표 B의 보전 → 목표 A의 훼손`

- 트리핀 딜레마는 두 목표를 각각 설명한 뒤 양립 곤란을 드러낸다.
- 선지는 한 목표의 개선을 전체 체제의 개선으로 확대하거나, 양쪽 결과가 발생하는 조건을 뒤집는다.
- 생성 적용: 효율성과 형평성, 현재 수혜와 장기 공급, 정책 정확성과 집행 비용처럼 동일한 정책 안의 경쟁 효과를 둔다.

## 3. 법 지문의 고유 골격

### 3.1 전형 L1 — 요건과 효과

`요건 사실의 충족 여부 → 법률 효과`

- 법 지문의 과정은 물리적 선후가 아니라 규범적 판정이다.
- 선지는 요건 하나가 빠졌는데도 효과가 발생한다고 하거나, 효과의 주체·상대방·범위를 바꾼다.

### 3.2 전형 L2 — 원칙, 유형 분기, 예외의 예외

`일반 원칙 → 유형 A/B → 각 유형의 효과 차이 → 제한 사유 → 제한되어도 남는 효과`

- 고지 의무 지문에서는 해지 가능 여부와 보험금 지급 책임이 항상 함께 움직이지 않는다.
- 임의·단속·강행 법규 지문에서는 법적 불이익, 계약 효력, 급부 의무, 반환 청구를 각각 분리한다.
- 생성 적용: ‘위법이면 모두 무효’처럼 하나의 판단을 다른 법률 효과 전체로 확장하지 못하게 한다.

### 3.3 전형 L3 — 권한의 근거와 한계

`권한 부여의 근거 → 행사 가능한 범위 → 절차 → 범위 일탈 시 효력`

- 행정입법 지문은 제정 주체, 위임 필요 여부, 포괄 위임 가능 여부, 국민에 대한 직접 적용, 공포 절차를 교차시킨다.
- 생성 적용: 명칭 암기가 아니라 새 사례에서 제정 주체와 위임 범위를 대응하게 한다.

### 3.4 전형 L4 — 재량과 자기구속

`재량 허용 → 기준 설정 → 반복된 적법한 관행 → 동일 사안에서 재량 제한`

- 처음에는 법규가 아니어서 직접 구속하지 않던 기준이 평등 원칙을 매개로 뒤에서 행정청을 구속한다.
- 생성 적용: 앞 문단의 법적 성격과 뒤 문단의 실제 효과가 겉보기에는 충돌하도록 떨어뜨려 배치한다.

## 4. 사회문화 지문의 고유 골격

### 4.1 전형 S1 — 동일 문제, 다른 시대적 처방

`공통 문제 → 이론가 A의 현실 진단과 매개 집단 → 이론가 B의 현실 진단과 매개 집단 → 공통점·차이의 역사적 이유`

- 같은 명칭의 제도라도 이론가별 기능과 국가와의 관계가 다르다.
- 선지는 공통 기능을 한 이론가만의 기능으로 만들거나, 한쪽의 특수 기능을 둘의 공통점으로 확대한다.

### 4.2 전형 S2 — 이론의 계승과 수정

`선행 개념 → 후속 이론의 구체화 → 설명 한계 → 대안 이론 → 적용 조건`

- 집합 의례 지문에서 후속 이론은 선행 이론을 전부 부정하지 않고 핵심 통찰을 받아들인 뒤 필연성을 우발성으로 수정한다.
- 생성 적용: 학설을 병렬 나열하지 말고, 무엇을 계승하고 어느 전제만 폐기하는지 밝혀야 한다.

## 5. 사회 지문용 코드 번역

| 잠재 코드 | 경제에서의 표면화 | 법에서의 표면화 | 사회문화에서의 표면화 |
|---|---|---|---|
| 조건문 | 다른 조건이 일정할 때, 기간·기대에 따라 | 요건이 충족되면 | 특정 사회 조건에서 |
| 부분/전체 | 개별 행위자와 시장 전체 | 개별 효과와 법률관계 전체 | 집단의 일부 기능과 제도 전체 |
| 보충도식 | 기존 정책에 새 정책 추가 | 원칙을 제한하는 예외 | 선행 이론의 한계를 후속 이론이 수정 |
| 비교대상 | 정책·기간·집단별 귀결 | 법규 유형별 효력 | 학자별 현실 진단과 처방 |
| 선후 | 단기와 장기, 정책 시차 | 요건 판단 후 효과 발생 | 이론의 계승·수정 순서 |
| 함수 | 선택 유인의 변화 | 규범적 판정 | 이론이 사례를 설명하는 방식 |

## 6. 기존 경제 v2의 기술 지문성 진단

- 관찰값, 측정 장비, 검출 대상, 측정 정밀도라는 어휘장이 기술 지문의 장치 설명을 연상시켰다.
- 문단의 중심이 경제 주체의 선택과 시장 결과보다 측정 도구의 정확성에 놓였다.
- 정책 효과가 기간·집단·시장 조건에 따라 달라지기보다 측정 단계의 오류와 보완으로 이어졌다.
- 따라서 소재가 외부 효과여도 독해 경험은 기술 지문에 가까웠다.

## 7. 경제 v3 설계 원칙

- 소재: 임대료 상한과 주거 보조
- 핵심 축: 계약 임대료와 주거의 총부담, 단기와 장기, 기존 임차인과 신규 진입자, 임차인과 임대인
- 문단 시퀀스: 시장 기준 → 상한의 단기 효과 → 장기 공급·품질 반응 → 집단별 귀착 → 대안 정책과 공급 탄력성
- 문제 시퀀스:
  1. 계약 가격의 하락과 총부담의 변화를 분리
  2. 수혜 집단 일부와 임차인 전체를 분리
  3. 수량·비가격 비용을 새 수치에 대응
  4. 보조금의 명목액과 실제 귀착을 단기·장기로 구분

경제 v3에서는 기술 장치의 입력·처리·출력보다, 하나의 정책이 서로 다른 기간과 집단에 미치는 상반된 효과가 문항 엔진이 된다.

## 8. 통합사회 배경지식형 도입부

평가원 사회 지문의 구조를 따르더라도, 이 프로젝트에서는 통합사회 핵심 개념을 학습할 수 있는 도입부가 추가로 필요하다. 구체 정책에서 바로 시작하지 않고 다음 순서를 사용한다.

`시장경제 → 수요·공급 → 시장 가격의 신호 기능 → 정부의 가격 규제 → 임대료 상한 사례`

여기서 앞의 교과 개념은 단순한 쉬운 설명이 아니다. 뒤의 비가격 비용, 공급 감소, 보조금 귀착을 판단하는 전제가 된다. 이후 문항은 이 정의를 그대로 묻지 않고, 정의된 원리가 새로운 조건에서 어떻게 제한되거나 다른 결과를 낳는지를 묻는다.

## 9. 사회계열 지문의 추론 간격 기준

- 도입 정의: 0~1단계 허용
- 핵심 논증: 2단계 이상을 기본값으로 설정
- 최고난도 관계: 경쟁 경로 또는 2단계 추론과 지연 회수의 결합
- 문항: 4문항 중 최소 3문항을 2단계 이상으로 구성

경제 지문에서는 다음과 같은 2단계 이상의 관계를 우선한다.

- 가격 상한 → 초과 수요 → 비가격 배분 → 총부담 변화
- 임대료 수입 감소 → 관리·공급 선택 변화 → 주거 서비스 또는 신규 진입자의 부담 변화
- 보조금 → 수요 증가 → 시장 임대료 상승 → 임차인·임대인 간 실제 귀착
- 동일 정책 → 기존 임차인과 신규 임차인에게 상반된 효과 → 일부의 이익과 전체 평가의 분리

법 지문에서는 `요건 → 1차 효과 → 예외 → 예외 뒤에도 남는 효과`, 사회문화 지문에서는 `선행 이론 → 계승 요소 → 수정된 전제 → 사례의 다른 해석`처럼 분야에 맞는 매개 고리를 사용한다.
