# 2027년 LEET 언어이해 26번

> QZip의 2차 전사 자료이며 공식 정본이 아니다. 원문 대조용으로만 사용한다.

이 문제는 히트펌프의 작동 과정과 성능계수 관계식을 바탕으로, 윗글에서 논리적으로 따라 나오는 내용을 고르는 문제입니다. 특히 각 방식에서 에너지 보존식과 성능계수 정의를 연결해 보셔야 합니다.

증기압축식 히트펌프에서는 냉매가 증발기, 압축기, 응축기, 팽창밸브를 돌며 열을 옮깁니다. 에너지 보존식은 Q_H = Q_L + W_C이고, COP_H = Q_H / W_C, COP_C = Q_L / W_C입니다. 흡수식 히트펌프에서는 압축기 대신 흡수기, 발생기, 용액펌프가 쓰이며, 발생기 구동열 Q_G와 용액펌프의 일 W_P가 투입됩니다. 이때 에너지 보존식은 Q_H = Q_L + Q_G + W_P이고, COP_H와 COP_C는 각각 Q_H와 Q_L을 Q_G + W_P로 나눈 값입니다.
