# 지문 구성 원리 후보 — PA01~18 도출본

PA19~22를 열기 전에 고정하는 v0. 아래 PA-C 번호는 이 독립 연구의 구성 후보 식별자다. IR-P나 SDSS 번호를 변경·추가한 것이 아니다. ‘복수 근거’는 이번 목적 표본 안의 관찰이며 보편성·학생 학습 효과 검증을 뜻하지 않는다.

## PA-C1 — 같은 대상을 더 정밀한 기준으로 다시 구별한다

- 관찰: 의미와 진위(PA05 P2~P4), 정의와 본질(PA09 P1~P3), 책임 주체와 인정 정도(PA10 P2~P5), 관측 변화와 사건 효과(PA01 P1/P2/P4)가 처음의 가까운 개념을 분리한다.
- 조건: 같은 낱말·지표·행동을 한 축으로만 판단하면 설명 대상의 차이를 놓치는 경우.
- 필요한 이유: 뒤 개념을 ‘더 어려운 추가 지식’으로 두지 않고 앞 이해의 해상도를 높인다.
- 다른 구성: PA14의 두 약제는 같은 지표의 정밀화보다 개입 지점의 병렬 비교다.
- 부자연스러운 적용: 단순 장치 순서를 설명하는데 의미/진위 같은 추상 구별을 덧붙임.
- 집필: 출발 오해를 한 문장으로 쓰고, 이를 구별하는 두 상태를 만든 뒤 정확히 무엇을 같게·다르게 보는지 정한다.
- 검증: 여러 영역의 직접 사례가 있으나 ‘항상 오해로 시작해야 함’은 관찰되지 않았다.

## PA-C2 — 비교 대상들을 공통 과제나 과정의 같은 좌표에 놓는다

- 관찰: PA14 P2의 성장 과정이 두 약의 표적을 위치시킨다. PA06 P1은 두 의미 이론의 공통 과제를 준다. PA17 P1/P5는 순위 결정에 다른 평가축을 결합한다.
- 조건: 여러 이론·방법의 차이를 설명할 때. 비교축의 일부가 다를 수 있음을 허용한다.
- 필요한 이유: 각 방법이 무엇을 해결하거나 측정하는지 알 수 있어 이름·장단점 목록을 넘는다.
- 다른 구성: PA01의 기존 실험/이중차분은 대체 가능성의 조건이 핵심이고, PA17의 중요도/적합도는 서로 대체하지 않는다.
- 부자연스러운 적용: 역사적 학자 모두에게 본문에 없는 동일 질문·평가 척도를 강제함.
- 집필: 공통 대상, 각 방법의 입력·개입 위치·출력·적용 범위를 먼저 나란히 쓴다. 표의 빈칸을 억지로 채우지 않는다.
- 검증: 병렬성이 설명 결함이 아님을 세 영역에서 확인. 어느 배열이 더 잘 읽히는지는 미검증.

## PA-C3 — 중간 변환에서 정보의 뜻을 잃지 않게 연결한다

- 관찰: PA11 P2/P4/P5의 투과·감쇄·역투사, PA16 P2/P5의 배증·발색·Ct, PA17 P3/P4의 분배·댐핑.
- 조건: 원자료가 가공되어 다른 양·표현·판정으로 바뀌는 설명.
- 필요한 이유: 공식 결과만 알려 주면 독자는 왜 그 값이 대상의 특징을 나타내는지 모른다.
- 다른 구성: PA03의 천 개념 변화는 수량 정보의 변환이 아니라 의미와 정당화의 변화다.
- 부자연스러운 적용: 모든 인문 지문에 입력/출력 도식을 강제하거나 학문적 의미를 계산값으로 환원함.
- 집필: 각 변환에 ‘입력은 무엇의 양인가→무엇을 제거·합산·보존하는가→출력으로 무엇을 알 수 있는가’를 적는다. 다음 문단은 그 출력을 실제로 사용한다.
- 검증: 기술·측정 표본의 반복 근거. 원리의 보편성보다 해당 설명 과제에 대한 강한 적합성이 있다.

## PA-C4 — 바뀌는 것과 남는 것을 함께 추적한다

- 관찰: PA03의 천명 수용/독점성 수정, PA02의 규제 틀/구성 변경, PA10의 원고 책임/인정 수준, PA13의 동일 청구/판결 후 법률 상태.
- 조건: 개념·제도·이론의 개정 또는 시점별 적용을 설명할 때.
- 필요한 이유: 독자가 변화=전면 폐기, 같은 이름=같은 상태로 단순화하는 것을 막는다.
- 다른 구성: PA06의 의미 근거 이동은 가치 평가의 초점 변화이며 매 단계가 정식 규정의 개정은 아니다.
- 부자연스러운 적용: 실제 관계가 없는 여러 시대를 하나의 목적적 발전 과정으로 묶음.
- 집필: ‘이전에도 지금도 X는 유지 / Y만 변경 / 그로 인해 Z를 다시 판단’이라는 명세를 만든다. 문장 형식을 그대로 본문에 반복할 필요는 없다.
- 검증: 역사·제도·법적 시점에서 반복. 이 명세가 항상 독자에게 명시되어야 한다는 뜻은 아니다.

## PA-C5 — 독립적으로 준비한 정보층을 필요한 지점에서 결합한다

- 관찰: PA13의 계약 조건과 기판력은 P5에서 합쳐진다. PA02의 금융 기준과 국제 규범은 건전성의 신뢰를 통해 묶인다. PA18은 두 문제 가지 중 하나를 더 깊게 전개하며 중앙값 정의를 공유한다.
- 조건: 단일 원리나 시간순 과정만으로 설명 대상이 끝나지 않을 때.
- 필요한 이유: 여러 문단을 인위적으로 직렬 연결하지 않고도 전체 글의 질문을 유지한다.
- 다른 구성: CT는 실제 단계 의존이 강하다. CT의 연결을 단순 주제 병렬로 느슨하게 만들면 기전이 빠진다.
- 부자연스러운 적용: 동일한 ‘경제’라는 주제만으로 서로 쓰이지 않는 지식 두 묶음을 붙임.
- 집필: 각 정보층이 혼자 답하는 질문, 두 층이 만나야 답할 수 있는 질문을 따로 적는다. 결합 질문이 없다면 한 글에서 함께 다룰 이유를 재검토한다. PA18처럼 공통 목적의 분기 설명 자체가 목표인 경우에는 ‘결합하여 한 결론’까지 강제하지 않는다.
- 검증: 복수 정보층의 존재는 확인. 결합 강도의 최적 수준은 미확정.

## 후보와 집필 검사법을 구별한다

삭제·이동 검토, 예시의 기능 기록, 사실·가정 분리는 이 후보를 적용하고 검수하는 방법이다. 그것 자체를 새 평가원 구성 유형으로 세지 않는다. ‘문제→정의→사례→한계’라는 공통 문단 배열은 이번 표본으로 정당화되지 않는다.

보류검증 전의 예측: PA19의 예술론은 PA-C2/C4로 일부 설명되더라도 비판의 판단 기준을 놓칠 수 있다. PA20/21의 기술·측정은 PA-C3에 맞는지 실제 매개를 확인해야 한다. PA22의 법은 PA-C1/C4에 맞더라도 예외를 무조건 완화로 해석하면 실패할 수 있다. 이 예측은 제목·첫 문장 수준의 표집 정보에서 세운 것이며 본문 확인 뒤 사후 맞춤으로 바꾸지 않는다.
