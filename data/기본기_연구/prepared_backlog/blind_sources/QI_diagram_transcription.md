## 노드·분기·화살표 전사

1. 사각형: `주소창에서 사용자가 입력한 도메인 네임을 읽는다.`
   - 아래 화살표 → ⓐ
2. 사각형: `ⓐ: 질의 패킷을 보낸다.`
   - 아래 화살표 → ⓑ
3. 사각형: `ⓑ: 응답 패킷을 받는다.`
   - 아래 화살표 → 판단 마름모
4. 판단 마름모: `특정 질의 패킷에 대해 처음 받은 응답 패킷인가?`
   - `아니오`(왼쪽) → ⓓ
   - `예`(아래) → 다음 판단 마름모
5. 사각형: `ⓓ: 응답 패킷을 버린다.`
6. 두 번째 판단 마름모(ⓒ): `다른 네임서버의 IP 주소를 알려 주는 응답 패킷인가?`
   - `예`(오른쪽) → 위쪽/오른쪽으로 되돌아가 ⓐ 직전의 질의 단계로 순환
   - `아니오`(아래) → ⓔ
7. 사각형: `ⓔ: 응답 패킷에 적힌 IP 주소로 접속한다.`

## 기계 정정 이력

- 2026-09-18: 최초 전사에서 ⓒ를 `다른 네임서버의 IP 주소를 이용해 질의 패킷을 보낸다`라는 사각 동작으로 잘못 기록하고, ⓒ/ⓔ의 분기 방향을 뒤바꾼 오류를 확인했다.
- 부모 Astra의 원도식 직접 판독에 따라 ⓒ를 판단 마름모로 정정했다. 이미지가 잘려 겹쳐진 구간의 세부 선분 좌표는 별도 단정하지 않고, 확인 가능한 노드·분기·순환 관계만 기록했다.

## 복원 범위·노출 통제

이 파일은 QI의 blind `<보기>` 도식만 복원한다. 공식 답, SDSS 태그, 기존 해설·코드 판정, sealed 자료는 읽거나 기록하지 않았다. QI의 `hold` 상태와 G111 blind barrier는 Astra가 직접 확인하기 전까지 유지한다.
