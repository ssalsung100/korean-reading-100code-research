# 추가 참조3군의 귀납과 국소 정합 점검

R7·R8·R9의 추가 검토가 끝난 뒤 R074 `meta_induction`, R075 `manual_parity_audit`를 먼저 raw로 저장했다. 이 파일은 그 판단을 문서화한 것이다. 기존 기본기 원장의 누계·완료 상태·코드 판정을 수정하지 않는다.

아래 귀납 표는 R074 시점의 판정을 보존한다. 후속 R094에서는 공유1의 직접 근거를 R7에서 R9 8③으로 교체하고 R7 연결을 기능적으로 낮추었다. 최신 판단은 [대응표](기출핵심판단_신규문항_대응표.md)를 따른다. 과거 점검 결과를 최신 판정처럼 소급하여 덮어쓰지 않는다.

## 귀납에서 유지한 차이

|자료|정답의 실제 연산|같다고 묶지 않은 연산|R074 당시 제작 결정|
|---|---|---|---|
|R7 데이터 권리|권리의 종류·행사 대상에 대한 규칙 적용|권리가 모두 하나의 소유권이라는 도식|공유1의 국소 권한 대조는 직접 대응. 다른 권리 사례 전체로 확대하지 않음.|
|R8 공포 소구|닫힌 입력-출력 관계에서 관찰과 양립하는 입력 복원|알려진 입력으로 결과를 계산하는 순방향 적용|확산2를 실제로 바꾸어 역복원과 일부 미정 상태를 구현.|
|R9 자료 처리|대표값의 민감도, 임시 집합·후보 단계의 가능성|지역별 가중 집계, 잘못된 차감항의 편향 방향|빈곤2를 유지. 평균이라는 공통 단어만으로 직접 대응을 부여하지 않음.|

세 자료 모두 명칭이나 결과 하나만으로 충분하지 않음을 보여 주지만, 그 사실을 새 상위 원리 하나로 묶어 동일 연산이라고 선언하지 않았다. R7의 제외 조건, R8의 입력 후보 범위, R9의 후보 단계가 각각 다른 정보를 요구한다.

## 원문·raw·보고서의 국소 대조

핵심 표본은 R7의6번, R8의YT(6번), R9의DX(10번)이다. 전체 원장에 대한 전수 감사가 아니다.

|점검 항목|확인 결과|처리|
|---|---|---|
|원문 결정 조건|R7 새 가치 생성, R8 닫힌 조합·이론 부합, R9 후보 단계가 핵심|요약에서도 이 조건을 생략하지 않음|
|최소 풀이|R8은 집단3·4만으로 답, R9는 후보 생성 단계만으로 답|다른 집단·최종 알고리즘 전체 분석을 정답자의 필수 수행으로 합산하지 않음|
|노출|R7 정답 노출 사고, R8 세션 순서 준수/과거 불명, R9 같은 시험 정답 기노출|서로 다른 노출 경위를 보존. 엄격 blind 성과로 확정하지 않음|
|태그 순서|R8·R9는 전체 코드 판정 저장 후 태그 공개|답 일치와 코드 의미 일치를 구별|
|의미 정합|R7의 일부 비교 요약은 ‘새 가치 생성’을 단순 가공이라는 말로 줄여 읽을 위험이 있었음|해당 조건을 요약에 다시 명시하여 보완|
|원문 미정 범위|R9의 등호 경우·거리 집계 방식 미명시|새로운 내용으로 메우지 않고 답에 필요한 범위만 확정|

R9의 독립 주 코드와 사이트 태그가 다르거나 판독 층위가 겹쳤다. 특히10번의 사이트‘양상’은 가능/보장 축, 독립‘대상범주·선후’는 그 가능성이 어느 대상·단계에서 성립하는지에 초점을 둔다. 둘을 같은 정답 경쟁으로 단순화하지 않는다. 사이트의 전체 의도나 정의는 태그만으로 확인되지 않았다.

## 판단을 출제 규칙으로 옮길 범위

1. 같은 용어를 쓰더라도 정답을 결정하는 입력·관계·목표가 다르면 기능적 또는 넓은 유사성으로 남긴다.
2. 관찰에서 원인을 되찾는 문제에는 가능한 기준과 그 밖의 요인을 제한해야 한다. 여러 후보가 남는 관찰은 미정으로 둔다.
3. 절차 중 붙인 집합의 이름과 실제 자료의 성질을 같다고 보지 않는다. 후보 생성과 최종 판정의 조건도 구별한다.
4. 새 문항에서 실제 판단할 등호·분모·시점은 명시한다. 원기출에 미정 부분이 있다는 사실을 새 원고의 결손을 허용하는 근거로 쓰지 않는다.
5. 통계량의 변경은 같은 지표의 단순 개선이 아닐 수 있다. 빈곤2의 중앙값0과 평균0.16은 서로 다른 대상을 나타낸다.

## 정리 방식과 한계

최신 사용자 요청의 다른 모델 호출 금지와 기존 원장 읽기 전용을 따라, 이번 폴더의 판단·문서 정리는 주 작성자가 직접 수행했다. Luna를 호출하거나 외부 독립 감사를 받았다고 기록하지 않는다. 기존 공용 queue의 sync·진행률 갱신도 하지 않는다.

추가 심층 보완이 필요한 정답 미해결 사례는 이 표본에서 남지 않았다. 다만 R9의 원문 서술 범위, 태그 저자의 의도, 실제 학생 난도·오답률은 확인되지 않았다. 이러한 서로 다른 유보를 ‘검증 완료’ 한 문장으로 지우지 않는다.
