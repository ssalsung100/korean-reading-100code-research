# 통합사회 전체 범위 출제 배분표

> 174개 개념이 어느 세트의 본문·문항·해설에서 학습되는지를 추적하는 누락 방지표이다.

## 배분 규칙

- A급: 서로 다른 세트에서 최소 2회 노출
- B급: 최소 1회 본문 노출
- C급: 최소 1회 본문 노출하고, 3단계 심화 개념은 해설 연결 지시 추가
- 같은 세트에서 본문과 해설에 반복되어도 세트 노출 횟수는 1회로 센다.

## 요약

- 개념 174개 전부 배정
- 세트 묶음 50개: 윤리 6, 지리 11, 사회문화 5, 경제 14, 법과 정치 5, 역사 3, 융합 6
- 중요도: A 46 / B 75 / C 53
- 검증: **PASS** — 누락 0, 노출 미달 0, 묶음 내부 단계 역전 0
