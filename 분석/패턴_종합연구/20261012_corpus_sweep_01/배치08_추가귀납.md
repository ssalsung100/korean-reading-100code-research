# 배치08의 직접 종합과 경계

40지문·53장면을 추가했다. 누적300지문·388장면이며195지문이 남는다. 각 그룹의 기존 완성 풀이를 읽고 A~F를 저장했으며 모든 선지 전수 주석이나 일반 타당성 검증 완료를 뜻하지 않는다.

- U0336/BBF: ㄷ·ㄹ→ㄴ, ㄴ·ㅁ·ㅂ→ㅅ이라는 근거 합류는 추상 표상 병치와 다르다. U0336/BBH의 물리 장치→기관 기능 유추도 수치 역산과 인과 설명 방향의 구별과 다르다. 최초의 넓은 후보 연결을 수정 원장에 보존하고 각각 근거망복원·기능유추로 분리했다.
- U0104/PI: 정책 조정은 고정 기준4% 대비1.5%p이며 분기별 요인은 독립이다. 한 분기 시차·한 분기 지속을 적용해1월과4월 모두5.5%로 설정한다. 이력에 따른 상전이 상태가 아니므로 경로의존에서 조정기준시점으로 수정했다. 보기·선지를 직접 대조했다.
- U0345/BCH와 U0346/BCM: 표면 소재보다 호감이라는 평가 방향 또는 접근→구속의 상태 관계가 함축 기능의 대응 근거다. 이전 U0341/BBV의 눈·물소리와 고향 그리움 장면도 비교할 수 있지만 이번 빈도에 새 장면으로 자동 추가하지 않았다.
- U0374/BFS: 연속 갱신 증분이면 망원합으로 순변화를 얻지만 같은 사전에서 따로 평가한 증거 힘은 가산성이 주어지지 않는다. 정답 일치로 경계 유보를 해소하지 않았다.
- U0344/BCF: 최초 실패는 전사 오류로 설명되지 않는다. 항성수명의 간접 영향과 행성 온도·원소의 간접 영향을 비대칭으로 취급한 실패 후보를 보존한다. 은하 원소 종류의 완전 배제 논거는 후속 기록에서도 유보이므로 확정 사례로 세지 않았다.
- U0376/BFX: 계통수 구조답과 선지 번호 대응의 확신을 구별한다. 시각 자료의 순차 번호를 공식 선지 번호 확정으로 바꾸지 않는다.

규칙우선순위·집계정보손실·직전상태갱신·사건서술시간분리·반사실유사성·누락연결전제는 구체 행동과 조건으로 새 후보에 보존했다. 단일 사례의 새 후보를 보편적 기본기로 확정하지 않는다. KICE 제작에는 시차·갱신·분모·관계 당사자가 명시된 장면을 우선 사용하고 LEET/MEET의 유보된 강도와 번호 매핑을 그대로 옮겨 모호한 정답 근거를 만들지 않는다.

기계 검사는 식별·중복·원장 payload·사용한 원문 해시의 연결만 확인한다. 의미 검증과 원문 이미지 전수 재검수는 별도이다. 다음 배치로 계속 진행한다.
