# 연구자 읽기 안내

먼저 학생용 후보를 보고, 그다음 해설과 실제 기출을 나란히 읽는 순서를 권한다. 학생용에는 정답·설계 메모를 넣지 않았다. 이 안내 자체에는 정답이 있으므로 실제 풀이를 먼저 하려면 아래 학생용 파일만 열면 된다.

인쇄·열람용은 [학생용 6쪽 합본](출력본/학생용_4세트_합본.pdf), [교사용 9쪽 합본](출력본/교사용_4세트_합본.pdf)이다. 전달용 [학생용 ZIP](출력본/학생용_4세트_문제와원고.zip)에는 학생용 PDF와 원고만 있다. 수정할 때에는 아래 Markdown을 기준으로 고친 뒤 [재생성 절차](출력본/읽기와_재생성.md)를 따른다.

선택적 추가 실험은 [사회적 확산 학생용](D_추가연구/04_사회적확산_학생용후보.md)과 [교사용](D_추가연구/05_사회적확산_교사용.md)이며 현재 답③⑤③이다. 초기 직접 대응 미확보 이후 R8을 추가 분석하여2번을 역복원 문항으로 바꾸었다. 이어3번은 I의 최초 채택 시점과 II의 최종 채택 여부를 함께 판단하도록 [선택지 구조를 개정](D_추가연구/08_확산3_고정상태_필수판단_대안.md)했다.2번의 국소 직접 대응과1·3번의 기능적 유사성을 구별하며, 세트 전체의 동일 수준 인증으로 읽지 않는다.

## 네 가지 연구 검토 지점

1. **기출 대응을 낮춘 곳부터 확인한다.** [대응표](기출핵심판단_신규문항_대응표.md)에서 기존 빈곤2의 수량적 동일성과 R3의 제도적 공통 속성을 구별했다. 비교라는 공통 이름만으로 직접 대응하지 않았다.
2. **수정이 실제 풀이를 바꿨는지 본다.** [빈곤 대안](A_지역빈곤/02_대안문항_비교.md)은 두 문항을 5선지까지 완성해 비교했다. 선택한 A는 차감항 대체가 정답 근거가 된다. 미선택 B도 구성 변화라는 다른 가치가 있다.
3. **다른 문항의 답 단서를 점검한다.** [품질 수정 기록](B_품질보증/05_자체검증과_수정.md)은 초기 교차 단서를 제거했다. [공유 재설계](C_공유자원/05_3번_재설계와_비교.md)는 권리 분류를 반복하던 3번을 반례 평가로 바꾸었다.
4. **무엇을 검증하지 못했는지 본다.** [교차 검토](문항품질_교차검토.md)는 수치·정오·기출 대응·학생 반응을 구분한다. 실제 학생 자료가 없어 난도·변별력·선택률을 인증하지 않는다.

## 근거를 따라가는 경로

- [최근 기출 정밀 분석](최근기출_핵심판단_정밀분석.md): 기존 여섯 세트의 11개 핵심 문항. 기존26문항 연구를 새 실적으로 중복 합산하지 않음.
- [추가 R7](추가기출_R7_권리의대상과_효과.md): 2024 9월 데이터 권리. 선택표 원문 복원과 정답 노출 경위를 공개. 엄격한 blind 실적 아님.
- [추가 R8](추가기출_R8_관측결과와_입력복원.md): 2024 6월 공포 소구. group 전체 최초 풀이→공식답→독립 코드→태그 순서를 지켜 관측 반응에서 입력을 복원하는 판단을 확보. 과거 노출 불명으로 엄격한 blind 성과 확정은 아님.
- [추가 R9](추가기출_R9_대표값과_후보단계.md): 2024 수능 자료 처리. 평균이 나온다는 이유로 빈곤의 가중 집계와 같다고 묶지 않은 부정적 대조. 이후8번의 명시 예외/일반 진술 대조를 공유1의 직접 근거로 재사용하고, 이전 R7 연결은 기능적으로 낮췄다. 사이트 태그와 독립 판정의 차이·원문 미정 경계도 보존한다.
- [추가3군 귀납·정합 점검](추가참조3군_귀납과_정합점검.md): 비교 요약에서 원문의 한정이 보존됐는지 국소 대조한 결과.
- [분야별 기준](분야별_정보논리_제작기준.md): 유지할 대상, 명시/복원 관계, 보기의 추가 조건을 분야별로 비교.
- [학술 근거](신규소재_선정과_학술근거.md): 직접 읽은 원문 쪽, 자체 유도, 창작 가정을 구별.
- [교과 원문 대조](교과기초_심화연결_직접대조.md): 실제 교과서·경제 학습 자료의 기초에서 무엇을 심화했는지와, 사회 간 문화 전파/개인 간 채택의 단위 차이를 확인.
- [다음 제작 기준](다음제작_실행기준_v1.md): 실제 수정·반례에서 도출한 실행 규칙.
- [요구사항별 수행 근거](요구사항별_수행근거와_유보.md): 실제 산출물·판정·검증과 미확인을 연결한 대조표. [문체·범위 대조](문체와_문장범위_최종대조.md)는 현재 문안의 구체 위치에서 권장의 적용과 유지 이유를 확인한다.

## 보존과 재개

실제 독자 반응을 받을 때는 [학생용 응답기록지](후속검토/학생용_응답기록지.md)와 [교사용 관찰 기준](후속검토/교사용_관찰기준.md)을 사용할 수 있다. 먼저 기본4세트의 자유 풀이를 남긴 뒤 추가 확인을 제시하도록 구분했다. 추가 자료는 정답만으로 식별되지 않는 가중 방법·기준 복원을 살펴보는 서술형이며 아직 실시하지 않았다. 실제 응답 수는0이다.

각 세트의 `02_학생용_초안.md` 또는 빈곤의 `초안보존/`은 출발본이며, `03_학생용_최종후보.md`가 현재 후보이다. 중간의 의미 있는 변경 전 문안은 `개정이력/`에 둔다. raw는 append-only이며 사후 정정은 새 record로 추가한다. 완료 상태와 이후 재개 기준은 [checkpoint](checkpoint.json), [재개 기록](재개기록.md), [결과 보고](연구결과_보고.md)를 따른다. 최종 후보라는 말은 이번 내부 비교에서 선택했다는 뜻이며 전체 100코드 연구 완료를 의미하지 않는다.
