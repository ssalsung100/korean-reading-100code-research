# 배치09의 조건과 반례

40지문·41장면을 추가하여340지문·429장면을 저장했다. 남은155지문을 이어간다.

U0350/BCZ에서는(7,8)과(5,10)의 합계가 모두15라도 전자는 일방 변경이 불리하고 후자는 갑의5→7 이탈이 가능하다. 합계와 안정성을 구분하는 일방변경안정성을 새 후보로 보존했다.

U0389/BHG 후속 보강은 두 후보 모두 범위 밖이면 기권한다는 규칙의 대우까지만 보장한다. 범위 안→투표, 특정 후보 투표→그 후보 범위 안은 추가 규칙이다. 감소량이 없는 후기 효용에서는 예선0/9도 모든 허용 모형의 유일 결과로 강제되지 않는다. 수치 탐침은 조건 점검이며 출제 빈도에 추가하지 않는다.

U0395/BHY에서는B10℃·1T와C18℃·1T가 같은 장세기라도 온도는 다르다. 관측된 각 임계조건의 후보 적합성과 공통온도에서의 물질효과 식별을 구분했다. U0394/BHV는 유능한 타인·협동이 결합된 처리 효과를 비교하는 설계이며 각각의 순수효과 분리는 아니다.

U0357/BDS의 병렬 구조는 A층에 있지만 실제 정오 판단은 각 억제·활성에서 스트레스 해소의 방향을 추적한다. 공통 배경의 두 결과를 직접 인과로 잇지 않기라는 후보와 합칠 수 없어 조건부방향으로 수정했다. U0396/BIB도 필요조건에서 선후를 추가하는 행동이 아니므로 단계별 후보·차단·산출의 단계구분으로 수정했다. 수정 원장을 적용한 집계를 사용한다.

KICE의 TG 출력 대상, UK 공간 구별성과 시간 안정성, UH 지질·캡시드 기능의 독립 상태는 신규 제작에서 중간 추론을 선명히 만들 수 있다. 조합 요건·값·대상 중 하나만 바꾸는 선지는 실제 오답 작동을 보존한다. 후보 중요도는 이 명료성과 재사용 조건을 함께 보며 빈도 순서만으로 정하지 않는다.
