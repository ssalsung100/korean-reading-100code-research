# 코퍼스 종합 연구의 현재 결과

고유 지문 그룹 495/495개를 1차 종합하여 616개 판단 장면, 590개 고유 문항에 직접 연결했다. 대상 지문의 1차 종합은 완료했다. 문항·선지별 전수 장면 추출과 심층 보완은 남아 있다.

원장 7,605건은 출제 문항 수가 아니다. 현재 연결 집합은 완료·단일분석자 검토 기록 1,730건, 이에 연결된 고유 문항 1669개, 반복 분석 61건이다. 기존 보류 지문에 붙은 완료 초기 분석 2개 문항도 별도 보존하여 이번 추출의 대상 문항은 1667개이다. 추출 대상 지문은 495개이고 보류 지문 2개를 합한 연결 지문은 497개다.

이 수는 본문 정규화와 식별자 연결로 확정한 저장소 단위 수다. 실제 시험지 이미지 전수 대조에 따른 출제 이력의 최종 확정은 아니다. 완료 표시는 원 연구의 완료 상태를 승계하며 의미 타당성의 전수 재검증을 뜻하지 않는다.

1,730건은 준비 코퍼스의 consumed_sdss 1,663건, 초기 연구03/04의 25건, 코드 검토01/02의 single_analyst_reviewed 42건이다. 마지막 42건의 독립 절차·추가 검수 완료를 주장하지 않는다. 최초 blind·공식 대조·독립 판정·후속 수정의 관계는 원장 ID와 문서 경로에 별도로 보존한다.

## 현재 후보와 실제 근거

### 가중된 변화의 상쇄와 개별 변화 크기 구별하기

계수와 개별 변화량을 분리하고 가중합이 일정한 식에서 변화 방향과 크기 비율을 각각 복원한다.

적용과 경계: 가중 관계식과 계수 조건이 필요하다. 가중합0은 개별 변화량이 같은 크기라는 뜻이 아니며 계수의 극소·극대 조건을 유지한다.

현재 근거: 1 지문 / 1 문항 / 1 풀이 장면 / 구조만 0 지문.

- `U0467-S02`: 분몰부피 변화가 반대 방향이라는 관계를 같은 크기의 변화로 읽는다. nS·dVS+nR·dVR=0에서dVS=-(nR/nS)dVR이다. a에서nR/nS=10^-6이므로 다량S의 변화는 희석R보다 훨씬 작아③의 같은 급격함은 틀리다.

구성 활용: 희석 성분과 다량 성분의 몰수를 크게 다르게 놓고 분몰부피 변화의 반대 방향과 상대 크기를 따로 묻는다.

### 연결 변화 뒤 분배와 후속 경로를 다시 계산하기

새 연결로 직접 늘어난 값뿐 아니라 기존 연결의 몫 변화와 후속 합계를 재계산한다.

적용과 경계: 송신값·나가는 링크 수·감쇠 규칙이 제시되어야 한다. 링크가 늘면 수신값이 단순 추가된다고 가정하지 않는다.

현재 근거: 1 지문 / 1 문항 / 1 풀이 장면 / 구조만 0 지문.

- `U0019-S02`: e→c 링크 추가의 직접 유입과 e→b 감소 뒤 후속 유입을 함께 계산한다. e=16, 두 송신 링크와 0.5→e→b=4, e→c=4→b=4, b의 두 링크→b→c=1→c=5. 기존 b=8을 고정하면 틀린다.

구성 활용: 링크 추가가 기존 수신을 줄이면서 다른 경로로도 값을 보내는 소규모 도식을 만든다.

### 하나의 값과 그 값을 갖는 대상의 수 구별하기

관계의 입력을 고정하고 같은 값이 되는 입력값 수와 그 입력값에 대응하는 실제 대상 수를 차례로 센다.

적용과 경계: 값과 대상의 대응 및 대칭 조건이 확인되어야 한다. 단조적인 에너지-반경 관계의 유일성을 에너지-공간위치의 유일성으로 확대하지 않는다. 필요한 추가 가정은 원문 조건과 구별한다.

현재 근거: 1 지문 / 1 문항 / 1 풀이 장면 / 구조만 0 지문.

- `U0428-S01`: 같은 에너지의 반경값 하나를 궤도 위 지점 하나로 바꾼다. 최초 풀이가 사용한 K최근점>KY>K최원점과 중간 반경의 두 대칭 지점 아래에서 에너지가 같은 반경은 하나여도 지점은 둘이다. 후속6725행은 r*=2r0(r0+ra)/(ra+3r0)를 도출하되 각운동량·원궤도 속력·대칭 기하 H1~H3를 추가 가정으로 분리했다.

구성 활용: 하나의 반경값에 대칭인 두 지점이 있는 궤도를 주고 에너지가 같아지는 반경의 수와 공간지점의 수를 따로 묻는다.
