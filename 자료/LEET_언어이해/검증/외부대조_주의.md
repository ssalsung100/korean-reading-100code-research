# 외부 전사 자료 사용 주의

QZip의 문항별 텍스트는 이미지형 공식 PDF의 OCR을 검토할 때 사용하는 **2차 대조 자료**일 뿐, 정본으로 사용하지 않는다.

실제 대조에서 외부 전사 오류가 확인되었다.

- 2022학년도 언어이해 1번 지문
  - 공식 문제지 페이지: `개척의 터전으로 총진군했던 부랑인 가운데`
  - QZip 전사: `개척의 터전으로 충진군했던 부랑인 가운데`

따라서 QZip 문장을 정본 Markdown에 복사하지 않는다. OCR과 QZip이 일치하더라도 공식 페이지 이미지 대조를 통과하기 전에는 `검증 완료`로 표시하지 않는다.
