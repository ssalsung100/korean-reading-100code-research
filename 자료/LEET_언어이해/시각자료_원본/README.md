# LEET 작업형 문제지 시각 자료

## 범위

텍스트 층이 없는 작업형 문제지 3종의 공식 페이지를 전수 확인하여, 문항 판단에 직접 쓰이는 표·그래프·도식을 별도 PNG로 잘라 두었다.

- 2022학년도 홀수형: 3개
- 2023학년도 홀수형: 4개
- 2027학년도 단일형: 6개
- 합계: 13개

각 파일은 공식 PDF의 전체 페이지 PNG에서 필요한 사각 영역만 자른 것이다. 별도로 내려받은 원본 벡터나 출판용 삽화가 아니며, 픽셀을 보정하거나 도형·문자를 다시 그리지 않았다. 출처 페이지, 페이지 SHA-256, 자르기 좌표, 결과 파일 SHA-256은 [manifest.json](manifest.json)에 기록되어 있다.

## 사용 규칙

1. 문항·지문을 전사하거나 분석할 때에는 이 크롭만 보지 말고 `manifest.json`에 연결된 공식 전체 페이지도 함께 확인한다.
2. 표의 수치, 그래프의 축·범례, 게임 나무의 분기·보수는 OCR 문장이 아니라 PNG의 표기를 기준으로 한다.
3. 새 문항 제작에 구조를 참고할 수 있으나, 원 도표를 변형하여 평가원·LEET의 새 기출처럼 표시하지 않는다.
4. 문제·정답의 저작권은 법학전문대학원협의회에 있으므로 프로젝트 내부의 검증·분석용으로 사용한다.

## 재생성

```bash
python3 scripts/extract_leet_working_visuals.py
```

자르기 좌표를 바꾼 경우에는 13개 PNG를 다시 육안으로 확인하고, 검증 스크립트를 실행한다.
