# 빈곤 지표 학술 근거의 국소 재확인

기존 지문의 학술 근거 기록을 읽은 뒤, 이번 실행에서 원기관 자료의 필요한 부분을 직접 확인했다.

- [World Bank PIP 2022-04 방법론 §4.1](https://worldbank.github.io/PIP-Methodology-2022-04/surveyestimates.html): 빈곤율의 분모는 전체 인구이며 빈곤갭지수는 빈곤선 대비 부족액의 전체 평균이다. 비빈곤층의 부족액은0으로 둔다. 페이지 자체가 최신판이 아님을 명시하므로 현행 국제 빈곤선·최신 방법론 전체의 확인이라고 쓰지 않는다.
- [World Bank, Introduction to Poverty Analysis §7.2](https://documents1.worldbank.org/curated/en/775871468331250546/pdf/902880WP0Box380okPovertyAnalysisEng.pdf#page=69): 서로 배타적인 집단의 지표를 인구 비중으로 가중하여 전체를 얻는 가법적 분해를 확인했다. 텍스트와 변수 설명을 읽었으며 새 지면 렌더 전수 대조는 아니다.

개인 소득·공통 빈곤선·가중치에 관한 학생용 가정은 단순 모형의 한정이다. 실제 조사 가중치나 지역별 생계비 차이를 처리했다고 주장하지 않는다. 지역 이름·인구·소득·지원액은 창작이다.

지수 분해와 지급액의 상한 처리는 별도 자체 유도로 검산했다. `G=Σmax(z−y,0)/(Nz)`에서 바로 도출되는 관계를 사용하며, 관측된 정책의 인과효과를 추정하는 식으로 바꾸지 않는다. 기존 지문을 수정할 학술적 오류는 이번 확인에서 발견하지 못했다.
