# LEET HWP 홀수형 시각 자료 검증 상태

## 결론

분석 정본으로 사용할 범위는 사용자가 선택한 **2009학년도 예비시험~2021학년도 홀수형 14개 문제지**이다. 이 범위에서 HWP 텍스트 스트림은 정본 Markdown과 문자 단위로 일치하며, 내장 그림·자료표·선지표·`<보기>`를 본문 및 개체 스트림 순서에 따라 문항군에 연결했다.

- 내장 그림: 46개
- 의미 자료표: 14개
- 선지 배열표: 5개
- 구조화된 `<보기>`: 125개
- 문항군 매핑 재검토 대상: 0개

내장 그림 46개는 전부 육안으로 판독했고, 원본 바이너리를 해독한 픽셀과 PNG 작업본의 픽셀이 일치함을 확인했다. 이어 한컴의 페이지 이미지 생성 기능으로 14개 문제지 216쪽을 렌더링하고, 재사용 대상 65개(그림 46개·자료표 14개·선지표 5개)의 **원래 쪽·단·줄·글자 위치와 HWP List/Para/Pos 앵커**를 확정했다. 그림 46개는 확정된 쪽의 렌더링 이미지에서 원본 그림과 픽셀 템플릿을 다시 대조했으며 전부 확인되었다.

## 사용 기준

- 그림의 정본은 HWP에서 추출한 원본 바이너리이다.
- PNG는 판독과 Markdown 삽입을 위한 무손실 작업본이다.
- 표는 `표/` 아래의 구조화된 Markdown을 사용한다.
- 문항군 연결은 [HWP 홀수형 시각 자료 문항 매핑 원장](HWP_%ED%99%80%EC%88%98%ED%98%95_%EC%8B%9C%EA%B0%81%EC%9E%90%EB%A3%8C_%EB%AC%B8%ED%95%AD%EB%A7%A4%ED%95%91_v1.md)을 따른다.
- 재사용 가능한 그림·표의 통합 목록은 [LEET 홀수형 시각 자료 전체 목록](LEET_%ED%99%80%EC%88%98%ED%98%95_%EC%8B%9C%EA%B0%81%EC%9E%90%EB%A3%8C_%EC%A0%84%EC%B2%B4%EB%AA%A9%EB%A1%9D_v1.md)을 따른다.
- 정확한 원래 쪽·단·줄·글자 위치는 [HWP 홀수형 페이지·좌표 검증](HWP_%ED%99%80%EC%88%98%ED%98%95_%ED%8E%98%EC%9D%B4%EC%A7%80%EC%A2%8C%ED%91%9C_v1.md)을 따른다.

## 검증 방법

1. `hwp5txt` 재추출문과 정본 Markdown 본문을 문자 단위로 비교했다.
2. `hwp5html`이 제공하는 본문·표·개체 스트림 순서와 명시된 문항 범위를 결합하여 각 자산을 문항군에 연결했다.
3. 자동 문항 번호가 스트림에서 사라지는 일부 앞부분 문제는 정본의 문항 문구와 해당 표 내용을 직접 대조하여 고정했다.
4. 내장 그림 전부를 연도별 접촉 인화지에서 육안 판독했다.
5. 원본 이미지와 PNG 작업본을 같은 색상 모드로 해독한 뒤 픽셀 해시를 비교했다. 46개 모두 일치했다.
6. HWP의 각 그림·표 컨트롤에 `GetAnchorPos(0)`을 적용하고 해당 위치에서 인쇄 쪽·단·줄·글자 위치를 읽었다.
7. HWP 컨트롤 스트림의 그림·표 순서를 기존 자산 스트림 순서와 일대일 대조했다. 46개 그림과 전체 표 컨트롤 수가 모두 일치했다.
8. 144 dpi로 렌더링한 해당 쪽에서 원본 그림을 HWP 개체 크기 주변의 다중 축척으로 대조했다. 그림 46개 모두 픽셀 경계 상자가 확인되었다.

## 남는 한계

HTML 변환본은 원본 HWP의 페이지 나눔을 보존하지 않으므로 쪽·단 위치의 근거로 쓰지 않는다. 쪽·단·줄·글자 위치는 HWP 내부 앵커를 근거로 하고, 그림의 픽셀 경계 상자는 한컴 페이지 렌더에서 검증한다. 구조화된 Markdown 표는 래스터 원본이 아니므로 픽셀 경계 상자를 별도로 주장하지 않고 HWP 표 앵커를 좌표 정본으로 삼는다.

일반 `<보기>` 배치 상자 125개는 문항군 연결이 완료되어 있으나, 문제 제작에 재사용할 독립 시각 자료가 아니므로 이번 좌표 전수 감사 대상에서는 제외했다.

짝수형은 사용자의 결정에 따라 분석 정본 범위에서 제외했다. 파일 무결성과 직접 텍스트 추출 여부는 보존하지만, 홀수형과 같은 시각 자료 전수 판독을 마쳤다고 표시하지 않는다.
