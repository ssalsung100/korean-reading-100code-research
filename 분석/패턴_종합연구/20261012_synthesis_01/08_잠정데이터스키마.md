# 전체 코퍼스 분석을 위한 잠정 데이터 스키마

이 명세는 후속 작업의 입력 계약이다. 이번 실행에서 전체 코퍼스를 재분류하지 않았다. [corpus_event.schema.json](corpus_event.schema.json)은 JSON Schema 2020-12 형식의 `0.3-draft`, [schema_examples.jsonl](schema_examples.jsonl)은 현재 표본의 7개 예시 레코드다. RX를 서로 다른 단계의 두 레코드로 저장하여 결손 보류와 보강 사용을 덮어쓰지 않는 방식을 보여 준다.

## 기본 단위와 연결

`source identity → analysis condition → source state → text structure → item manipulation → reasoning steps → judgment`를 하나의 판단 장면에 묶는다. 패턴 라벨은 마지막 연결 정보이며 이 경로를 대신하지 않는다. 동일 문항에서 여러 선지가 서로 다른 연산을 요구하면 장면을 나눈다. 한 선지에 두 결손이 있으면 ATN③처럼 한 레코드의 서로 다른 단계 또는 분리된 장면에 담되 고유 선지 수를 늘리지 않는다.

|필드|내용|반드시 지킬 경계|
|---|---|---|
|record_id|분석 실행·장면의 안정 ID|같은 case의 Sol/외부 적용/C를 다른 record로 보존|
|source_identity|case·group·passage·identity_family·question·시험계열·표본 분할·선지|group 관리번호와 고유 지문 동일성을 구별; alias로 독립 증거 증식 금지|
|analysis_condition|코드북·기존 풀이 사전 열람, phase, 과거 노출 이력, 관찰 여부|현재 세션 미열람과 과거 미노출은 별개|
|source_state|완결·결손·시각 전사·보강 사용과 제한|자료 결손을 비적용·논리적 미확정으로 바꾸지 않음|
|text_structure|지문 조직과 그 장면에서 실제 사용 여부|구조 존재→문항 활용 자동 복사 금지|
|item_manipulation|원문에서 유지·변경한 항목, 발문의 요구|문항 설계 조작과 학생 행동을 중복 패턴으로 세지 않음|
|reasoning_steps|입력, 연산, 간선 의미, 출력, 근거 ID|화살표에 정의·시간·조건·증거 등 의미를 명시|
|judgment|내용 상태, 요구 역할 적합성, 발문 극성, 선택 행동, 그 단계의 선택, 기존 답 대조|부적절한 내용과 정답 선택이 동시에 가능. 과거 null 소급 수정 금지|
|pattern_links|구조·활용·유용·설명·경계·미확인·미분류; 하위형과 필수성|상위 후보 적용을 모든 하위형 검증으로 해석하지 않음|
|evidence|파일·SHA·pointer·문자 구간·정확한 인용·검수 수준|문자 일치는 논리적 충분성 인증이 아님|
|boundary|최소 적용 조건, 비적용, 실제 경계/강한 반례/창작 반모형, 대안 경로|경계 사례와 규칙 자체를 깨는 강한 반례를 구분|
|uncertainty|원문·논리·반복·노출·원지면·의미·학생 효과 한계|서로 다른 이유의 ‘모름’을 합치지 않음|
|teaching_and_design|재현 행동과 제작 제약, 학생 효과 검증 여부|기출 풀이 가능성을 학생 효과로 대체하지 않음|
|lineage|원 후보 ID, 이전 기록 참조, supersedes, 수정 이유, 실행 ID|수정된 의미와 최초 판정을 모두 보존|

문자 구간은 디코딩한 문자열의 0기준 시작과 끝 제외 인덱스다. JSON 입력은 JSON pointer, 텍스트 보강 파일은 전 내용을 `{"text": ...}`로 보는 `/text`를 쓴다. 인쇄 페이지와 문단 번호는 별도의 provenance에 남기고 문자열 인덱스와 혼용하지 않는다. 현 사례 전체의 정본 연결·출처 컨테이너·기존 답 대조는 [case_registry.jsonl](case_registry.jsonl)에 있다. 과거 원장의 답은 원 배포 정답표의 이번 신규 재검증을 뜻하지 않는다.

## 별도로 유지할 원장

1. **후보 원장**: 원 후보 ID·정의 버전·최소 근거·반복 상태·계층. 현재 [candidate_correspondence.jsonl](candidate_correspondence.jsonl)은 원본과 대응 관계를 보존한다.
2. **후보 관계 원장**: from/to·관계 유형·적용 부분·대표/경계 case·판단 이유·판단 실행. 동일/하위/중첩/별개/부족을 구별한다. 현재 표의 관계는 전체 정의가 아닌 명시한 하위 부분에 한정될 수 있다.
3. **출처·보강 이력 원장**: 결손 발견, 복원 자산 생성, 실제 열람, 원지면 대조, 답 대조를 별도 사건으로 기록한다. 파일 생성 시점과 분석 단계의 사용 시점은 같지 않다.
4. **학생 관찰 원장**: 향후 동의된 수업에서 실제 행동을 관찰하면 별도로 만든다. 모델이 재구성한 reasoning_steps를 학생 사고 관찰로 복사하지 않는다.

## JSON 형태 외에 필요한 의미 검사

JSON Schema는 필드 형식·허용값·필수 항목을 검사할 뿐 아래 사항을 완전히 증명하지 않는다.

- 근거 ID가 같은 레코드 또는 등록된 외부 인덱스로 해소되어야 한다. 인용한 선택지 번호가 해당 case와 일치해야 한다.
- `char_end_exclusive - char_start`는 정확한 인용 문자열 길이와 같아야 하고 원문 부분 문자열도 일치해야 한다.
- `phase=Sol독립1단계` 기록에서 코드북 사전 열람이 false라는 것은 해당 단계의 보고를 보존하는 값이다. 실제 런타임 전체 미노출을 증명하지 않는다. G095와 RX의 이력은 별도 남긴다.
- `answer_action=번호보류`이면 해당 단계의 선택은 null이어야 한다. 별도 사후 답 대조 값이 생겨도 초기 선택을 바꾸지 않는다.
- `content_status=근거부족`은 그 진술의 현실적 거짓과 같지 않다. `task_role_status=부적합`은 내용 자체가 거짓이라는 뜻이 아니다. AYG②가 대표다.
- 경계·미확인·미분류는 양성 활용 계수에 넣지 않는다. 설명된 구조를 실제 수행으로 바꾸지 않는다.
- 강한 기출 반례에는 원 규칙의 모든 최소 조건이 충족되었다는 직접 논증이 있어야 한다. 단순한 비적용 사례에는 그 값을 쓰지 않는다.
- `necessary_for_all_routes=예`에는 모든 타당 경로에서 그 연산이 필요하다는 근거가 추가로 필요하다. 현 예시에서는 그런 강한 주장을 하지 않는다.
- 관계가 다른 원장을 supersede하더라도 파일을 덮어쓰지 않는다. 새 버전·변경 이유·이전 기록을 연결한다.

## 후속 빈도 산출

집계 키는 **패턴·하위형·관계·역할·시험계열·표본분할·분석조건**이다. 지문 수는 identity_family의 집합, 문항 수는 정본과 연결된 question ID의 집합, 장면 수는 stable event ID의 집합으로 계산한다. Sol과 외부 적용이 같은 문항에 같은 판단을 했으면 분석 기록 수는 둘이지만 고유 문항은 하나다. 상위 가족 수와 하위형 수를 합산하여 총 문항 수로 쓰지 않는다.

현재 자료는 목적 표본이며 원자 사건의 전수 추출도 아니다. 0은 연결된 양성 근거가 없다는 뜻으로만 사용한다. KICE·LEET·MEET는 나누어 보고하고, G095 과거 노출과 RX 단계별 결손은 별도 층으로 필터링한다. 향후 전수 코퍼스 빈도를 계산하려면 별도의 전수 적용 범위·완결성·중복 제거·결손 분모 정책을 먼저 정해야 한다.

## 예시가 보여 주는 구별

|예시|상태|표현하려는 차이|
|---|---|---|
|JN④|내용 반박·부정형 정답 선택|내용이 틀려도 선택 행동은 ‘선택’|
|YT①|내용 지지·부정형 비선택|위협은 확정, 효능감은 미확정|
|AYF③|논리적 미확정·증거 역할 부적합|부분 순서의 결손과 반모형|
|AYG②|내용 자체 미판정·요구 역할 부적합|효율 차이를 거짓으로 만들 필요 없이 증거 기능 배제|
|ATN③|근거 부족·부정형 정답 선택|찬성 사실에 동기를 추가한 결손|
|RX Sol 단계|자료 결손·번호 null|A/B 의미는 판단해도 번호는 보류|
|RX 외부 적용 단계|보강 자료 사용·④ 선택·당시 공식 미대조|후속 선택이 이전 null을 덮어쓰지 않음|

이 7개 예시는 스키마의 표현력을 보여 주는 축소 기록이며 해당 문항의 모든 추론·근거를 전수 재주석한 자료가 아니다. 전체 논리 설명과 추가 근거는 사례집과 기존 분석을 함께 따른다.
