# 100코드 패턴 연구 심층 종합 — 작업 C

2026-10-12. 기존 다섯 연구 폴더와 필요한 개별 원문·원장을 근거로 종합했다. 고유 표본은 18지문·60문항이다. Sol 독립 분석과 코드북 외부 적용은 같은 후속 6지문을 다른 조건에서 분석한 기록이며 두 독립 표본으로 세지 않았다. 전체 코퍼스 재풀이·재분류는 수행하지 않았다.

핵심 결과는 지문 구성, 문항 조작, 풀이 행동을 서로 연결하면서도 동일시하지 않는 구조다. 원 후보 46행(코드북 13, Sol 20, 외부 잔여 13)을 빠짐없이 대조했고, 기존 코드북으로 남는 연산에는 N01~N11의 잠정 식별자를 부여했다. 일부는 기존 후보의 하위형이며 새로운 확정 패턴 11개라는 뜻이 아니다. 실제 기출의 대표·경계 대조 20묶음, 교재 단원과 강의 시연, 신규 제작 원리와 축소 시제품 2개, 후속 코퍼스용 스키마와 7개 예시를 저장했다.

주요 판단은 다음과 같다.

- P05와 ACT-I의 문맥 치환은 같은 원리로 연결한다. S03은 OX·YR의 두 KICE 지문에서 전개 동작 대응이 반복된다.
- NL의 정의 의존 순환, NM의 결합 전제 실패, RW·GL의 기전 선후는 서로 다른 추론이다.
- 내용의 참·거짓과 증거·반박·대안의 역할을 분리한다. GK·NN·AYF·AYG·ATO는 상위 질문을 공유하지만 하위 연산을 보존한다.
- 유보도 YT의 다대일 역상, AYF의 비교 간선 결손, ZF의 후보 적합성, RX의 원문 결손으로 나눈다.
- S05는 현재 AJP 장면에서 P02 하위형으로 연결하되 규범 해석 전체의 통합은 유보한다. RY의 오류별 후속 경로 선택은 P06의 잠정 확장으로 남긴다.
- ATN③의 ‘감축→면제’와 ‘찬성→특정 기대’를 분리한다. 원문 총량이 없으므로 실제 잔여를 새로 단정하지 않는다.

## 결과를 사용할 때

이 결과는 기존 분석을 공개한 상태의 심층 종합이며 새 blind 발견 실험이 아니다. G095의 정답·코드 노출 이력, RX의 9월 결손/복원/보조 작업자 노출과 10월 단계별 보강 사용 차이를 유지했다. 원지면 신규 전수 검수, 실제 학생 관찰, 표본 밖 반복 검증은 수행하지 않았다. KICE·LEET·MEET 빈도는 별도이며 모집단 비율로 일반화하지 않는다.

입력 보존과 인용·참조·스키마·설계 상태 점검은 [validation_report.json](validation_report.json)을 따른다. 검증 통과는 의미 타당성이나 학생 효과의 인증이 아니다. 요청 모델/effort와 확인 가능한 런타임 정보는 [run_metadata.json](run_metadata.json)에 분리했다. 결과는 이 폴더에만 저장했으며 기존 원본·동결 파일·공용 원장 수정, 다른 모델 호출, Git push는 수행하지 않았다.
