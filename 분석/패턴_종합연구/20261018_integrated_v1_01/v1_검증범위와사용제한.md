# v1의 검증 범위와 사용 제한

이 v1은 기존 분석을 탐색·수업·제작에 사용할 수 있게 조직한 파생 연구 체계다. 연구의 종료, 모든 원리의 확정, 학생 효과나 완성 창작 문항의 품질 검증을 선언하지 않는다.

## 입력과 이번 작업

- 현행 통합 입력: 사례집78·원리63·결정96·변형 효과300·기존 후보112. 잠정 안정화26·단독 잠정29·추가 비교5·재분류3의 상태를 그대로 보존했다.
- 장면: 탐색616+심층 보완1586=2,202, 고유 문항1,667. 모든 장면의 ID·출처·연결 상태를 수록했다. 모든 선지에 필요한 모든 연산을 추출한 코퍼스라는 뜻은 아니다.
- 이번 제한된 직접 대조: 16문항·15지문군의21장면, 원리 연결23건. 기존 직접 비교191장면 안에서 대표·경계를 다시 읽은 것이므로191에21을 더해 신규 실적으로 보고하지 않는다.
- 의미 연결 승계만 있는119장면, 후보명 경유 연결만 있는1,847장면, IR 미연결 후보195장면, 후보 없는 미분류20장면을 구별한다. 후보 경유 연결9,890건은 가능한 탐색 경로 수이며 실제 출현 빈도가 아니다.
- 제작 카드4개, 잠정 학습 단위12개를 작성했다. 카드의 가상 수지·복원·규약 기본 모형은 [국소 검산](카드_국소검산.json)에 범위를 기록한다. 완성 문항 제작이나 학생 실험은 수행하지 않았다.

## 출처 확인의 수준

이번 직접 대조는 로컬 정본/전사 텍스트와 기존 중간 추론을 대상으로 했다. AGT의 골격과 BFV의 거리 계통수·분기론 그림3개는 직접 판독했다. BEX·BHM·AYN의 별도 보기 텍스트도 함께 읽었다. AXY는 기존 수식 복원 파생본을 사용했다. 원배포 PDF나 공식 답안의 전수 재검증은 하지 않았고, 공식답은 기존 정답 대조 결과를 승계했다. 새로운 blind 성과는0이다.

원리 정의·한계·상태는 기존 원장, 실행용 입력·단서·중간 추론·상위 조직은 이번 AI의 편집 제안이다. 원리 수63은 서로 완전히 독립인 인지 능력63종의 실증적 발견을 뜻하지 않는다. 상위 조직7개와 관계52개도 새로운 확정 원리 수로 더하지 않는다.

기존 비교191장면과 현행 원리에 정확한 장면ID로 연결된 범위가 같지는 않다. 비교 후 별도 후보·유보로 남은 장면이 있고, 하나의 장면에 여러 원리나 경계 역할이 있다. 이 차이를 자동으로 메우기 위해 결정 기록의 모든 원리와 모든 장면을 교차 연결하지 않았다.

## 사용 가능한 범위

잠정 안정화26개는 명시된 조건과 제외 적용을 붙여 교수 설명·제작 설계의 입력으로 사용할 수 있다. 단독 잠정29개는 해당 사례의 조건부 설명과 대조용으로 사용하며 독립 반복이 충분히 확인된 보편 규칙으로 소개하지 않는다. 추가 비교5개는 미해결 해석을 정답 생성 규칙으로 사용하지 않는다. 재분류3개는 원래 판단을 보존하되 독립성은 미정이다.

[사용 제외 목록](사용제외_적용목록.json)의 AKX 충분 방향, BDN 전신 순효과, ASN 공포 제거 목적, BEB 느슨한 상한 반박, AQQ 기법 전면 부재, AXB 절대 구조 유일 역산 등을 자동 정답 근거로 쓰지 않는다. NF/AXY/AYN/BHM, MB/MJ/BDI/W, KF/HL/KB의 국소 조건도 그대로 남는다. QZ·SH의 문언·모형 유보, BCF 메타, 원유보93건·G024/G370 hold도 해소 처리하지 않았다.

## 아직 검증하지 않은 것

전2,202장면의 새 의미 판정, 모든 원리의 독립성·완전성, 전300개 변형의 새 수정 문항 검증, 기출의 외부 학문적 사실 전수 확인, 실제 학생의 재현성·학습 효과, 새 소재의 전문적 완성도, KICE 문체·난도, 다른 모델의 성능·상호 검토 효과는 검증하지 않았다. 기존 시제품3종도 이번 작업으로 사용 가능 판정을 얻지 않는다.

파일 검사는 JSON/JSONL 문법·ID 유일성·실제 장면 집합 일치·원리/결정/효과 참조·로컬 경로·필수 파일의 저장을 확인한다. 이는 의미의 전수 타당성 검증이 아니다. 입력 보존 검사는 기록해 둔 주요 입력13개에 한정하며 전체 저장소 불변을 증명한 것으로 보고하지 않는다.

요청 실행 모델은 GPT-6 Astra xhigh다. 이번 작업에서 모델 전환·다른 모델 호출은 하지 않았고, 도구에서 실제 런타임 모델의 정체성을 별도로 확인하지 않았다. 설정명으로 실제 실행 모델을 검증했다고 주장하지 않는다. Git push와 기존 원장 수정도 수행하지 않았다.
